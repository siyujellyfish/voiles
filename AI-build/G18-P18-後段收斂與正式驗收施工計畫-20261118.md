## S1 連續同步方法的呼叫位置與持有者生命期

基線為 #849。已重現 main 將第一次方法回傳存入 int 宣告，再呼叫同一持有者的方法時，原 Checker 接受，原執行器卻在準備第一筆局部宣告時失敗。

方法執行計畫現在依原語句及呼叫範圍選擇方法。整段程式先驗證，執行時在同一份 Checker 資料上綁定各位置的實參。main 只建構一次持有者，同一個借用追蹤器依序發票、還票。方法返回值依宣告身分留在呼叫端，下一次呼叫會讀到當下的欄位與整數槽。第一個執行期錯誤會結束序列並清理持有者。各次呼叫保有自己的來源範圍、借票與退出紀錄。

連續呼叫的專項涵蓋共享欄位、連續返回值相依、同名方法收據錯序／遺失、溢位截斷及來源身分竄改。此批涵蓋持有者建構後連續以 int 宣告接收方法值，再進入既有 main 後段。B4 的多持有者、方法與普通函式共用一般控制圖仍待驗收，清冊維持 17/26。

### 呼叫之間的主函式區域變數

普通整數／布林宣告、首次賦值、重新賦值與持有者欄位更新可以穿插在同步方法之間。主函式保存已宣告的身分與實際初始化槽。每個呼叫位置只執行上一次方法返回後的陳述式；方法歸票後，主函式的槽仍可供下次呼叫使用。只有主函式離開才清空其區域槽。獨立案例驗證跨呼叫的空槽初始化、欄位只加一次、布林重賦與方法回傳再作實參。

同一 main 開頭可按宣告順序建構多個具已核准常值欄位的持有者。每個呼叫位置由原接收者宣告身分挑選結構與簽章，獨立驗證該位置的借用事實。交替操作兩個同型別實例時，只有被呼叫的實例會改變；成功收據同時核對位置及持有者身分。直接 await 維持原單一持有者子集。
