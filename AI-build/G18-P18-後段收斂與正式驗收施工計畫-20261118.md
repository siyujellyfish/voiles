## S1 連續同步方法的呼叫位置與持有者生命期

基線為 #849。已重現 main 將第一次方法回傳存入 int 宣告，再呼叫同一持有者的方法時，原 Checker 接受，原執行器卻在準備第一筆局部宣告時失敗。

方法執行計畫現在依原語句及呼叫範圍選擇方法。整段程式先驗證，執行時在同一份 Checker 資料上綁定各位置的實參。main 只建構一次持有者，同一個借用追蹤器依序發票、還票。方法返回值依宣告身分留在呼叫端，下一次呼叫會讀到當下的欄位與整數槽。第一個執行期錯誤會結束序列並清理持有者。各次呼叫保有自己的來源範圍、借票與退出紀錄。

連續呼叫的專項涵蓋共享欄位、連續返回值相依、同名方法收據錯序／遺失、溢位截斷及來源身分竄改。此批涵蓋持有者建構後連續以 int 宣告接收方法值，再進入既有 main 後段。B4 的多持有者、方法與普通函式共用一般控制圖仍待驗收，清冊維持 17/26。

### 呼叫之間的主函式區域變數

普通整數／布林宣告、首次賦值、重新賦值與持有者欄位更新可以穿插在同步方法之間。主函式保存已宣告的身分與實際初始化槽。每個呼叫位置只執行上一次方法返回後的陳述式；方法歸票後，主函式的槽仍可供下次呼叫使用。只有主函式離開才清空其區域槽。獨立案例驗證跨呼叫的空槽初始化、欄位只加一次、布林重賦與方法回傳再作實參。

同一 main 開頭可按宣告順序建構多個具已核准常值欄位的持有者。每個呼叫位置由原接收者宣告身分挑選結構與簽章，獨立驗證該位置的借用事實。交替操作兩個同型別實例時，只有被呼叫的實例會改變；成功收據同時核對位置及持有者身分。直接 await 維持原單一持有者子集。

### 普通函式與同步方法的同一次進退紀錄

由 main 直接返回普通同步函式，可經多層具名函式轉交至實際建構持有者並呼叫方法的框架。每層須有原 Checker 驗證的 Return 邊、整數結果及簽章；整數常值與已綁定的整數形參可依位置傳給下一層。相同拼字在不同函式分別使用自己的宣告身分。整段執行記錄 main、普通函式及方法的進入、返回或錯誤、逆序離域及真借票歸還。方法內單筆收據與整段進退紀錄的借票身分逐一核對。

此路徑限每個外層普通函式以一條 return 轉交至下一層。包含借用參數、一般條件分派與迴圈的呼叫仍須獨立驗收。B4 仍開放。

### 同步方法執行期間的字串欄位

當已驗證的結構帶有 str 字面預設時，沿用既有 P16 字串種子、建構及單一資源帳。每個實例的欄位有各自的 ResourceId，無法作為 Copyable 純值傳參或回傳。方法正常、整數溢位或入口故障時須先歸還 self 票據，建立實例的普通函式退出前按持有者與欄位的反序清理。完整事件與實際欄位 ResourceId 清單逐筆對照。多個實例的資源在同次執行內核對；同步方法可修改其他 int/bool 欄位，這批沒有開放 str 欄位的部分移動或跨 await 持票。

### 普通函式控制流內的共享方法讀取

普通函式可在純量運算式中，對已建構的持有者呼叫零參數同步方法，返回 self 的整數欄位。呼叫沿用普通函式的控制流、步數與呼叫預算。每次實際執行才借票及還票，並依原始方法宣告、接收者身分、欄位與來源位置核對收據。獨立案例覆蓋迴圈次數、提前返回、預算耗盡時清理、既有字串參數借票，以及變造來源與重播票據。B4 的其餘契約仍待驗收。

結構建構的具名整數實參若含同步方法呼叫，直接呼叫、括號及加減均沿用普通函式的任務堆疊。先按來源順序取值並歸票，全部實參成功後才建構新持有者。獨立測試核對成功時兩個實例與方法執行次數，以及溢位時只留下第一個建構事件。

一般函式控制流可執行零參數同步方法的單次整數常值欄位寫入與欄位返回。測試在迴圈三次取得獨占票，再以共享票讀回同一實例，並驗證 const 欄位於原 Checker 被拒絕。B4 的帶參方法與完整錯誤退出仍待驗收。

普通函式迴圈內的同步方法可接收多個位置整數實參（常值或具名槽）。依原 Checker 的引用身分逐次讀取，按方法宣告身分綁定，再取得接收者借票並寫入欄位。獨立案例核對三次迴圈的動態值、最後共享讀取、錯型拒絕與呼叫端加法溢位後停止執行及清理相鄰字串資源。方法內部故障及複合實參仍待驗收。

方法的整數欄位賦值可使用已驗證的形參加減式。取得獨占票後才求值；成功才寫入。溢位時記錄方法內錯誤、歸票及方法退出，普通函式隨後清理資源。共用退出紀錄只計同一次錯誤一次。獨立案例包含第二輪溢位與對調還票、錯誤事件的拒絕。

方法實參改用原 Parser 的同一原子與 Checker 的純整數運算式，可接收括號及加減。所有實參依序在呼叫者內求值成功後才領取方法票。驗收分別在實參及方法內觸發溢位，核對兩者的進入與歸票時序。

方法實參透過同一動態工作堆疊由左至右求值，實參中的普通整數函式有自己的進退框架，成功後才進入持票方法。方法依原 Checker 的 int／bool 型別與順序匹配簽章。共享方法可依布林形參提前返回另一整數欄位；測試同一來源在兩個分支的讀值，以及迴圈內普通輔助函式的呼叫次數。

同步方法中的欄位讀寫、分支及提前返回改由同一份已驗證陳述式計畫依序執行。int／bool 欄位使用同一個 P16 持有者，可在多層 if／else 中寫入再讀取；每個執行到的陳述式消耗呼叫者的共用步數。方法內提前返回會略過剩餘陳述式，耗盡則循相同錯誤路徑還票。獨立案例覆蓋欄位條件因第一輪寫入改變而在次輪選擇另一個分支。

同步方法的具名字串實參使用原 Checker 按實參次序核准的 BorrowFact。實參求值取得借票並連結既有 ResourceId，之後才取得 self 票。方法正常返回、整數溢位或在持票期間耗盡步數時，先還 self 再逆序歸還各實參票，最後退出方法。外層資源清理逐筆對照同一次歸還，收據若缺少實參票則拒絕。

同步方法可在同一呼叫接收多個明確移入的 str，以及借入與純量實參。所有實參求值成功後，依 Checker 的來源宣告身分一次移交資源，來源與形參交叉同名也能保留正確 ResourceId。方法正常或溢位退出時逆序清理。獨立測試另核對實參溢位時沒有移交、重複移動被拒及變造收據被拒。

同步方法可在賦值與返回中對 self 整數欄位、形參與常值作巢狀加減。方法 Checker 核准後記錄原算式位置、兩個運算元與運算子，執行器在持票期間從當下實例取值。驗證普通函式迴圈內連續呼叫同一可寫方法所得累計值、持票溢位後歸票與欄位型別不符時的靜態拒絕。方法本體的 for／while 仍由原 P15 Checker 拒絕；此處的迴圈由普通呼叫者執行。

方法可依分支傳回明確移入的 str 形參。方法出口保留被選中資源的原身分，其他形參逆序清理。普通呼叫端可直接轉回、宣告接收或首次賦值接收。專項核對兩種分支的資源身分、具名借入無法作為移動來源、持票溢位時兩筆同時回收，以及替換返回身分時稽核拒絕。

同步方法返回 bool 時，呼叫端按經驗證的布林簽章接收結果。工作堆疊可在普通函式的區域宣告、if、另一函式的布林實參與欄位賦值等待方法返回。專項確認同一實例依序返回 true、true、false，並驗證欄位寫入後分支改變及整數運算拒絕布林。

同一個方法也可混用字串常值暫存與具名移動實參。依書寫次序求值，移交前核對整批暫存資源與具名槽。實際釋放或傳回的資源編號依來源清單逐項核對。括號內的移動與字面值沿用相同來源證據。

普通函式的迴圈可呼叫持票方法，再由方法呼叫同步純整數函式。方法取得自己的整數局部槽，依來源次序宣告與重賦值；每次內部呼叫保留原呼叫位置、形參身分、實際值與結果。方法退出時先逆序結束已成功初始化的局部槽再還票。獨立案例核對成功、內層溢位、內層步數耗盡與刪除子呼叫收據，以及另一個持有者的欄位作為實參。

方法的 helper 收據依語句與實參求值順序核對，巢狀呼叫先核對實參，再核對外層呼叫。同一方法內兩次呼叫的收據互換時，即使各自的結果與形參仍相符，稽核也會拒絕。

持票方法在真正求值 if 條件後記錄選葉。稽核依已驗證方法重建所選分支與提前返回路徑，逐筆核對必經呼叫；即使同步刪除子呼叫收據及其三筆進退事件，成功執行仍須拒絕。故障允許只執行到第一個未完成的步驟。
