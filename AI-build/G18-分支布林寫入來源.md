# P18 方法分支布林寫入

基線為 #847。同步方法直接寫入與 true 分支的布林寫入共用原 Checker、Lexer 與形參宣告身分驗證。執行時先選分支，取得同一張獨占票據，再從實際形參框架或持有者欄位讀值、提交並讀回。分支計畫保留目標、來源與語句位置。

原分支寫入專項的動態來源案例覆蓋帶括號的形參、main 更新後的欄位，以及兩種來源未選中的路徑。其餘常值、靜態拒絕、竄改與錯誤退出案例沿用。這批補上 B4、M2、M3 的局部證據，正式清冊仍為 17/26。

## 接收者型別身分

以原 Checker 驗證的 main 持有者宣告型別查找結構定義。同一來源可定義具有同名方法的其他結構；選擇目標時使用持有者的宣告身分，建構式、方法呼叫與借票仍逐一核對。專項新增雙結構同名方法，分別執行兩種持有者並核對相異結果，再驗證交叉建構被靜態拒絕。這項證據涵蓋單一實例的型別選擇，多實例共同執行仍待完成。
