# G18／P18.1／P18.4｜同一真 str BorrowTicket 與多個 Copyable int 函式參數（2026-11-06）

> 基線 main 7323704c5731a93d73e249d5311ad274f22dd47d 已通過最新三必要 CI。沿用原私有 Lexer／Parser／Checker、P16 TypedMember／BorrowFact、HC14 BorrowSafety、P16 OwnedStrRuntime，不新增語言語法、公開入口或假型別轉換。**原 G18 六項不得提前 Passed。**

## 實際驗收缺口

先前 P18.4 真普通函式 BorrowTicket 僅允許一個 str 借用及最多一個 Copyable int；已核准 Checker 接受一個 str 預設借用與多個 Copyable int 參數，但現有私有執行器錯誤用長度 2 上限拒絕。與本期前批 #557 已接通純 int 多參數呼叫不一致，阻礙 P18.1/P18.4 同函式混合傳參及退出責任完整驗收。

## 真工程

- 直接擴充既有 src/struct_stage/execute_call_borrow.rs 的**同一真正借用執行器**：原 Checker 必須確認唯一 str 型別參數及其餘任意數量 int；仍要求原 Lexer 具名 str 唯一所有者和 call_borrows_at(NodeSpan) 精確 BorrowFact/Kind/DeclarationId，絕不把 str 複製成別的 ResourceId。
- 按原 Parser 簽章順序逐參數檢查每個 int 的 P16 TypedMember、Checker DeclarationId／ScalarHIR；每個 int 實參可為已驗證字面或本切片唯一已初始化具名 Copyable var／const，合法重複使用同一具名值。舊單 int_binding 保留來源相容，其餘均保存在 additional_int_bindings，重新 Checker 交叉比對時後續參數不得竄改或移位。
- 真動態執行中**只簽發一份原 Checker str BorrowTicket**，先以同 tracker／serial／Kind／source_id 驗證，讀取原 OwnedStrRuntime 真 UTF-8 長度；同一函式框架再為每個 int Parameter DeclarationId 綁定 i64 slot，原已驗證算術返回每項自真動態槽求值。正常／整數溢位／內部測試故障，均先清空所有 i64，再按原 Checker BorrowFact 原子歸還票據，最後 ResourceId 必須恰好釋放一次。
- 七項真正正反涵蓋四 int ＋單 str、str 參數夾在 int 中間且為 var 獨占、同一具名 int 重複 Copyable 取值、溢位及故障清理、後續參數與借用事實遭竄改、錯型別／漏參數／尚未執行語句拒絕。專項 Gate 25→32，原 G18 六項 P18.4 追溯增加真來源。
