# AI-build｜voiles 專案工作依據

> 本資料夾專供協作開發時讀取與維護；對外介紹請參考儲存庫根目錄的 README.md。

## 目的

voiles 是自製程式語言專案，目標是保留 Python 風格的簡潔語法，參考 Rust 的記憶體安全設計，優先發展直譯器，並逐步支援編譯、封裝獨立執行檔與工具鏈自舉。

## 明確規則

1. 語言與儲存庫名稱均為 `voiles`；不再使用舊名稱。
2. 每次實作或規劃變更，同步以修改方式更新 `AI-build/` 既有適當文件，優先保留精簡、可增量閱讀的內容。
3. 實作在新分支進行；透過合併請求與壓縮合併（Squash merge）進入主分支。
4. 持續整合須兼顧可靠、快速與成本，避免在對話內不斷輪詢等待執行結果。
5. 不得將推測視為決策；需要新假設、技術選型或有風險的改動時，先取得使用者同意。
6. 所有說明文件與程式註解一律使用繁體中文；無法迴避的語言關鍵字、路徑與專有名稱可保留原文，其他英文盡量避免。
7. `README.md` 面向外部使用者；`AI-build/` 保存內部規格、規則、工作狀態與待確認事項。
8. 所有檔案讀寫指定 UTF-8 編碼。

## 每次工作開始與結束

- 開始：先讀本檔及與工作相關的 `AI-build/` 文件，再檢查儲存庫現狀。
- 執行：確認需求邊界；只修改已同意的項目；使用新分支。
- 結束：同步更新既有規格、工作紀錄與待確認事項；驗證後提出合併請求；一律採壓縮合併。
- 若持續整合未結束：回報真實狀態與合併請求網址，不進行高頻輪詢，不宣稱已通過。
