# AI-build｜voiles 專案工作索引

本資料夾是後續開發與規劃的**唯一專案內工作依據**，避免每次以冗長對話重述歷史。對外說明由儲存庫根目錄 `README.md` 負責。

## 閱讀順序

1. [專案規則.md](專案規則.md)：強制執行的協作、分支、文件、驗證規則。
2. [語言規格-v0.2.md](語言規格-v0.2.md)：已確認的語言方向與現階段語意界線。
3. [待確認事項.md](待確認事項.md)：尚未獲得授權的決策；不得自行當作既定規格。
4. [工作紀錄.md](工作紀錄.md)：最新成果、驗證情形與下一步。

## 維護方式

- 每次開始工作都要**重新讀取儲存庫目前版本**，不可使用過時的對話推斷現況。
- 每次實作或規劃調整，**修改既有適當文件**，只保留最新有效規範；重要變更另寫入精簡工作紀錄。
- 新的技術選型與推測性行為需先取得使用者同意；未決項目寫入待確認事項。
- 文件與程式註解一律繁體中文，所有讀寫採 UTF-8。
- 工作用新分支；合併請求通過必要檢查後，使用壓縮合併。不得宣稱未完成的檢查已成功。
- 優先更新現有內容而非反覆新增重複文件，控制上下文閱讀量。

## 專案目的

voiles：Python 風格的簡潔語法、參考 Rust 的所有權與記憶體安全，直譯模式優先，支援編譯及打包獨立執行檔，長期以自身語言自舉。
