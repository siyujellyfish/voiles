## 程式修改

只修改 `src/struct_stage/execute_call_scalar.rs` 三個**既有**生命週期位置：

1. `PreparedPrivateScalarCall::execute_with_budget_and_fault_scheduler`，在建立任何私有 RunTime 框架、P16 UTF-8 `ResourceId` 和動態事件之前，用原唯一 `verified_private_source_tokens(source, &self.verified.tokens, &self.verified.structs, &self.verified.functions)` 對帳真正封存的 Lexer／AST。
2. `PrivateScalarGraphContinuation::new_with_budget`，在 `root_for_graph`、保存 checkpoint 或協作式 FIFO 配發 ID 前，再驗原來源 bytes、同一份 Token、原 `is_consistent` 與 `matches_source`；不安全時 `SourceChanged`，上層佇列映射 `Engine`，**不能消耗新 submit ID**。
3. `PrivateScalarGraphContinuation::poll`，在每次真正新 poll／重進安全點時重新對帳原已封存 Token／AST，失敗保持 `SourceChanged`，不得重建舊資源或造出新 Returned。
4. 全部皆重用原 `token_provenance.rs`、`checked_function_header_tokens`、`VerifiedScalarHIR`，不新增第二 Lexer／Parser、任何可觀察語意或動態借用，也不自行變更 V7 E1～E5、S17、P16 或公開 CLI。
