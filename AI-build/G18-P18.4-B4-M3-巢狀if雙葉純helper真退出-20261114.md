## 本批唯一新執行路徑

現在 M2 巢狀 if／else 的內層 else 葉，與現有 true 葉共用 `private_self_checked_helper_return_leaf`：只讀取**原 Checker `method_writes` 已核准且 `self.evaluate` 已生成的完整 ScalarHIR**，核對原 Lexer／Parser span、直接 `Call`、唯一已封存的純 Copyable int helper 名稱與全簽章參數原 `DeclarationId`、無 await、無子函式 Call、所有實參均屬已核准純 int HIR。不得自行造 TypedHIR、借用政策、函式解析路徑或一般控制流程。返回計畫仍由 `matches_source` 完整真重編防偽。

方法進入時僅借用原 Checker 證明的唯一 `self BorrowTicket`。若外層 bool 為 false，內層 if 完全未觀測、不執行其任何 helper 或 self 欄位寫入。若外層 true，先觀測內層原 Lexer bool／唯一原 Parser bool 形參；只在 true／else 真選中葉寫入其已核准 self.int 常值、由 Caller 在當前 int frame 依原順序求完真引數，才可 `FunctionEntered` helper。求參溢位不得假進內層 helper，helper 返回溢位才可記唯一 `UnwindStarted`、`FunctionExited(false)`，最後才由既有方法退出責任歸還 BorrowTicket。未選中葉無任何假返回或錯誤事件。此批不放行 Nested Call、普通函式多層 CFG、非 Copyable str ResourceId、Borrow／Move、方法局部與分支交錯、async。

## 八項 Rust 真來源正反與 CI

新增 `src/struct_stage/g18_b4_m3_nested_if_helper_return_tests.rs`，八項涵蓋：

1. 外層真、內層 bool true：只執行 true 葉 helper 返回 7，子框架先退後歸還 self；
