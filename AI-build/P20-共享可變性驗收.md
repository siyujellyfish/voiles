# P20 模組級共享字串

2026-11-21 核准 P20-B 建議項。依 H04、I02、X06、Y04，模組級 `share name:str = 初值` 必須明確標型並立即初始化。同一模組的函式可以直接讀寫，不需要寫入意圖標記。

| 存取者 | 讀取 | 寫入 |
|---|---|---|
| 宣告模組 | 允許 | 依借用狀態允許 |
| 不同模組且名稱可見 | 允許 | 拒絕 |
| 不同模組且名稱不可見 | 拒絕 | 拒絕 |

P20 採單執行緒。跨執行緒存取、區域級 share 與其他型別皆不開放。沿用最後使用點與跨 await 借用限制。P21 負責真實多檔來源的名稱匯入與可見性解析。

## 施工與驗收

私有入口 `struct_stage::inspect` 與 `PreparedShareModule::prepare` 共用模組宣告、函式 AST 與存取計畫。測試素材為 `tests/fixtures/p20/模組共享字串.voil`。公開 MVP-A CLI 維持原階段範圍。

| 子階段 | 本批驗收案例 |
|---|---|
| A | 同模組多函式共享最新值、缺型別、缺初值、型別錯誤、重複宣告、區域級宣告 |
| B | 兩個模組皆宣告 x，名稱可見時外部讀取、不可見時拒絕、跨模組寫入拒絕、獨占借用阻擋外部讀取 |
| C | 共享及獨占別名、直寫與間接呼叫衝突、最後使用點、祖先借用跨直接 await |
| D | 整字串與單字素覆寫、真 BorrowTicket、錯誤退出、失敗前後持有者識別與資源事件 |
| E | 逐名執行同模組來源、跨模組權限矩陣及回滾案例，重跑完整 Rust 內測與 G17–G19 |

本批執行入口支援以字串常值初始化、零參數且回傳 int 的直線函式、直接 await、整字串覆寫及常值索引。尚未將任意既有函式、控制流或 struct 與此入口組合；未支援的組合在準備階段拒絕。跨檔 import 由 P21 接線。

本機以 `rustc --edition=2021 --test --crate-name voiles_source_tests src/lib.rs` 建置內測，再以 `python3 tools/核對G20驗收.py --test-bin <本次測試執行檔>` 逐名執行。正式結案依最新 PR HEAD 必要 CI 與合併後 main 狀態核定。
