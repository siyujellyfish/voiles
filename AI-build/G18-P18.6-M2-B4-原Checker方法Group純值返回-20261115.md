## 實際修改與最小安全邊界

1. 只新增 `private_self_checked_ungrouped_return` 在同一 `execute_method_self.rs`：逐層解開**原 Parser 已建** `Group` 的內部 `Term` 借用引用，不建立第二份 AST；每層要求內 Span 嚴格被外 Span 包含，原 Lexer 原位必有精確 `(` 起始與 `)` 結束 Token。任何已封存括號來源不符都拒絕，並由現有 `matches_source` 在真執行前再次校驗原原始碼、Checker、安全 HIR 與封存 Token。這不是新語法，也不簽發任何新借用票據。
2. 無方法局部的 `return` 仍以原 Checker `MethodSafety.checked_returns`、原方法唯一簽章、原 main Caller 真 `call_borrows`、唯一 `BorrowFact` 為授權；只有原純 helper Call、BinaryInt 含 helper 時仍沿用已驗收 `private_self_checked_helper_return_leaf`／ScalarHIR，不變更 #808 真 Group helper 退出子圖。
3. 對沒有 helper 的返回式，在經原 Lexer Group 逐層查核後，允許直接 `FieldRead`／已驗證 int 形參 `Name`／原 Lexer Integer 常值／既有二元 int 加減。方法參數仍必須由 `private_self_method_parameter_reference` 查核原已綁定 DeclarationId 及真 Name Token；常值額外核對 `TokenKind::Integer` 原起訖跨度與確切內容、`integer_i64` 合法性，再映射原已存在的 `PrivateSelfIntReturn::Constant`。
4. 二元加減保持原完整左右外節點跨度驗算實際 `+`／`-` 字元位置、原 Checker 已核准的 int 型別及借用；僅對左右**值葉**各自解開真 Group，依原 Lexer `FieldRead`／Name／Integer 精確解析，不接受其他未證實的資源、Move、Borrow、任意函式或隱含型別轉換。執行期仍走既有唯一 CheckedSelf Return、SharedCallExit 和原 HC14 票據，含溢位 Unwind→LoanReturned。
5. V7 直接 `await owner.read()` 的無方法內 await 子集亦使用同一 `PreparedPrivateSelfMethod`，故本次同步 pure self 修復可在已核准 V7 `PrivateCheckedDeferredSelfAwaitQueue` 真 FIFO、LoanAcquired 及安全正常退出中驗證，不新增外顯 async 語法／背景任務／跨 await 借用。
