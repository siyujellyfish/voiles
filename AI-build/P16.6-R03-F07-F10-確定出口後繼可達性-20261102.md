# P16.6-R03 F07／F10｜確定退出的後繼可達性接入借用 use-def（2026-11-02）

> 本批只針對已能以既有受限語意**靜態證明必定離開當前語句序列**的情況減少借用活性假陽性；不假設未知條件、不提前開放一般 CFG 或 P17。全文 UTF-8。

## 已實作
- 在私有 `Checker` 加入 `future_stmt_must_exit` 與 `future_block_must_exit`，只將 **return、break、continue** 以及存在 else 且兩側語句序列均必定退出的 if 視為確定終止當前語句序列。
- F07 已有的後繼單次 DeclarationId use-def 掃描，現在於確定退出語句完成其自身名稱使用解析後**停止掃描同一序列的不可達後繼**。不會因不可達的同名讀取而將外層 LoanBinding 的票據延長至無關路徑。
- 無 else、只一側退出、while 與 for range 因可能執行零次或具有反向邊，仍保守視為可能繼續；迴圈內 break/continue 僅終止目前本體序列，**不得讓迴圈外後繼消失**。
- 新增直接返回後未執行的別名、兩側 return 的 if、缺 else 和僅單側 return、迴圈 break／continue 及迴圈後仍用別名等獨立架構回歸；保留已核准診斷及完整 P01／P13～P16 來源檢查。
