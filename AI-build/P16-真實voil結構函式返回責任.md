# P16 真實 voil 結構整筆函式返回與 UTF-8 資源歸屬（2026-10-30）

> 接續 #257 持續結構資源模型及 #258 真正來源整筆 move；本批驗證被呼叫函式真正建立整個結構，將所有非 Copyable 欄位資源移交呼叫者，且不在被呼叫函式退出時重複釋放。這不是一般 P17 執行入口，P16 原始六項仍待正式驗收。

## 已核准設計

- P13 非 Copyable str 與整個結構 S19／S21 移動／複製安全；非擁有借用不得藉函式返回逃逸或變成第二所有者（VA15-02-A）。
- VB16-01-A：具名引數先依原始碼書寫順序求值，未覆蓋預設再依結構宣告順序；已覆蓋預設不求值。
- VA16-01-A／VA16-02-A：每個真實 UTF-8 緩衝區只有一個持有者，轉交同一資源身分，不依賴 Rust Drop 決定清理次序；失敗回滾按已初始化逆序清理。

## 本批新增來源映射

- src/struct_stage.rs 新增測試專用 trace_persistent_struct_return_source。真實 .voil UTF-8、Lexer、Parser、Checker 全部通過後，只對無參數 provide()->Struct 中的「單一 str 結構建構；return local.move()」及 main 中的「var received:Struct = provide()；return 0」建立唯一資源返回路徑。
- 從真正 AST 提取已核准 str 欄位預設與具名字面值，交由 #257 OwnedStructRuntime 真實配置 UTF-8 String；依序回傳同一 OwnedUtf8 資源，向帳簿發出 Returned 身分事件，離開被呼叫端後由新持有者清理，並核對每一筆 Released 恰好一次。
- 失敗注入只限真正的具名／未覆蓋預設步驟；若求值中途失敗，只在被呼叫端逆序釋放已成功取得資源，沒有 Returned 事件。
- 不支援不經 .move() 的整體非 Copyable 回傳、借用逃逸、任意函式額外語句、main 額外操作、字串轉義求值及一般控制流程。這些來源需安全拒絕，不可聲稱有完整函式執行器。

## 八項真實來源正反

1. 合法來源完整結構建立、逐欄位 Returned、呼叫端逆序 Released，各同一資源身分。
2. 具名欄位失敗回滾且無任何返回事件。
3. 未覆蓋預設值失敗回滾，先前具名資源亦逆序釋放。
4. 禁止非 Copyable 結構普通名稱直接回傳，避免第二擁有者。
5. 禁止一般 borrow 借用直接回傳逃逸。
6. 被呼叫端額外操作因尚無一般執行器而拒絕。
7. main 額外操作不能在未執行時假稱正常清理已驗收。
8. 未解碼來源字串轉義不作假緩衝區內容。
