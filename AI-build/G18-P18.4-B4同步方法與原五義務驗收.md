# P18.4 同步方法借票驗收

原始 voiles 程式由 main 呼叫普通函式，在迴圈中以同一持有者呼叫寫入方法，再比較兩個持有者的共享讀取結果。方法在持票期間呼叫普通函式，由 Checker 記錄整數引數算式的 HIR 以供執行器重驗。

- `b4_01_兩輪獨占寫入及跨持有者共享讀取`
- `b4_02_方法參數借票與逐輪移交使用實際資源`
- `b4_03_同一來源借後移動與不可寫接收者均在靜態拒絕`
- `b4_04_第二輪子框架溢位截斷後繼共享呼叫`
- `b4_05_共用預算在借票前與持票後均安全退出`
- `b4_06_方法與參數還票次序交換須拒絕`
- `b4_07_原始來源及不同接收者呼叫位置不可互換`

五個獨立 Gate 分別執行 11、20、42、7、42 個案例。正式認列依 PR 與合併後 main 各自提交上的必要 CI 結果。
