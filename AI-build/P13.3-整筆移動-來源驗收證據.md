# P13.3 明確整筆移動正式驗收候選證據（2026-10-29）

> 原始條文：在安全規則核准後追蹤 .move() 的所有權轉移；結構禁止只移動個別欄位。本檔為可追蹤來源候選，不代表已正式完成。

## 已核准規格

- HB13-A：僅合法具名的整筆值可以 .move()；不自動隱式移動。
- S21：不得移動單一結構欄位；S12／S15：方法 self 不可消耗。
- VA14-A／HC14-A：借用中的原持有者不可移動，非擁有借用別名本身不可轉成所有者。
- 來源未初始化、已移動或可達合流不確定時，移動不得意外讀取。
- 允許 Copyable int／bool／float 值的明確整筆移動；str 非 Copyable 但可合法 move，結構遵守 S19 複製能力與 S21 移動單位。
- D01 容器能力 Undecided 不是容器實際 AST 文法或資源表達已完成；P13 私有入口 B 不變。

## 目前新增的來源回歸

| 來源分類 | 正反期望 | 測試 |
|---|---|---|
| str 經函式引數與返回連續移交 | 合法，所有權僅轉交 | str_資源經函式引數及回傳可連續明確轉交 |
| 含資源結構整筆移動／隱含複製 | 明確移動合法，隱含複製拒絕 | 含資源結構可整筆移動但不可隱含複製 |
| 結構具名欄位資源轉交 | 明確移交合法，來源第二次移交拒絕 | 具名欄位建立式明確轉交資源不得重複使用舊來源 |
| 借用別名 .move() | 靜態拒絕 | 移動借用別名不得偷轉成所有者 |
| 來源有有效借用仍 .move() | 靜態拒絕 | 有效借用未歸還前不得移動原持有者 |
| 單一結構欄位 .move() | S21 靜態拒絕 | 結構單欄位移動即使資源型別也不被接受 |
| Copyable 方法位置參數明確移動 | 合法、移動後失效、同接收者移動拒絕 | p13_方法位置引數明確整筆移動（PR #202） |
| 其他既有 move 模型與分支 | 必須回歸 | ownership_model、ownership_ledger、struct_ownership、p13_跨函式資源移交 等測試群 |

## 正式完成前必須檢查

- 逐條核對已核准所有來源是否存在合法但因語法／方法資源責任未完成而被保守拒絕者；尤其方法帶非 Copyable 參數，以及完整其他已核准來源。
- 真正的 P16 清理責任仍須獨立驗收，不能把 Rust 抽象事件測試當成整個 P16 已完成。
