## 同一原 Checker 動態呼叫核心

- 原 Lexer／Parser／Checker／TypedHIR 仍是唯一來源，`PrivateScalarBoolExpr::from_checked_call_argument` 只把同步 `bool` 函式返回編譯成具名、已核准的 bool 工作節點。型別、參數、來源身分與 no-async 安全邊界不變。
- `PrivateScalarTask::CheckEarlyReturn` 遇到 bool Call 時，不會先用常值、名稱或 0/1 假猜結果；先以既有工作棧排 `EvaluateBoolArgument`，在原 `BoolReturned` 後由 `FinishEarlyCondition` 讀取真值並選中 if 或下一條 else-if。未選分支完全不排動態指令，不建其資源，不進其函式。
- `PrivateScalarTask::CheckWhile` 每輪先排真 bool Call 與 `FinishWhileCondition`，明確以當輪動態值決定是否再入本體，避免把上一輪 bool 當下一輪快照或偷跑一步。新增任務仍使用 D18-01 每工作累積步數／呼叫深度預算，耗盡走原 Unwind 與 OwnedStrRuntime 真逆序退出。
- 原 `PrivateScalarEarlyIf::collect_calls` 與 `PrivateScalarBranchAction::collect_calls` 現收錄 if/else-if/while bool 條件，並連帶收錄分支 bool 局部宣告／更新的已核准 Call；由原 Checked Source 產生可達工作圖，`matches_source` 仍重新編譯核對不可偽造。
- 原純布林字面、具名及 P16 結構欄位的非 Call 快路不動，避免改變既有 D18/R05 的執行預算與觀測事件先後；未支援 bool 其他型別及等待語意保守拒絕，不新增公開 CLI。

## 真 Rust 正反驗收八項

`src/struct_stage/g18_f2_bool_condition_tests.rs` 由 `tools/核對G18-F2布林條件真控制.py` 逐一 `--exact` 真執行並核對「1 passed、0 failed、0 ignored」：
1. bool 函式真正返回 true 後才選 if true 控制邊；
2. bool 函式真正返回 false 不執行未選中的返回；
3. else-if 依序真執行兩個 bool 條件而只選中第二分支；
4. 第一個 if 已真時，不執行後續 else-if 內的 bool Call；
5. while 條件逐輪重新呼叫 bool 函式，依前輪局部更新得到 true→false，不能重用舊結果；
6. 首輪 while false 時完全不建本體的 P16 UTF-8 資源；
7. 迴圈 bool Call 持續 true 而配置步數耗盡時，原外層 UTF-8 仍由真 OwnedStrRuntime 恰好釋放一次、不假 Returned；
8. int 函式結果不得充當 bool 條件，原 Checker 先拒絕。
