# G18／P18.4-B1：Copyable 形參不消耗原值（2026-11-13）

## 原義務及權威

- 原契約 **B1**：`int`、`bool` Copyable 形參使用值語意，合法傳入不移動／耗盡原持有者；相同來源可重複傳參，與非 Copyable `str` Move／Borrow 的動態責任分開處理。
- 來源權威：原 `Lexer → Parser → Checker → TypedHIR`、`DeclarationId`，真正 `PreparedPrivateScalarCall::prepare → execute`；資源由真 `OwnedStrRuntime`，借用票據由真 `BorrowSafety` 產生。
- 不新增語法、公開 CLI、跨 await 借用或 P13～P16 未核准行為。

## 十一條獨立原始來源

| B1 義務等價類 | 來源與動態驗收 |
| --- | --- |
| B1-01 | const int 傳入兩次；呼叫後原值仍可在 main 讀取 |
| B1-02 | 同一 Copyable int 綁定三個不同形參；值與框架參數數精確對應 |
| B1-03 | 可寫 bool 改值後再次傳參；每次都按真當前值求值 |

| B1-05 | 巢狀兄弟函式同一來源；動態框架／返回值不混用 |
| B1-06 | for 三輪 Copyable 持續可讀，動態迭代值不消耗來源 |
| B1-07 | 同 str BorrowTicket 共存兩次 Copyable 傳參，票據先歸還後釋放唯一 ResourceId |
| B1-08 | str 明確 Move 與 Copyable int 同呼叫，僅 str 轉交資源，int 在呼叫後仍可讀 |
