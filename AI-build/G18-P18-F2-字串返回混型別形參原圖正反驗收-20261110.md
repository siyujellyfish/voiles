## 本批真正實作

- 延伸原 `PrivateScalarStrInitializer::Call`，從零形參改為**原 Checker 確認的同步 str 返回函式**，形式參數可依宣告位置混合 `int`、`bool`、`str`。不能以 Rust 宿主值推測 AST，所有 `int/bool` 均由原 TypedHIR 逐項檢查，禁止隱含轉型；只允許合法 `TermKind::Call` 或已證明是函式的 `UnresolvedZeroArgs`，保留括號原 Lexer 身分。
- 每個 `str` 形參只允許原 Parser 具名借用（原 Checker `BorrowFact`／`DeclarationId`／共享或獨占）或明確 `.move()`（原 Checker／Lexer 唯一來源）。整串 `call_borrows_at(span)` 必須精確等於真編譯的借用序列，拒絕假票據。
- `PrivateScalarTask::DeclareStr` 在原顯式 LIFO 棧上安排左至右真求值：`Evaluate/RecordArgument`、`EvaluateBoolArgument/RecordBoolArgument`、`BorrowArgument`、`MoveArgument`，全部成功後才 `EnterCall`，沿既有真 `StrReturned(ResourceId)`→`FunctionExited`→`StrReturnAccepted(DeclarationId,ResourceId)` 接管同一 `OwnedUtf8`，絕不以 `i64` 模擬 ResourceId 或重新配置。
- 後序實參溢位時，原呼叫者清理真 ResourceId 與 BorrowTicket；未 Enter 的函式不能有假 `StrReturned`。沿 R05/H14/P16／可配置步數清理，不改原 P15 while 不允許函式呼叫條件、V7 限直接 await 的安全界線，不新增公開語言語意。

## 八項原 Rust 來源等價類

`src/struct_stage/g18_f2_str_return_args_tests.rs` 與 `tools/核對G18-F2字串返回混型別形參.py`：
1. `int/bool` 實參先真正求值並綁定，才把 UTF-8 OwnedUtf8 從子函式返回給呼叫者，真 ResourceId 唯一；
2. 父幀持有的 const str 先真借用，子函式另建 UTF-8 返回，票據歸還、兩資源獨立逆序釋放；
3. 父幀 str Move 給子函式，子函式 `return source.move()` 真返回同一 ResourceId，僅一次 Created／Moved／Returned／Released；
4. 一個 int 子函式先真返回，結果再作 str 返回函式的 int 實參，保持動態先後；
5. str 借用後下一 int 實參溢位，不進 str-return callee、不假返回、真票據歸還；
6. str Move 意圖後下一 int 實參溢位，不能提前實際 Move，原幀唯一釋放；
7. str/int 型別錯置及隱含 str 複製由原 Checker 靜態拒絕；
8. 竄改同一個 `StrReturnAccepted` 的 ResourceId，即使事件數相等亦須由來源／雙帳拒絕。
