# G18／P18.4-B4／M3：原 Checker 真 if 選中葉普通純 int helper 提前返回（2026-11-14）

## 已驗收起點與實際缺口

起點 `main ad53dc0ad3e28f95905f904f5e69d33cb8ee1a68`，PR #769 已 Squash merge，且新主線同一 SHA 的「文件與工作紀錄」「Rust 前端建置」「Rust 獨立架構測試」三必要 CI 全部 `completed/success`。現有 B4／M3 已支援方法有原 Checker 已核准 int 局部時在最後 `return helper(...)` 真進普通同步純 int helper、先求實參、局部清理與 BorrowTicket 歸還；M2 已支援真 `if(bool)` 選枝及提前 Return self.int／Copyable int 常值／加減、選中葉可先寫入 self.int。

**尚未接通**：方法 `if flag { return helper(3,2) } return self.value` 的 true 葉雖經原 Checker `method_return_type` 靜態型別／借用安全檢驗，方法 `method_writes` 並未為直接普通 `Call` 建立可供私有執行的原 `TypedHIR`；M2 `method_branch_return` 也尚只接受原 Lexer int 字面或 self.int。這使兩個已核准控制位置無法真正共用普通函式呼叫工作圖。

## 原 Checker 唯一來源：只補完整 HIR 證明，不發明語意

- 新 `safety_checker.rs::method_branch_checked_pure_helper_return` 只在**方法提前 Return 已經由原 `method_return_type` 簽發合法型別後**，辨識 `TermKind::Call`、未 await、單一同步普通 helper、`int` 返回、零至多個原 Parser 真 `int` 形參、形參名非 `self` 且唯一、函式本體單一 Return 並只使用自己的形參／Lexer int／Group／BinaryInt(+|-)，所有 Call 實參只允許原 Lexer 整數或純字面加減樹。通過後**重新使用原 `self.evaluate` 與原 `Scopes` 真生成附原跨度的 `ScalarHIR`**，不可自行新增 TypedHIR 或以文字猜測名稱。
- 未能完成上述嚴格白名單的普通 Call 不獲得此額外 HIR；原 `method_return_type`、Borrow／Move／self borrow 模式、原 Parser AST／Token／MethodSafety.checked_returns 權威一律不動。bool 條件仍只能原 M2 支援的 Lexer 真 bool 或單一原 Checker bool 形式參數，不把整數轉為 bool。
- `PreparedPrivateSelfMethod::prepare` 只在原 if true 最後的 `StmtKind::Return` 是 **整筆 `TermKind::Call`** 且 `PrivateScalarReturnExpr::from_checked_bindings` 真取得同一原 Checker TypedHIR 時，才以 `private_self_matches_helper_call` 再次核對原普通函式名、完整 `int` 形參與 `DeclarationId`、未 await 以及純 int 引數工作圖。封存為現有 `PrivateSelfIntReturn::CheckedScalar(Call)`，由原 `matches_source` 再次重編逐欄比對。
- **原 M2 分支工作圖不改變**：保留原 if/else 及 nested 分支、self 欄位寫入的 true/else 安全證據和最終回傳選擇責任，不擅自支援分支內局部、任意 helper 運算嵌入、非 Copyable str Move/Borrow、await、遞迴或任意嵌套普通函式。這是有限的 M3 真 CFG 出口閉合子集，不是新語法核准。

## 真動態時序與錯誤路徑

`execute_with_fault` 仍在真正取得原唯一 `self BorrowTicket` 後、觀測真 bool 條件並選定唯一 if 葉，再依 M2 原 ExclusiveWrite `BorrowFact` 必要性只在選中 true 葉執行已核准 self.int 寫入。之後才由 `selected_calculation` 選中 `CheckedScalar(Call)` 的同一 B4/M3 helper 執行器。所有實參先依原 Lexer／Checked int 工作圖在 Caller `parameter_frame` 求值，**選不中的葉不求值、不 Enter helper、不報未達溢位**；求參失敗不能假造 helper FunctionEntered。真正進入後 `Returned` 或唯一 `UnwindStarted` 與 `FunctionExited(false)` 在內層工作圖完成，再由外層 M2/R05 清理／歸還原唯一 self 票據。

## 八項不重複原 Rust 真來源與必要 CI

新增 `src/struct_stage/g18_b4_m3_if_selected_helper_return_tests.rs`、`tools/核對G18-P18.4-B4真if選中helper返回.py`：
1. 真 bool 形參 true 葉呼叫原 Checker 純 int helper 返回 5，先子框架退出再還票；
