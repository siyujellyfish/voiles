# P13.5 Copyable／資源型別正反來源正式驗收證據（2026-10-30）

> 原始條文：加入可複製與資源型別的正向／負向案例。本次只簽核 P13.5 所需來源案例與代表性私有資源模型，不等於 P16.1～P16.6 的執行期全功能驗收。

## 類型範圍（不得擅定其他型別）

- Copyable：int／bool／float、所有欄位皆 Copyable 的巢狀結構。
- 非 Copyable 資源：str（單一持有者 UTF-8 緩衝區）、含 str 的巢狀結構。
- 已核准未決：list／dict 各自 Undecided，不得假冒完成容器實際來源／執行期或永久不可複製。Optional 及其他未定能力保持 Undecided。

## 正反案例清單

| 領域 | 合法正例 | 必須拒絕的負例 |
|---|---|---|
| Copyable | int／bool／float 多次隱含複製與賦值；巢狀全 Copyable struct 整值複製；方法／函式使用獨立值 | 未初始化、已移動的來源不得讀取或複製；賦值型別不匹配 |
| str | 新建獨立文字常值；具名整筆 `.move()`；函式及方法參數明確移交與獨立 str 回傳；移動後重新初始化 | 既有名稱隱含複製；移動後再次使用；借用中移動、別名偷變成所有者 |
| 巢狀資源結構 | 包含 str 的 struct 與多層結構可合法整筆 move | 多層資源結構不可隱含複製、不能移動個別欄位，移動後原名稱不可再使用 |
| 部分初始化 const／var | var 依 S07 完成全部欄位後整值可用；D02-A const 值仍可表示部分初始化但不能冒充完成 | 缺欄位的整值讀取、複製或移動拒絕；const 不能藉欄位寫入補完 |
| 候選執行期資源模型 | OwnedStrRuntime 真實 UTF-8 單一所有者、轉交後一次釋放；StructInitialization 具名／預設值清理切點 | 重複釋放／洩漏／非法覆寫／部分失敗清理順序負例在內部測試通過；正式 P16 仍須來源橋接與全部事件驗收 |
