# 公開語言缺口逐批驗收

## 純量延後初始化與字串返回

依 I05-A，函式區域 var int、bool、float 可先宣告。讀取時每條可到達該處的路徑均須已成功寫入同一個繫結，右值先於寫入檢查。分支中已返回的路徑免於合流。迴圈按可能零次處理，例外處理區塊以進入 try 前確定的初始化狀態開始檢查。此批單獨驗證 Copyable 純量。

同步 str 返回函式可使用 bool、float 形參。布林與十進位皆嚴格按形參型別驗證；沿用既有純量槽和字串所有權移交。可從條件分支返回新建字串。

驗收命令為 `python3 tools/核對公開語言缺口.py 建置好的CLI`。每例走 check、run、build、pack，成功建置後實跑兩種產物。

字串借用、原始位元組與數值邊界還會執行 tools/核對M7字串.py、tools/核對M7標準庫.py、tools/核對M7十進位.py。方法與例外另由 tools/核對M7結構.py、tools/核對M7例外.py 驗證。

## 動態半開區間

公開 for 的左右端點接受 int 運算式，進入迴圈時從左至右各求值一次。迴圈本體寫入原本的上界變數時，當次迭代仍使用已保存的上界。

## 一般函式的 none 返回

同步函式可宣告 `->none`，明確寫 `return none` 或轉回其他同型函式的結果。呼叫者可直接寫獨立呼叫語句。入口維持 `fn main()->int`；none 呼叫結果不可當作整數、條件或相等比較的運算元。

## 整數算術與比較

int 同型運算維持 i64。乘除、整除與餘數先於加減，次方右結合且先於一元負號。相容決策為同型 int 的 / 朝零截斷，// 向下取整，% 的非零結果與除數同號。負整數指數、除以零、結果溢位走既有 EvaluationError。整數支援相等與大小比較。依 D05-B，區域變數的 return i+=n 先檢查寫入權限，右值與加法成功後才寫回並返回。

## 原始位元組

read_bytes(path) 一次讀完整檔案，回傳 list[int]。每項保留原始位元組 0 至 255，連無效 UTF-8 也維持相同索引。可用 len 與 with 讀取或移交整份清單。

## 字串參數的預設借用

同步呼叫以具名字串提供唯讀形參時，傳遞同一份 UTF-8 資源的共享檢視。返回呼叫端後可繼續讀取原持有者。函式體若明確移動該形參，呼叫須提供可移交的值。原生產物以共享參考或持有值表達這兩種傳遞。

## 結構清單跨模組傳遞

list 可使用可見的具名結構作為元素。append 以建構式建立完整元素，with 區塊可讀其公開純量欄位。傳參及返回以原始宣告模組與結構身分比對元素型別，整份清單透過 .move() 移交。

## 純量方法多載

依 S20，以方法名稱及形參型別的順序區分簽章。同簽章即使返回型別不同也拒絕宣告。呼叫按實參型別選擇唯一方法，再核對結果型別。更新自身欄位的方法要求可寫接收者。

## match 與 case

採用既有圓括號與大括號風格。match(expr) 僅求值一次，按來源順序比對同型的 int 或 bool 常值。case _ 為末尾預設分支。重複模式與不可達分支會在檢查時拒絕，分支的資源與初始化狀態沿用 if 合流。

## 有限 decimal64 乘除

同型 float 支援十進位乘除，求值以整數係數與指數完成，在最後一次捨入至最近值、半數取偶。除以零與超出有限範圍沿用 EvaluationError。

## 具型別例外的訊息

except 類別 as 名稱 可取得此次失敗的繁體中文訊息。訊息是處理區塊內的唯讀 str，外層同名綁定會在離開時恢復。既有 except 類別寫法仍可使用。

D05-B 的模組計數器亦接受 share int。同一模組可透過賦值或 return i+=1 更新，其他模組可讀取計數器並呼叫更新函式。

特殊值採明確的 float.nan() 與 float.infinity()，負無限值使用一元負號。NaN 與自身不相等，正負零相等且格式化保留負號。有限值的除零及超界處理沿用既有執行錯誤。

## 已裁決的所有權與非同步邊界

依 VB14-01-A，對既有借用別名再建立 .borrow() 仍須拒絕。預設字串傳參允許從原持有者建立僅涵蓋同步呼叫的共享存取。依 D18-02-E1-A，async 採延遲啟動與直接 await；背景工作、工作控制代碼及跨 await 保留有效借用屬另一項設計變更。
