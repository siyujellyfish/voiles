# P21 模組裁決

每一份 .voil 來源是一個模組。用 `import a` 綁定模組，透過 `a.name` 引用公開名稱；`import name from a as local` 綁定指定公開名稱的別名。底線前綴的宣告僅限模組內可見。

模組解析以入口檔目錄為根，`import a` 對應該目錄的 `a.voil`。缺檔診斷需保留匯入位置與嘗試開啟的路徑。

先檢查整份依賴圖，再依相依順序初始化每個模組一次。獨立依賴按來源中的匯入順序排列。循環須在執行前回報完整循環路徑。P20 的共享字串僅由其宣告模組寫入。

## G21 多檔執行驗收範圍

私有入口使用真實入口路徑、依賴圖與各檔 AST。每個模組在整份圖通過檢查後依序初始化一次。跨模組直線函式支援 int 返回、可見共享字串的讀取、整筆結構顯式 move 至同步函式、const／var 欄位的常值建構及零參數唯讀 self 整數欄位方法。結構參數按宣告模組與型別身分核對。跨檔移動與故障退出使用與共享字串相同的真資源帳。公開 CLI、多參數結構轉移、任意方法本體與通用多檔編譯留待後續。

`tools/核對G21驗收.py` 逐名執行六組正反測試；`tools/核對P21來源登錄切片.py` 驗證來源身分與快照。另以完整 Rust 測試及既有 G17–G20 工作流程檢查回歸。
