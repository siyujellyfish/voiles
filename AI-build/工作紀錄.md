## 2026-10-23：新版本語言草案與函式可見性決策

- 使用者宣布舊語言規格暫時捨棄，改採新提出的 20 項初步規劃。
- 補充確認：例外關鍵字為 `except`；一般借用於最後一次使用後歸還、函式借用至執行離開函式作用域；字串插值參考 Python f-string / t-string；UTF-8 雙層索引；`Optional` 同時表示聯集與缺失值。
- **函式可見性決策**：採方案 A，一般 `fn` 預設公開；函式識別字以 `_` 開頭即為內部函式，其他模組不可呼叫。此決策亦涵蓋 `async fn`。
- **新增方法可見性決策**：`struct` 方法採相同方案 A，方法預設公開，`_` 前綴方法不對外部模組公開；不延伸到欄位、變數及結構名稱。
- **模組內部存取決策**：採方案 A，`_` 前綴方法可由相同模組其他函式與結構呼叫，但不可跨模組呼叫；方法具體定義及接收者語法仍未決。
- **結構欄位存取決策**：採方案 B，`struct` 方法內必須使用 `self.欄位名稱` 明確存取自身欄位；`self` 接收者的宣告、所有權、可變性、借用與生命週期仍逐項待確認。
- **結構方法位置決策**：採方案 A，`fn` 方法與欄位均直接宣告在 `struct {...}` 內，不另設 `impl` 等實作區塊；此決策不決定 `self` 的接收者與資源安全規則。
- 已將舊版語法示意與新版衝突之處從有效規格中標為廢棄／待確認，舊版 Phase 的語法相關敘述須以新版規格為準。
- 僅更新文件，不宣稱已實作或驗證語言功能；分支及合併狀態依實際 GitHub 結果記錄。
