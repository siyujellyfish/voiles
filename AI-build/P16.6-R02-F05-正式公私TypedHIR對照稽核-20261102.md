## 已實作

- `struct_stage/parity_tests.rs::public_check` 改以目前正式公開 `check_file` 同一順序執行 `P09::resolve_with_facts → P10::check_with_names_and_hir → P11::check_with_typed_hir → functions::check`。不能再透過 P10/P11 的舊獨立入口跳過 HIR 證據交付而產生偽陽性交集測試。
- 對一份真實合法交集來源，以**實際公開 P10 HIR**及**私有整份 Checker 全部成功後的 HIR**對照 bool if 條件、具名 int return、int 初始常值及末尾 return int 的原始位元組半開來源跨度與具體型別。
- 核對公私 `DeclarationId`、int/bool 型別與 var/const 權限一致；來源起點相同但終點竄改不能冒充已驗證運算式。

- 保留原有 19+30 P01 來源基準、公開與私有 P13～P16 權限隔離、UTF-8 診斷及所有權／借用資源回歸。
