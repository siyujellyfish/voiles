# P18-C｜私有條件分支真提前返回與資源退出（2026-11-04）

> 非公開 P18-C 工程子批，**不是 G18/P18 正式驗收**。以主線 `cc79dbdd7c4773e4b4ee2a327c33c0046cf666c9`（PR #507 合併）為基底。

## 真實施工

在既有 P17-C／P18-B 私有 `str` 來源檢查及真 `OwnedStrRuntime` 上加入已核准的 `return int` 作用域退出。仍由同一 `verify_source_with_ability` 真 Lexer／Parser／Checker／SafetyPlan 預先驗證：選中的 `if` 或 `else` 區塊，僅允許依來源順序的 `var/const str` 常值宣告與**最後一筆明確整數常值返回**。無其他控制流程、任意求值或方法借用。

`PrivateStrBranchBody` 儲存真已驗證的局部字串與可選的整數返回；`execute_str_literal_branch` 使用真正 `enter_scope/declare/leave_scope`，**無論是否 return 均先退出內層**，再將返回值上交外層。外層 `execute_with_fault` 因有成功返回不再執行後面的語句，隨後 `finish` 真正釋放仍活躍的外層持有者；失敗退出同樣保留清理責任。未選中的分支不產生任何 ResourceEvent。來源身分與原 Checker 一致，不以靜態 CleanupObligation 捏造執行事件。

## 新增五項真 Rust 正反證據

| 類型 | 應有結果 |
|---|---|
| true 分支兩筆 str 後返回 | 真實兩筆內層逆序釋放，最後釋放外層 |
| false 分支不執行，else 返回 | 只建立被選中的 else 資源，返回值正確 |
| 具名 false 分支 return 不執行 | 走到外層 return，分支零資源事件 |
| 具名 true 分支返回 | 由執行期 DeclarationId 取得條件、真返回並清理 |
| 動態返回式未接通 | 即使原 Checker 支援，執行切片仍拒絕 |

**處理過時負例**：原 `p18_b_分支內返回或巢狀資源控制尚未驗證必須保守拒絕` 隨本批新增已核准整數常值返回而失效，改為 `p18_b_巢狀資源控制未驗證仍必須保守拒絕`，實際使用真巢狀 if 資源案例確認保守拒絕；不刪除其他已完成驗收與 F00 凍結測試。

`tools/核對P17私有字串切片.py` 由前 22 項擴至 **27 項**內部真來源案例；只驗原 Rust 全量 `--list`，不重跑核心，維持 G6 真驗收與原 P01 CLI 不變。
