# G18／P18.1-F2 原始義務閉合證據（2026-11-13）

## 驗收邊界

F2 只對原始契約「int/bool、已核准 str 與混合函式參數依原 Parser 順序求值；所有權返回、借用歸還、函式與局部作用域正確退出」結案。屬於 F3 呼叫位置及 F4 可達函式圖的所有變體仍不在本單項之內。其他階段 P18.2～P18.6 亦無提前核准。

原 Lexer／Parser／Checker／TypedHIR 仍為靜態來源唯一權威；真正 OwnedStrRuntime 和 BorrowSafety 為事件唯一權威。拒絕非法已初始化 var str 接受函式返回覆寫、跨 await 活躍借用及其他未核准語意。
