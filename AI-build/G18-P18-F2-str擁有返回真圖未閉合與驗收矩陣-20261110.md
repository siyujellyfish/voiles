## 原 P16 真資源的五項正反證據

`src/owned_str_runtime.rs` 的五項真 Rust 資源測試，由 `tools/核對G18-F2資源返回接收權限.py` 逐項 `--exact` 驗收：
1. Returned(str) 接入 const str 保留同一資源 ID、同一緩衝區位址，後續覆寫明確 ImmutableBinding。
2. 返回接入 var str 可以原子覆寫，舊 ResourceId 只釋放一次，新值有新的唯一 Created ID。
3. 接收端同名拒絕不能丟失返回的 OwnedUtf8；回傳錯誤含完整資源，正式 release_detached 後與原既有持有者各自正常清理。
4. 兩層連續返回相同 OwnedUtf8，兩次 Returned(同 ID)、零重新配置、最後唯一 Released(同 ID)。
5. 返回值在呼叫端尚未成功接收就遇到失敗，需由 return 值持有人 release_detached 真回滾；宿主 Rust Drop 不等於 voiles 真資源退出。

**這五項只驗證原有 P16 真資源原語與其正確權限，尚不是原 Checker→TypedHIR→普通函式工作圖的 str return 真執行。** 不得因本批 Gate success 就將 F2 Closed。
