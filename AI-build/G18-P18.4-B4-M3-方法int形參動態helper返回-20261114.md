## 唯一靜態身分與真動態求值

- `safety_checker.rs::method_branch_checked_pure_helper_return` 改從原 `method: &Function` 精確辨識參數名稱；允許 `TermKind::Name(n)` **僅在原 Parser 方法真形參 `n:int`**、不遮蔽 self 且合法已核准時作純 Copyable int 實參，並保留 Lexer 整數、Group、BinaryInt(+|-) 的白名單。所有 bool／str／Move／Borrow／FieldRead／Nested Call／await 與任意 Expr 依舊拒絕，不新增型別或所有權裁決。
- 為使 `self.evaluate` 真簽發 `ScalarHIR`，只用與 `method_checked_int_locals` 相同原已核准 `Scopes` 構建契約：對每一個原 `int` 形參，使用唯一 `DeclarationId(parameter.declaration_start)`，`Binding::new`／`ValueSlot::initialized(CopyPermission::Allowed)`，及原 `record_declaration`；bool 形參不冒充 int，`self` 不能被混入。仍由正式 `self.evaluate` 判定準備時型別與可用性，沒有另造 TypedHIR、已簽發結果值或預先執行 helper。原 `method_return_type` 與 `VerifiedMethodSafety`／借用權限仍是預先關卡。
- 受限 Runtime 不另建任何新 int evaluator：`private_self_checked_helper_return_leaf` 仍從原 `ScalarHIR` 與 `method_bindings` 重建同一 `CheckedScalar(Call)`。真執行方法已取得原 BorrowTicket 且在目前 `parameter_frame` 完成原方法參數綁定後，先求完整 Caller `n` 或 `n+3`，成功才 Enter 普通函式子框架；helper 真運算完成才 Return/Exited。Caller int 溢位時不得 Enter helper；helper 本體溢位先退出內層、唯一 Unwind，再外層歸還自借用票據。
- `method_writes` 及 `check_method` 兩處都調用**相同 helper HIR 生成權威**，因此原 M2 `if(true)` 選中 Return 可以讀取方法合法 int 形參；未選中葉完全零求值。此批**不放開 bool 與 int 混合新方法簽章的受限 Runtime**，也不開一般非 Copyable 資源與動態別名逃逸。
