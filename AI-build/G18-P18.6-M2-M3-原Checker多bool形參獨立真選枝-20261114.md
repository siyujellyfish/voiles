## 靜態權威與真動態執行

- 原 Lexer／Parser／Checker、S20 方法完整形參數量和逐位置 int/bool 型別唯一性、`VerifiedTypedMember(Parameter)`、原 `plan.members` 與 `DeclarationId` 是唯一靜態授權來源，不另設第二套重載或轉型推導。
- 在準備階段依**原 Parser 每個實參位置**保存 `Vec<(usize,bool)>`；只接受真 Lexer `true`／`false` 且其原 token 半開跨度吻合的 bool 實參。每筆再依同位置方法原形參建立唯一 `DeclarationId`，保存 `Vec<(DeclarationId,bool)>`，不靠同樣真假值推斷是否為同一個形參。int 不更動現有 `PrivateScalarReturnExpr`／`TypedHIR`／main Caller 真求值，所有尚未完成的 int 實參仍在取得 self BorrowTicket 前處理。
- `if(gate)` 與巢狀 `if(branch)` 各自先用**原 Parser 方法形參名稱、型別、DeclarationId 與 Lexer Name token 精確匹配**，才從其獨立 bool frame 取得動態值。沒有任何 int→bool／bool→int 隱式轉換，未選中分支不求 helper 參數、不執行原 self.int 獨占欄位更新。
- `matches_source` 以原來源真重編比較**整份** bool 形參向量；換參數順序、竄改真假值、少掉一個 DeclId 不能從同值猜測中偷渡。動態執行 `bool_parameter_frame` 逐一插入唯一 ID，重複 ID 立即拒絕，原 M2 巢狀選葉、原 B4/M3 純 helper、R05 BorrowTicket 單張借還／內後外 Unwind 仍共用同一執行路徑。
- 本批**只接通原 Checker 核准的純 Copyable bool/int 實參**，不擴張 str／Move／Borrow／ResourceId、任意組合條件式、async、自動並行或新容器。S20 既有方法多載唯一性與 F00/G6/G17 凍結不變。
