# G18／P18.1-F2：原 Lexer 字串常值直接作 str 實參

## 原 Checker 合法邊界
原 Checker 的 P15.6 允許非 Copyable 形參接收 `TermKind::Literal("str")`，它不是任何具名來源的預設借用，也不能將 UTF-8 文字隱式 Copyable 化。此前私有動態工作圖只支援具名 Borrow／Move 與巢狀 str-return，對字面直接傳參仍保守 Unsupported。

## 本批變更
- 在原 Parser／Checker 來源驗證後，以 `PrivateScalarCallArgument::LiteralStr` 保留原 Lexer 常值，僅當工作棧真正到達實參時，呼叫 `OwnedStrRuntime::create_detached` 建立唯一 OwnedUtf8。
- 新增 `StrLiteralTemporaryCreated(ResourceId)` 動態事件；真 trace 要求它緊接真 `Created(id)`、該 ID 仍屬本框架、尚未綁定其它 DeclarationId、不得重複宣告。擅自將待交參字面偽造普通具名持有者亦須拒絕。
- 前批的跨框架 `StrTemporaryTransferred`、`OwnedResource::Moved` 與原 Checker 目標 `ResourceOwnerBound` 共用唯一資源身分；不重新配置、隱式複製或杜撰來源 DeclarationId。
- 同一套逐框架 `pending_owned_returns` 處理「字面已建立、後序實參溢位」及「字面已傳入、被呼叫函式故障」，資源以真 P16 ledger 各釋放一次。
- 原子接收原語更名 `accept_temporary_argument_as`，可處理原 Lexer 直接字面與上一批真 str-return 臨時值，語意仍限核准的同步直接 await 邊界。
