## 真實未閉合的 F2 範圍

既存 `src/struct_stage/execute_call_scalar.rs` 的普通函式準備器明確只允許 `result_ty == "int"` 的可達函式，而原私有 Checker 能核准合法 `fn ready(flag:bool)->bool { return flag }` 宣告。現有 Rust 已用「未使用的 bool 回傳函式不得妨礙 int 主工作圖」證明其應當隔離，而非證明其可達呼叫已執行。因此 **F2 仍 OpenEngineering**；不得從此九項新增測試推論完整 bool 返回和其他已核准返回組合已通過。後續須先確認原 Checker 允許的可達 bool 返回使用位置，將其納入原 TypedHIR 與動態值表示，拒絕任何不合法的 bool/int 隱式轉型，再補資源和失敗矩陣。

**合併規則**：最新 PR HEAD 三必要工作完整成功、作者/base/mergeable 符合後才 Squash merge；新 main 同一 SHA 再成功才把此九項子集視為已完成工程。正式原 P18.1 仍 SubsetVerified；F2 未達真正全部義務前不能 Closed，F3 與 V2 等下一驗收階段不得提前宣告開始。
