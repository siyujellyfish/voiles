# P16 持續存活字串結構整體資源責任（2026-10-30）

> 本批擴充真正的 Rust String／UTF-8 單一持有者模型，補足先前 build_string_struct 在「成功後立即清理」之外的持續資源責任；不建立 P17 直譯器，也不以這十項模型測試提前驗收 P16.1～P16.6。

## 既定核准邊界

- VA16-01-A：真實 UTF-8 String 只有一名持有者，整筆 .move() 不建立第二份所有權。
- VA16-02-A：完成初始化的資源依逆序清理，返回時資源責任從被呼叫端交給呼叫端；不依賴 Rust 宿主 Drop 推定語言順序。
- VB16-01-A：建立結構時先依具名引數來源書寫順序，再依宣告順序求值未覆蓋預設；被覆蓋的預設不求值。
- S19：結構全欄位須 Copyable 才可整體複製；內含 str 非 Copyable 者不可隱含複製。S21：禁止只移動單一欄位。
- F01：const 欄位必須有預設；未初始化 var 欄位不能被視為已配置資源。既有 P13～P15 靜態安全入口不擴張。

## 新增實作

- owned_str_runtime.rs 對原有 Created／Moved／Returned／Released 身分帳簿新增僅供內部結構欄位的真正 OwnedUtf8 建立、顯式整體轉移、返回與釋放接口，所有字段資源持有權透過非 Clone 的 OwnedUtf8 保留。
- struct_initialization.rs 新增 OwnedStructRuntime，成功建立後將已求值欄位持有至擁有者真正退出作用域；建構按既有 struct_eval_plan 先完整預檢再分步配置。建構途中若失敗，僅釋放本次已成功取得欄位並保持其他既有結構持有者完整，釋放次序為真正完成初始化逆序。
- move_whole 先核對目標同作用域名稱及原來源仍持有資源，再原子移轉所有欄位的 OwnedUtf8，舊來源設為失效；不可只移動欄位、不可對非 Copyable 字串結構隱含整體複製。
- return_whole 以相同資源身分逐欄位發出 Returned 事件並交給呼叫端；離開原函式作用域不得釋放已移交資源。accept_return 在撞名失敗時交還整筆所有權供呼叫端繼續處理或以 discard_return 明確反序清理，不依賴錯誤返回時宿主隱含 Drop。
- 字串結構內部欄位及實例身分、欄位順序、部分初始化、作用域清理及返回皆是 Rust 私有證據模型，不代表已具備將所有 .voil struct 語句直接執行的通用執行器。

## 十項受限資源模型正反驗證

1. 成功建構後資源維持存活至最終離開作用域，精確反序清理。
2. str 結構整體移動不拷貝原 UTF-8 緩衝區，原來源失效，所有資源仍只釋放一次。
3. 具名／預設每一階段失敗僅逆序回滾此次新增欄位，其他已存在結構仍可讀。
4. 重名或非法具名求值計畫在配置之前拒絕，不消耗任何來源。
5. 未提供也無預設的 var 不得當作已執行失敗注入步驟，不造假資源。
6. 內層結構先清理；退出後外層持有者仍有效，最後才清理外層。
7. 函式整體返回後原函式作用域不能提前釋放，最終呼叫端清理。
8. 返回接收者名稱衝突不遺失已轉交資源，顯式失敗清理恰一次。
9. 含 str 欄位的結構非 Copyable，隱含整體複製永遠拒絕。
10. 非法第二次移動與目的撞名不得破壞既有來源或產生第二持有者。
