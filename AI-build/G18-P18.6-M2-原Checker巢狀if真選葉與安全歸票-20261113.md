# G18／P18.6-M2：原 Checker 同步 self 巢狀 if 真選葉與借用安全退出（2026-11-13）

## 工程起點與原先拒絕原因

以 PR #757 合併後、主線同一 SHA 三必要 CI completed/success 的 `main d5d814dc2d625a427fb70437bae4e1b197b86d33` 為基準。目前原 Checker 的 `method_writes` 已遞迴解析合法巢狀 `StmtKind::If`、核對條件 bool 型別及每個 Return 的 Copyable 資源規則，並將各可達 return 的原 `NodeSpan` 寫入 `VerifiedMethodSafety.checked_returns`。但同步 self Runtime 只看首層 if 真葉的直接 `Return` 或 `FieldAssign → Return`，對原 Checker 合法的**內層 if** 一律 Unsupported，不能驗證未選中巢狀控制邊、真 Return 與故障歸票。

## 真控制圖、安全邊界

本批只接通以下單一、可靜態證明的原 Checker 子集：
```voiles
struct Counter{
var n:int = 7
fn read(flag:bool)->int{
if(flag){
if(true){
return self.n+5
}else{
return self.n
}
}
return self.n+1
}
}
fn main()->int{
var owner:Counter = Counter()
return owner.read(true)
}
```

- 外層條件仍是原 bool 形參或 Lexer bool 常值；內層條件先限**原 Lexer bool 常值**且兩葉各只有一條原 Checker 已核准的 Copyable return。內層 true 可以 `return self.n` 或 `return self.n +/- int`，內層 else 只能 `return self.n`；不開放巢狀寫入、一般函式呼叫、Move、Borrow 別名再借或 async。
- `method_nested_branch` 只保存內層 bool 常值與原內層 else Return 的 `NodeSpan`；內層 true Return 位置及安全計算沿用同一原 Checker 已編譯的 `method_branch` / `method_branch_return`。須同時在原 `VerifiedMethodSafety.checked_returns` 找到兩葉的真 ReturnSpan，所有 bool 常值用原 Lexer Keyword 的**同一半開 UTF-8 跨度**核對。來源被竄改則 `matches_source` 重新用同一原 Checker 編譯後拒絕。
- 真 Runtime **先依外層 bool 選中 true 才允許檢查內層條件**。若外層 false，直接執行原最後 return，內層条件旗標維持 None，不偽造 nested Return 事件；若外層 true，依內層 bool 返回原 self.int 或真執行已核准的整數加減。未選中葉算式可能溢位仍不得提前求值。
- 整個方法仍在**同一張**原 BorrowSafety 真 self BorrowTicket 之下。所有正常與錯誤路徑沿用原 `PrivateSharedCallExitEvent`、`UnwindStarted` 和逐框架退票；`nested_branch_checked`／`expected_nested_branch` 只追蹤**實際是否走到**內層，不在 prepare 階段預造動態事件。此純 int 子集不允許任何假的 ResourceId 或 UTF-8 ResourceEvent。

## 八筆真來源獨立 Gate

`src/struct_stage/g18_m2_nested_self_if_tests.rs` 與 `tools/核對G18-P18.6-M2原Checker巢狀if真控制.py`：

1. 外層 true／內層 true 返回 `7+5=12`、唯一 Returned、真還票；
2. 外層 true／內層 false 跳過 true 葉算式，返回當前 self 欄位 7；
3. 外層 false 不走內層 if，執行最後 `self.n+1=8`；
4. 外層 true／內層 true 已到達溢位，受控 `IntegerOverflow`、Unwind、零成功返回；
5. 內層 false 或外層 false 避開不可達的溢位算式；
6. 方法入口故障時不得虛構內層條件／Returned，原借用仍真歸還；
7. 竄改內層已編譯 bool 常值或 false ReturnSpan，須執行前 `SourceChanged`；
8. 原 Checker 拒絕內層非 bool 條件與不存在 self 欄位，不能由 Runtime 代為放行。
