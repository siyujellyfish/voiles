# P16.6-R02 F04／R03 F11｜私有 Checker 宣告權威正式遷移 TypedDeclaration（2026-11-01）

> UTF-8。此批將原本私有 Checker 的另一份 `(String, bool)` 資源宣告表直接替換為與公開 P09→P10→P11 共用的 `common_ir::TypedDeclaration<T>`。不擴張 P13～P16 語法、不替代完整 CFG／資源計畫，也不提前驗收 R02/R03。

## 本批實際實作

- 私有 Checker `recorded_declarations` 從 `BTreeMap<DeclarationId, (String, bool)>` 升級為 `BTreeMap<DeclarationId, TypedDeclaration<String>>`。Checker 成功驗證各種宣告後直接寫入真正的來源身分、型別名稱及 var／const 權限，與其現有 `Binding::semantic_declaration` 使用同一結構。
- `VerifiedDeclarationFacts::by_source` 同步持有完整 `TypedDeclaration<String>`，不再需要由另一份只有型別與可變權限的二元組反覆猜測 `DeclarationId`。
- `typed_declaration` 是私有資源橋接讀取已驗證宣告的統一入口，只有 map 鍵與物件記錄的來源身分相等才投影 `TypedDeclaration<&str>`；`matches`、`verified_direct_move`、`verified_named_return`、`verified_field_write` 都直接消費此共同資料格式。
- `evidence_is_consistent` 先稽核**每一筆**宣告的 map 鍵與來源 ID 完全一致，然後檢查直接轉移兩端型別、具名返回來源、欄位寫入接收者及 var／const 安全權限；有任一來源不一致，整份私有安全證據拒絕交付 P16 橋接。
- 增加真實多欄位結構 Checker 證據正例與篡改表鍵／來源身分、型別冒充及不合法資源移交拒絕回歸；沿用既有所有權／借用／P16 資源驗收測試。

## 尚未完成與合併閘門
