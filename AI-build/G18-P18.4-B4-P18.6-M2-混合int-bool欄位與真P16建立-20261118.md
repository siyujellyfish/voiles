# G18／P18.4-B4／P18.6-M2：原 Checker 混合 int／bool 純值欄位與 P16 真持有者（2026-11-18）

## 基線與本批責任

基於已 Squash merge 的 `main 66a74c426a46650e5bd43ecc0bc806e7481cab2b`，同 SHA 的文件與工作紀錄、Rust 前端建置、Rust 獨立架構測試三項必要檢查均 `completed/success`。#837～#840 已接通原 Checker 允許的 main owner.int 寫入、自讀、局部讀值、方法實參與額外多 int 預設欄位；此批只修復多欄位結構內**其餘直接預設 bool** 遭私有方法子集錯拒的缺口。

原六 Phase 仍 `P18.1～P18.3 Passed`、`P18.4/P18.5 SubsetVerified`、`P18.6 Incomplete`；原 26 義務仍 `17 Closed / 9 OpenEngineering`。B4、T1～T4、M2、M3、A1、A2 不提前 Closed。

## 唯一原 Lexer／Parser／Checker 與窄範圍

1. 原第一個 `int` 欄位仍是唯一已接通的方法 `self` 寫入／讀取目標，原 P13 獨占 `self` 借票與 `call_borrows_at` 事實不變；不為額外欄位建立新方法 API 或借用能力。
2. 對額外每一欄位，用原 `VerifiedTypedMember::checked_private(NodeRole::Field, declaration_span, name_span, type_span, mutable)` 與 `verified.plan.members` 比對；只允許 `int` 或 `bool`，並要求同源原 Parser 獨立直接預設值及**精確原 Lexer Token 起迄座標**：`Integer(raw)` 或 `Keyword(true/false)`。預設數字仍以原共同 i64 轉換，布林只由真 ScalarLiteral::Boolean 取值。其他 str／Move／借用／複合預設、無預設值一律保守拒絕。
3. 舊 `additional_int_fields` 改成保留**原欄位先後順序**的 `additional_copy_fields: Vec<(name, PrivateSelfAdditionalCopyValue::{Int,Bool}, immutable)>`；用一份資料保存 int／bool，以免先建所有 int 再建 bool 改動原 Parser 欄位建構順序。值相同但名字不同的欄位不能合併；bool 不可誤投影成 int。
4. `matches_source` 以 fresh 原 Checker 重建完整來源，對封存原 `additional_copy_fields`（名字、型別值、可寫屬性及次序）逐筆嚴格比對。改 bool 值、變型 int/bool 或 const 可寫性均須在實際 P16 建構／BorrowTicket 取得前 `SourceChanged`。
5. 真 main 首筆 `MixedStructRuntime::construct` 由同一原 owner 建立第一 int 與額外 int／bool `MixedFieldSpec`，每筆對應 `ScalarKind::Int／Bool` 與 `SeedValue::Int／Bool`；不會創建 `OwnedStr`、不會產生資源事件，且方法本體的 SharedCallExit、HC14、R05 反向還票、V7 E1～E5 均不動。

## 原 Checker 真正反驗收

保留並更新既有 `src/struct_stage/g18_b4_m2_multiple_int_fields_self_tests.rs` 八項以及其獨立 `--exact` Gate；原「bool 保守拒絕」隨本批正式接線改為**原 Checker 接受且真建構 bool** 的正例，不刪除既有八項集合。

新 `src/struct_stage/g18_b4_m2_mixed_copyable_fields_tests.rs` 包含十一項：
- 真 `var bool = true` 與 `const bool = false` 分別建立並保留可寫身份；
- int／bool／int 混合宣告序、兩個相同 bool 真值但不同欄位身分；
- main 前序更新 int 後仍保持 bool 欄位，真 self 方法寫入安全；
- 方法故障下唯一自借還票與再次執行、零虛假 `OwnedStr` 事件；
- 封存 bool 真值、型別變型、const 可寫性三種竄改必 `SourceChanged`；
- 未接通的 str 資源及無預設額外欄位負例仍被拒絕。

`tools/核對G18-P18.4-B4-M2混合Copyable欄位真持有者.py` 先 `--list` 逐一核對十一項完整集合，再依原 `--exact --test-threads=1` 強制每筆 1 passed／0 failed／0 ignored；新增到必要 `.github/workflows/前端建置.yml`，不能只憑 Rust 測試總數採計。原 F00/G6/G17、R06/R07、S0 義務一致性與所有 G18 已驗證 Gate 不移除。
