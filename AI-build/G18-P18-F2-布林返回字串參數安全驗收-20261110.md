## 八項真正反驗收

`src/struct_stage/g18_f2_bool_str_tests.rs` 對照 `tools/核對G18-F2布林字串混合參數.py`：
1. const str 共享借用 + bool/int；真正 bool 返回後，BorrowTicket 歸還早於資源最終釋放。
2. var str `.move()` + bool/int；同一 ResourceId 真 Moved 與子框架唯一 Released，沒有假借用。
3. 同一 bool-return 呼叫同時借用兩個 UTF-8 來源，int/bool 交錯求值，兩張真票據各自歸還，資源反向釋放。
4. 先借用、後續 int 算術溢位：不得進入 bool 被呼叫者或產生 BoolReturned，原借用正常歸還。
5. 先確定 Move 意圖、後續 int 溢位：不得提前 ResourceTransferred，原持有者唯一清理。
6. 同一 bool-return 呼叫中，兩個來源各自 Move 與 Borrow，ResourceId/BorrowTicket 互不冒充。
7. 把 str 實參提供給 bool 形參，原 Checker 拒絕，不能自動轉型。
8. 把已核准 BorrowTicket 與真正 ResourceId 對應竄改，即使筆數平衡，真稽核也要拒絕。

獨立 Gate 先 `--list` 比對八個精確 Rust 名稱，再逐例 `--exact` 真執行要求 1 passed／0 failed／0 ignored。沒有 CI 成功之前，本批沒有通過；PR 最新 HEAD 三必要 success、合併 main 同 SHA 三必要 success 後，才將本批子集視為已驗收。
