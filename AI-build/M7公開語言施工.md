# M7 公開語言施工

P31 基線為 0.1.0-preview.1（來源 ec0a7911）。tests/m7/preview1.json 每列含完整來源、舊式單檔預期、模組預期、個別命令例外與成功值。以 python3 tools/核對M7公開能力.py 發行版CLI 重跑。每個來源跑 legacy、check、run、build、pack，後兩者成功後實跑產物。借用衝突與型別不符為必須持續拒絕的反例。額外的路徑、位置、跨檔及執行錯誤沿用 G22、P25、P27 案例。

| 施工 | 使用者缺口 | 自舉相依與既有依據 |
|---|---|---|
| P32 | 一般 int／bool 函式、具名引數、資料條件、短路、迴圈與轉移 | 語言規格第三、四、七節；私有 execute_call_scalar、P18 控制流程。公開直譯與原生須共用同一份檢查結果。 |
| P33 | 結構與資源、容器、Optional、字串完整操作 | 詞彙串列、語法節點與符號表；P19 容器與字串語意及 VA14～VA16。凍結的舊入口須維持相容。 |
| P34 | 原始檔案／UTF-8、引數、路徑、標準輸出與錯誤傳遞、程序呼叫 | 詞彙統計工具及未來編譯器驅動程式。套件及函式名稱屬新標準庫決策；基線 argc() 僅驗證名稱尚無提供。 |
| P35 | decimal64、插值／格式化、例外與直接 await 跨模式 | 依已核准精度、捨入、資源清理及 VB15-01-A。原生直接 await 與公開直譯已有落差。 |

規格權威為[語言規格](語言規格-v0.2.md)。各案例只代表所列形式，詳細私有驗收見 [M4](M4實作範圍與程式碼審查.md) 及 [M5](P23-P27原生工具鏈.md)。後續各批須提供新的公開能力測試，版本凍結矩陣始終對應 preview.1。

### P32 第一批

公開模組入口支援同步 int 函式的位置及具名 int 引數。具名引數按來源順序求值，再依參數名綁定；整數沿用 Copyable 規則。驗收含多檔匯入、逆序命名、巢狀呼叫、被呼叫檔的溢位位置及四種無效呼叫。bool、流程控制及迴圈仍需後續驗收。

### P32 第二批

公開同步純量函式可用 int、bool 參數和回傳，入口 main 維持回傳 int。條件需要 bool。採用同型 int 或同型 bool 的不等比較，優先級依序為加減、比較、and、or。and 與 or 依 D03 短路。區間沿用現有半開整數常值端點；break 與 continue 作用於最近一層迴圈。分支、迴圈與轉移沿用呼叫者的步數預算。本批測試透過公開命令編譯與執行，涵蓋逆序引數、動態分支、短路略過溢位、迴圈轉移、常數寫入及區域名稱離域。

### P33 第一批

沿用 P19 容器宣告、len、整筆 move 與 with 唯讀元素。函式最外層建立的常值容器，其內容可在編譯期確定；檢查器依繫結記錄持有者與移動後狀態，長度可折疊，動態索引在執行時檢查。int／bool 元素可在 with 內讀取，字串鍵採字面值。缺鍵與越界在 run、build 產物、pack 產物回報相同來源位置。Optional 常值可建立及查詢長度；候選縮限、可變內容與一般跨函式資源仍待驗收。

### P33 第二批

分支與迴圈的區域容器可在宣告所在作用域內整筆移動，依最近繫結解析遮蔽名稱。跨區域移動外層容器仍需路徑合流及借用證據。以四個公開命令驗證遮蔽後恢復外層容器、迴圈逐次建立與移動、離域讀取及移後讀取。

### P33 第三批

公開 with 讀取 Optional 元素時會先檢查鍵或索引，可在 if 中比較缺失或判斷候選。非缺失證明只授權同一繫結緊接的候選條件鏈，私有與公開入口共用該位置規則。0、false、空字串均保留原型別；缺鍵與越界維持執行錯誤。此批尚未開放候選值取用。

### P33 第四批

共享字串與借用別名支援以 int 區域繫結動態選取字素、UTF-8 位元組及覆寫位置。具名替換值須於執行時正好含一個字素；先讀取替換來源，通過目標權限與長度檢查後才修改。沿用正負索引與 Unicode 邊界，未宣告或非整數索引為靜態錯誤。本批將四入口容器、純量與字串驗收納入 PR 的 Rust 架構測試。

### P33 第五批

函式區域 str 可持有常值、獨立字素、字素替換運算結果或明確移動的緩衝區。單一 str 形參同步函式可接收具名或位置 move 實參，沿用同一 OwnedStrRuntime 將原 ResourceId 移入新框架。正常返回與索引失敗均釋放一次；跨檔測試核對實際事件順序與來源。const、暗中複製、重複移交、移後讀寫皆應拒絕。

### P33 第六批

同步 str 返回與 int／str 混合參數使用明確的返回型別。具名實參依來源順序求值，呼叫前一次完成具名移動與暫存字串的框架移交。後續實參失敗時，逆序釋放已求值的暫存。明確 str.move() 返回維持同一資源，允許呼叫結果接續作為實參、宣告與重新賦值的來源。測試比對 Returned／Moved／Released 真事件與四入口的失敗位置。

### P33 第七批

完整結構的區域宣告可明確整筆移動；全欄位為 int／bool 的結構可建立獨立複本。採來源與目標的實際模組型別身分，依持有者及欄位可寫性驗證欄位更新。公開四入口涵蓋共享資源帳上的 str 欄位替換、正負索引、布林欄位條件選擇與純值複本獨立性。
