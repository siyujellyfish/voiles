# M7 公開語言施工

P31 基線為 0.1.0-preview.1（來源 ec0a7911）。tests/m7/preview1.json 每列含完整來源、舊式單檔預期、模組預期、個別命令例外與成功值。以 python3 tools/核對M7公開能力.py 發行版CLI 重跑。每個來源跑 legacy、check、run、build、pack，後兩者成功後實跑產物。借用衝突與型別不符為必須持續拒絕的反例。額外的路徑、位置、跨檔及執行錯誤沿用 G22、P25、P27 案例。

| 施工 | 使用者缺口 | 自舉相依與既有依據 |
|---|---|---|
| P32 | 一般 int／bool 函式、具名引數、資料條件、短路、迴圈與轉移 | 語言規格第三、四、七節；私有 execute_call_scalar、P18 控制流程。公開直譯與原生須共用同一份檢查結果。 |
| P33 | 結構與資源、容器、Optional、字串完整操作 | 詞彙串列、語法節點與符號表；P19 容器與字串語意及 VA14～VA16。凍結的舊入口須維持相容。 |
| P34 | 原始檔案／UTF-8、引數、路徑、標準輸出與錯誤傳遞、程序呼叫 | 詞彙統計工具及未來編譯器驅動程式。套件及函式名稱屬新標準庫決策；基線 argc() 僅驗證名稱尚無提供。 |
| P35 | decimal64、插值／格式化、例外與直接 await 跨模式 | 依已核准精度、捨入、資源清理及 VB15-01-A。原生直接 await 與公開直譯已有落差。 |

規格權威為[語言規格](語言規格-v0.2.md)。各案例只代表所列形式，詳細私有驗收見 [M4](M4實作範圍與程式碼審查.md) 及 [M5](P23-P27原生工具鏈.md)。後續各批須提供新的公開能力測試，版本凍結矩陣始終對應 preview.1。

### P32 第一批

公開模組入口支援同步 int 函式的位置及具名 int 引數。具名引數按來源順序求值，再依參數名綁定；整數沿用 Copyable 規則。驗收含多檔匯入、逆序命名、巢狀呼叫、被呼叫檔的溢位位置及四種無效呼叫。bool、流程控制及迴圈仍需後續驗收。

### P32 第二批

公開同步純量函式可用 int、bool 參數和回傳，入口 main 維持回傳 int。條件需要 bool。採用同型 int 或同型 bool 的不等比較，優先級依序為加減、比較、and、or。and 與 or 依 D03 短路。區間沿用現有半開整數常值端點；break 與 continue 作用於最近一層迴圈。分支、迴圈與轉移沿用呼叫者的步數預算。本批測試透過公開命令編譯與執行，涵蓋逆序引數、動態分支、短路略過溢位、迴圈轉移、常數寫入及區域名稱離域。

### P33 第一批

沿用 P19 容器宣告、len、整筆 move 與 with 唯讀元素。函式最外層建立的常值容器，其內容可在編譯期確定；檢查器依繫結記錄持有者與移動後狀態，長度可折疊，動態索引在執行時檢查。int／bool 元素可在 with 內讀取，字串鍵採字面值。缺鍵與越界在 run、build 產物、pack 產物回報相同來源位置。Optional 常值可建立及查詢長度；候選縮限、可變內容與一般跨函式資源仍待驗收。

### P33 第二批

分支與迴圈的區域容器可在宣告所在作用域內整筆移動，依最近繫結解析遮蔽名稱。跨區域移動外層容器仍需路徑合流及借用證據。以四個公開命令驗證遮蔽後恢復外層容器、迴圈逐次建立與移動、離域讀取及移後讀取。

### P33 第三批

公開 with 讀取 Optional 元素時會先檢查鍵或索引，可在 if 中比較缺失或判斷候選。非缺失證明只授權同一繫結緊接的候選條件鏈，私有與公開入口共用該位置規則。0、false、空字串均保留原型別；缺鍵與越界維持執行錯誤。此批尚未開放候選值取用。

### P33 第四批

共享字串與借用別名支援以 int 區域繫結動態選取字素、UTF-8 位元組及覆寫位置。具名替換值須於執行時正好含一個字素；先讀取替換來源，通過目標權限與長度檢查後才修改。沿用正負索引與 Unicode 邊界，未宣告或非整數索引為靜態錯誤。本批將四入口容器、純量與字串驗收納入 PR 的 Rust 架構測試。

### P33 第五批

函式區域 str 可持有常值、獨立字素、字素替換運算結果或明確移動的緩衝區。單一 str 形參同步函式可接收具名或位置 move 實參，沿用同一 OwnedStrRuntime 將原 ResourceId 移入新框架。正常返回與索引失敗均釋放一次；跨檔測試核對實際事件順序與來源。const、暗中複製、重複移交、移後讀寫皆應拒絕。

### P33 第六批

同步 str 返回與 int／str 混合參數使用明確的返回型別。具名實參依來源順序求值，呼叫前一次完成具名移動與暫存字串的框架移交。後續實參失敗時，逆序釋放已求值的暫存。明確 str.move() 返回維持同一資源，允許呼叫結果接續作為實參、宣告與重新賦值的來源。測試比對 Returned／Moved／Released 真事件與四入口的失敗位置。

### P33 第七批

完整結構的區域宣告可明確整筆移動；全欄位為 int／bool 的結構可建立獨立複本。採來源與目標的實際模組型別身分，依持有者及欄位可寫性驗證欄位更新。公開四入口涵蓋共享資源帳上的 str 欄位替換、正負索引、布林欄位條件選擇與純值複本獨立性。

### P33 第八批

容器在執行框架內保存實際內容，with 元素保留原持有者與選取路徑，巢狀容器可繼續選取。採 var 清單 append(value)、pop() 與字典 set(key,value)；append 與 set 回傳操作後長度，純量 pop 回傳移除元素，空清單在執行期失敗。字典覆寫既有鍵不增加長度。可變操作與有效 with 借用互斥。

Optional 直接比較排除 none 後可使用唯一候選，is 成立後可取用相符 int、bool 或索引 str。候選集合全部可複製時可在同型或較寬的 Optional 容器元素中使用。排序、缺失值、具名來源及呼叫後取消縮限沿用既定規格。

### P33 第九批

缺失比較可存成 bool 旗標，也可用 not 反轉。縮限依原 Optional 元素的繫結身分；複製 bool 不複製關聯。旗標重賦值、離開內層作用域與函式呼叫使對應關聯失效。and／or 右側與 while 本體不繼承條件的缺失證明；呼叫後可重新比較。四命令案例驗證取值、否定、重賦值、作用域、呼叫及重新建立證明。

### P33 第十批

可寫結構欄位依既有 S07 規則延後初始化。建構後追蹤缺少的欄位，全部填妥才允許讀取、複製或整筆移動；首次寫入在右值成功後提交。故障退出釋放先前完成的字串欄位。原生建構依具名值來源順序、再依未覆蓋預設欄位順序執行。

### P33 第十一批

同步工廠可明確移動完整結構作為返回值，呼叫端以實際模組型別接收。字串欄位保留同一資源身分，在共用帳上簽發返回事件並由最後持有者釋放。無移動、錯誤型別及已移走來源在四入口拒絕。

### P34 標準庫第一批

新增預設函式 argc、arg、read_utf8、write_utf8、file_len、file_byte、path_join、stdout、stderr、process_run。同名使用者宣告優先。程式引數從 0 起算，不含程式名稱；直譯使用 run 入口檔 -- 引數，兩種產物直接傳入。文字讀寫使用 UTF-8，file_byte 讀原始位元組，路徑相對於程序工作目錄。stdout／stderr 寫出原文字並回傳 0；process_run 直接執行指定程式，每個額外字串對應一個程序引數，回傳退出碼。I/O 失敗沿用來源位置的執行期診斷。驗收含繁中路徑與輸出、非法 UTF-8、越界、缺程序、靜態型別與同名函式。

原始位元組寫入使用 write_bytes(path, byte...)。每個 int 須介於 0 至 255，全部實參驗證後才開啟檔案；零個位元組可建立空檔。與 file_byte 對讀驗證 NUL、非法 UTF-8 位元組及失敗時舊內容的保留。

### P35 直接 await

原生產物沿用公開檢查計畫已核准的無參數直接等待，與直譯共用呼叫深度及步數上限。四個命令涵蓋直接與巢狀等待、子框架算術失敗位置、漏寫 await 及等待同步函式。

### P35 字串格式化第一批

緊鄰雙引號的 f 前綴在執行到該式時讀取區域 int 與存活 str；接受具名欄位、整數 d／x、文字 s 與雙大括號轉義。產生獨立擁有的 str。未知欄位、格式型別不合及未配對括號由四入口拒絕。

### P35 有限 decimal64

公開純量 float、同步參數與返回值使用 16 位十進位有效數字。有限常值與加減採最近值、半數取偶；量子指數為 -398 至 369，可表達次正規數。常值超界由檢查器拒絕，執行期加減超界回報來源診斷。不得隱式混合 int 與 float。私有 P13 凍結入口保留原有限子集。

### P35 具型別例外

try 區塊依來源位置選擇最近且型別相符的 except。EvaluationError 沿用公開運算失敗，str.to_int() 的有號整數轉換錯誤沿用規格拼寫 TypeConversationError。預算耗盡繼續向外傳遞。已完成寫入在處理區塊可見，失敗寫入維持舊值。

格式化亦可讀取 bool 與有限 float。float 的 .Nf 固定小數位（0 至 398），顯示採最近值半數取偶。相容決策為明寫 t 前綴的 const str 樣板，在宣告執行時擷取值並形成獨立字串；既有無前綴字面值仍逐字保留大括號。

插值欄位亦可使用具型別的純量常值、括號、加減、布林運算與無參數整數函式，依欄位順序求值。根區域持有的 str 可在條件、迴圈及具型別處理區塊內使用；len(str) 以相同 Unicode 字素索引邊界計數。

區域 Optional 可直接宣告、重賦值及縮限，持有者與 with 元素共用候選和值的表示。Copyable 候選集合可向同型或較寬集合複製；重新賦值先驗證右值，再使已有縮限失效。float 候選沿用 decimal64 同一數值槽。

直接 await 可傳入具型別的純量引數，並在原呼叫框架的步數預算內執行。with 的元素借用也受跨函式等待檢查保護。

具整數參數的結構方法可依序更新可寫 self 欄位及返回整數運算結果。只讀方法取得共享票據，寫入方法要求可變接收者與獨占票據。方法內故障使用定義模組的實際語句位置。凍結的私有解析器與公開模組入口各自保留適用的 Optional、decimal64 與例外語法。
