# P28～P30 自舉與發行

P28 第一個核心為整數字面值的進位累積。bootstrap/digits.voil 使用現有明確型別、結構、移交及受檢 int 加法重寫二、八、十與十六進位累積。編譯器從原有已檢查計畫匯出唯讀整數 ABI，宿主負責字元及前綴驗證。Rust 種子保留原版從字串解析的演算法以供獨立比對及恢復。

在 Linux x86-64 GNU 使用 stable rustc，執行 python3 tools/bootstrap.py target/seed，再以 python3 tools/bootstrap.py target/stage1 --previous target/seed/voiles 建立內含 voiles 累積核心的 CLI。輸出目錄須為新路徑。兩代走相同 run 入口比較完整 int64、無效數字及溢位診斷。P29 完整自舉與 P30 發行須另行驗收。
