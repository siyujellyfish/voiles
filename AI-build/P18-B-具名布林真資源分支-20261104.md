# P18-B｜具名 bool 條件的真資源分支

> 2026-11-04 施工候選。基準 main：`5ea240e6ed31b86463a3e7a1d8e80348c8768d33`。此批不是 G17/G18 正式驗收。

本批沿用私有 `verify_source_with_ability`，只接受同一 `main` 中直接 `true` 或 `false` 初始化的 `var/const bool`，宣告必須具有原 Checker `DeclarationId` 型別證據。具名條件 `if (name)` 須與原 Lexer 名稱及來源跨度吻合，執行期從 `BTreeMap<DeclarationId,bool>` 實際取值；選中區塊使用既有 `OwnedStrRuntime` 真正建立與逆序清理 UTF-8 資源。未執行分支不產生資源事件；bool 純值也不創建 `ResourceId`。

新增五項真 Rust 正反測試：具名 true、具名 false、錯型別條件、未初始化或未知名稱、尚未接通的 bool 非純值初始化拒絕。`tools/核對P17私有字串切片.py` 從 17 項擴至 22 項，只核對名稱存在；既有 Rust 全量測試負責實際執行。對外 CLI、F00 四凍結及 G6 不變。

尚未核准的 bool 一般賦值、方法、借用與迴圈繼續拒絕。PR 最新 HEAD 需三項必要 CI 成功、作者/base/mergeable 查核、Squash merge，合併後新 main SHA 另行驗證。P17～P22 不提前簽核。
