# G18／P18.5-T3／R05：真 BorrowTicket 跨框架錯序不能以張數平衡冒充成功（2026-11-14）

## 起始權威與可核實的缺口

從已 Squash merge 且同 SHA 三必要 CI `completed/success` 的 `main b4fd6e6e13c105c7b0b5b93324ca1125131ec339` 起步。P18.5-T3 原始契約要求**修改來源／事件可被真正稽核拒絕**，原 V0／R05 測試錨點特別列出「巢狀回滾交換內外票據歸還順序須拒絕」。`src/struct_stage/shared_call_exit.rs::private_shared_call_exit_balanced` 原本只使用 `Vec<BorrowTicket>` 並在 `LoanReturned` 按票據身份找到任意位置移除；即使兩個真不同 HC14 票據分別在外與內動態函式 frame 取得，若錯誤事件把外票放在內票之前，**集合與數量最後仍可平衡**，可能通過這一層跨普通函式／同步 self 共用的進退稽核。此問題屬既有 T3 安全證明缺口，不是需要新增語意的功能。

## 修正的驗證範圍

- 仍只讀原 Checker／BorrowSafety 已簽發的 `BorrowTicket`；將事件序列內有效票據帳從 `Vec<BorrowTicket>` 擴充為 `Vec<(BorrowTicket, acquire_frame_depth)>`。動態深度僅由真正 `FunctionEntered`／`FunctionExited` 事件改變；絕不依名稱或票據 serial 猜測借用授權，更不新建真票據。
- `LoanReturned(ticket)` 除原有「真取得一次、失敗先 Unwind、成功必在 Returned 後」條件，另要求此張票的取得深度不能大於現存函式層數，且**所有仍有效的更深框架票據都已先歸還**。因此內層框架錯序提前還外票必拒絕，不能只靠結尾 `tickets.is_empty()` 當作成功。
- **明確不推論「全部借用必 LIFO」**：兩個在同一動態 frame 且源自不同真 `DeclarationId` 的共享借用，可以按既有 Checker／P15 已證實際最後使用點依任意合法順序歸還；此層不創造新的 BorrowFact 或變更 VB14、P15 的詞彙有效期判定。原 `BorrowSafety` 才是真正授權／釋票據的唯一動態權威。
- 普通函式、遞迴資源與同步 self 的退出器仍產生原事件，本批只加強共享的**唯讀驗證器**，不改 Lexer／Parser／Checker／TypedHIR、方法／普通函式語言能力、OwnedStr ResourceId 或 async 排程。無真事件不可用偽簽章造票，也不可把單純測試增加當成 T3 已 Closed。

## 八項真 HC14 票據正反驗收

新增 `src/struct_stage/g18_r05_t3_nested_ticket_order_tests.rs`，從**真的 `BorrowSafety::acquire` 和 `check_ticket_access`／`release`** 取得不可偽造、跨 Tracker 不等價的真票據，再將原事件序列作必要對帳及可控竄改：

1. 內外兩個真不同票據在正常三層 FunctionEntered／Returned／Exited 時內後外成功平衡；
2. 正常路徑僅交換兩張 `LoanReturned` 的事件位置，張數／身份總數不變，但新驗證器必拒絕；
3. 相同兩本真票據在失敗 `UnwindStarted` 後內層先還、外層後還，三層 `FunctionExited(false)` 成功平衡；
4. 失敗序列僅交換內外 `LoanReturned`，仍必拒絕，證明非單純總量檢查；
5. **同一 frame 兩本合法共享借用**不受全域 LIFO 錯誤限制，允許先還最早取得者；
6. 不同真 `BorrowSafety` 追蹤器簽發的票據，即使 DeclarationId 相同也不能冒用；
7. 重複歸還一張真票或漏歸還，在其他事件看似成功時必拒絕；
8. 三層真票據＋三層 Copyable int 局部各自反向清理合法，改動票據或局部離域順序（事件數不變）仍拒絕。

`tools/核對G18-P18.5-T3跨框架真票據錯序.py` 必須先 Rust `--list` 精確核對八個完整唯一測試名稱，再逐一 `--exact --test-threads=1` 真正取得 `1 passed／0 failed／0 ignored`；已納入必要 Rust 獨立架構 CI，先前 F00／G6／G17／G18、R05／R06／R07 所有正式 Gate 均保留。
