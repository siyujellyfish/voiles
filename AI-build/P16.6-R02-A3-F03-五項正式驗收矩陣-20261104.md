## 安全界線

正式共有函式／宣告／賦值／return／if/else-if/else／區塊的唯一解析順序由 src/syntax_shared.rs 提供，雙 Parser 直接消費真正來源。公開 PublicMvpA 與私有 PrivateVerified 的核准語法集合依舊不同：私有參數、struct、for/while、break/continue 與借用／移動不得被公開前端接受。私有 else-if 沿用 StmtKind::If 巢狀 CFG adapter，而真正 else 保存 ParsedElse::Block 的大括號跨度，不重建第二棵 AST，也不改 P15 守衛。DeclarationId、BorrowTicket、ResourceId 絕不互換。

| 子項 | 唯一正式 AST／詞彙來源 | 正式消費者 | 真 Rust 正反拒絕門檻 |
|---|---|---|---|
| F03-01 | ParsedFunction、parse_function_decl、ParsedReturn、parse_return | 公開 P09～P12；私有函式 Checker | 公私相同函式／return 真 AST span；私有位置參數合法、公開拒絕與缺 return 表達式雙拒絕 |
| F03-02 | ParsedDeclaration、parse_declaration、ParsedNamedAssignment、parse_named_assignment | 公開頂層／局部 Binding；私有局部／struct 欄位 Checker | 真局部宣告／賦值跨度同源；缺冒號 Syntax、私有欄位模式隔離 |
| F03-03 | ParsedIfArm、ParsedIfChain、ParsedElse、parse_if_chain | 公開 IfChain/P11；私有 If CFG／合流 | 多層 else-if/else 真來源與原合流；缺 else 大括號雙拒絕 |
| F03-04 | ParsedBlock、parse_block | 雙 SourceIdentityAudit 與正式控制流程 | 真巢狀左／右括號與半開父子跨度；缺右括號 EOF 雙拒絕 |
| F03-05 | StatementHead、statement_head、私有已核准迴圈 AST | 公開拒絕；私有 P15 CFG | 真 for/while/跳轉及公開模式隔離；迴圈外 break/continue 原繁中安全診斷 |
