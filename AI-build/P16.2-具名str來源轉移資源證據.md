# P16.2 具名 str 整體移動真實 .voil 來源至資源事件（2026-10-30）

> 本項只建立已核准 VA16-01/02-A、P13.3 的私有來源／UTF-8 資源事件橋接，非 P16.2 或整個 P16 的正式簽核。

## 已核准前置

- P13.3 .move() 為明確整筆所有權轉交，禁止搬移已移動來源及 str 隱含複製。
- VA16-01-A 單一持有者持有真實 UTF-8 緩衝區；轉交資源不建立第二持有者。
- VA16-02-A 依取得責任及完成初始化逆序清理；新持有者移動後只負責釋放一次。
- P15／HC14 借用衝突等均以現有靜態 Checker 先檢查；沒有開放任何新語言文法或非同步／例外語意。

## 此次實作範圍

- 新增測試專用 struct_stage::trace_named_string_move_source。先解析真正 UTF-8 .voil、執行已核准私有 Lexer／Parser／Checker，僅對單一 main 中「直接字串常值建立持有者 → 具名整筆 .move() 到另一 var str → return 0」建立執行期事件。
- 使用原本 OwnedStrRuntime 的實際 String 緩衝區，預期事件為 Created(1), Moved(1), Released(1)；中文與表情符號保持真實 UTF-8，無第二次配置或重複釋放。
- 暫不接受轉義字串、const 移動目標、任意額外語句、函式呼叫、容器／結構與分支。這是可證安全的來源子集，不是假裝具備一般 .voil 解譯器。
- 五項真實正反回歸：合法整體轉移；重複移動拒絕；str 隱含複製拒絕；未實作轉義求值拒絕；無一般控制流程執行證明的額外語句拒絕。
