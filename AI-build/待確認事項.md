## F01–F06 批次（2026-10-23）

- **F01-A**：明確修訂 D09-A；struct const 欄位宣告時必須指定預設值，例如 `const id:int = 0`。禁止延後首次寫入；S07 只對 var 欄位保留延後初始化。
- **F02-A**：const 結構實例變數宣告時必須有初始化運算式，例如 `const u:User = User()`；不據此宣稱其中所有 var 欄位均已初始化。
- **F03-A**：int 溢位能靜態判斷則靜態報錯，其餘執行時報錯；確切分析範圍及錯誤型別待定。
- **F05-A**：一般函式呼叫允許尾逗號，例如 `add(1,2,)`；函式宣告參數表尾逗號未決。
- **F06-A**：忽略空白行。
- **F04 未選**：float 仍確定為 64 位元，但 IEEE 754 binary64 與 decimal64 的方案只做比較、尚未定案。
- **其他未決**：const 結構實例中仍未初始化的 var 欄位、S18 遞迴不可變與可變借用交會；D11 的 Optional 容器提議亦保持未決。

## E01–E07 批次（2026-10-23）

**原始 E 批次狀態（後續 F 批次已進一步修訂）**：E01 有號 64 位元整數、E02 溢位必須報錯（F03 已決定何時報錯）、E03 64 位元 float（F04 格式未選）、E04 未知欄位靜態錯誤、E05 具名尾逗號、E06 一般 const 必須初始化（F01/F02 已擴充）、E07 圓括號內允許跨行。

**E06 的 struct 擴充衝突（歷史，已由 F01/F02 解決）**：

- **原 D09-A** 曾允許未初始化的 struct const 欄位延後首次寫入；**F01-A 已明確修訂，此條不再生效**。
- **使用者已確認 F01/F02**：struct const 欄位宣告時必須有預設值；const 結構實例變數宣告時必須提供初始運算式。
- **現行處置**：已取得使用者明確授權改動 D09，S07 對 var 欄位的延後初始化及 S06 空建立仍有效；const 實例與其中尚未初始化 var 欄位的權限及 S18 交互仍待確認。

**其餘待補細則**：F03 已確定溢位報錯時機，細節及錯誤型別未決；F04 浮點格式未選；其他續行未定，D11 Optional 容器範圍提議獨立未決。

## struct 批次決策狀態（2026-10-23）

**最初確認、原決策未變動的 19 項**：S01-A、S02-A、S03-A、S04-B、S05-A、S06-A、S07-B、S08-A、S09-A、S10-A、S11-B、S13-A、S14-A、S16-A、S17-A、S18-B、S19-A、S20-B、S21-B。完整原文與適用範圍記於 [語言規格-v0.2.md](語言規格-v0.2.md)「三之一、struct 批次決策」。

**後續裁決完成的 2 項**：

- **S12（原方案 A 經使用者指定的衝突處理方案 A 修訂）**：`self` 只允許借用；取消原先「明確指定時才移動 `self`」的條款。不得將 `self` 作為可被方法消耗的移動接收者。
- **S15-B（維持）**：方法不允許消耗整個 `self`。
- **不受影響**：仍允許在方法呼叫以外，依既定通用所有權規則明確移動**整個**結構實例；S21 禁止只移動單一欄位。
- **結論**：S01–S21 共 21 項現在均有一致的已確認決策；不因此自動補齊借用可變性、生命週期、例外路徑與非同步安全細則。

**其他後續細則（非本批次選項衝突）**：

- S05–S09：S06 空建立有效，S07 延後初始化只適用 var 欄位；F01 要求 const 欄位宣告時有預設值、取消 D09 延後首次寫入；D08 具名引數覆蓋預設值時不求值，其他求值時序待議。
- S11／S14／S17：`self` 不列於參數表、方法結束歸還借用、跨 `await` 及失敗路徑的靜態安全檢查。
- S19／S21：各欄位是否 `Copyable`、複製深度、整體移動後的有效狀態與資源處理。
- S20：允許方法按參數簽章多載，但如何比較簽章、選擇多載、處理相同簽章及同名欄位仍需更完整規則，既定的欄位／方法同名禁令保持有效。

## 已確認且無須重複選擇

- 例外使用 `except`；`exception` 為筆誤。
- `fn`、`async fn` 與 `struct` 方法預設公開；名稱以 `_` 開頭者為模組內部函式／方法，同模組的其他函式或結構可呼叫，跨模組不可呼叫；不需要 `share fn`。
- `struct` 方法內存取自身欄位必須明確寫成 `self.欄位名稱`；S11 已確認 `self` 自動提供且不列在方法參數表，S14 已確認方法借用離開方法時歸還。S12／S15 已裁決方法 `self` 僅能借用、不可消耗整個 `self`，完整借用權限、可變性及非同步安全細則仍待確認。
- `struct` 的欄位與 `fn` 方法直接宣告在同一個結構區塊內，不另設 `impl` 或其他外部方法實作區塊。
- `struct` 欄位採方案 B：一般名稱預設公開，`_` 前綴欄位僅模組內可見；與函式、方法的模組可見性規則一致。這是存取範圍規則，不改變欄位可寫性或其他安全語意。
- 同一個 `struct` 的欄位與方法共用名稱空間，採方案 A：若欄位與方法同名，編譯器應回報名稱衝突；不自行擴張至其他同名、過載或解析規則。
- `struct` 型別名稱採方案 A：不含 `_` 前綴的結構預設公開；`_` 前綴結構只能於同一模組引用，不能由其他模組使用。
- 結構實例的 var 變數宣告須明確型別，例如 `var s:Stru = Stru()`。F01 要求 struct const 欄位在宣告時有預設值；F02 要求 const 結構實例變數有初始運算式；S07 延後初始化只適用 var 欄位；方法 self 只允許借用不可消耗，其餘借用可變性及安全規則未決。
- 一般借用至借用變數最後一次使用；函式借用在執行離開函式作用域歸還。
- `Optional` 同時具有多型別聯集與缺失值語意。
- 字串索引：先字元，後 UTF-8 位元組。
