# 待確認事項

以下**不是已採納決議**。未經使用者同意，不以任何選項作為實作前提。

| 主題 | 尚待確認的問題 |
|---|---|
| `share` | 外部可變的可見範圍、延長借用是否允許、跨模組與跨執行緒安全界線 |
| `const` | 是否必須編譯期常數，或僅是初始化後不可變；內部物件能否變動 |
| 複製 | `Copyable` 定義、資源型別與容器的能力限制、深層複製與效能規範 |
| 借用 | 借用綁定可否重新綁定；複製借用的結果應為新擁有值或另一借用 |
| 函式 | 參數／回傳借用模式標記與生命週期表示法 |
| 生命週期 | 是否採非詞法生命週期、欄位級分析及容器索引借用規則 |
| 語言基礎 | 整數位元寬、泛型、物件系統、模組、例外與標準函式庫 |
| 工具鏈 | 直譯器實作語言、位元組碼表示、原生編譯後端、封裝與自舉里程碑 |
| 持續整合 | 程式碼實作語言確認後，增加哪些自動建置、測試及效能檢查 |
| 儲存庫設定 | 是否限制主分支直接推送、禁止非壓縮合併、要求通過檢查後才能合併 |

## 決策處理流程

1. 提出可比較的具體方案及影響。
2. 等待使用者明確選擇。
3. 將決議寫入 `語言規格-v0.2.md` 或 `專案規則.md` 並修正本檔。
4. 在 `工作紀錄.md` 精簡記錄決策與驗證結果。
