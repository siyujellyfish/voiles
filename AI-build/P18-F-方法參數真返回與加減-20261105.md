## 上輪真正缺口

先前已能把原 Lexer `instance.method(13)` int 常值安全綁定至所選方法自己的真 `DeclarationId`，但方法本體僅能 `return self.count` 或 `self.count±常值`。真正合法 `fn get(n:int)->int{return n}` 仍保守拒絕，沒有讀取已建立的執行期參數框架。

## 本輪真正執行的範圍

- 維持原 Parser 的完整 `TermKind::Name` 或 `TermKind::BinaryInt`、原 Lexer 名稱與右側整數 token 的精確跨度，不以文字猜測；新的 `private_self_method_parameter_reference` 核對**選中方法**真參數名稱及 Parser DeclarationId。原 Checker `VerifiedTypedMember(Parameter)` 已在參數綁定時核對，`VerifiedMethodSafety.checked_returns` 在返回位置完整驗證。
- 新增 `PrivateSelfIntReturn::Parameter`、`ParameterAdd`、`ParameterSubtract`。被呼叫方法真正進入時先建立 Copyable i64 參數框架，再**按 DeclarationId 查出當次參數值**；不以 `self.count` 代替，也不將別個同名多載的參數誤用。所有加減採 `checked_add`／`checked_sub`，溢位回報受控 `IntegerOverflow`。
- SharedRead／ExclusiveWrite 動態 `self` BorrowTicket 與 `MixedStructRuntime` 仍依原 Checker 授權；正常／故障／溢位均清空參數框架，先歸還票據再退出。已驗證來源重新核對整份返回計畫，竄改參數來源身分或運算種類必在執行前拒絕。
- 七項新 Rust 正反：真參數返回值、真加減、重複執行、溢位、故障、偽造計畫以及錯誤來源 Checker 拒絕。原測試「任何具參數都拒絕」按真實能力更新成尚未執行的 `return n+n` 受限反例；專用 Gate 31→38，原 G18 P18.6 稽核追加六項真來源。
- 不新增公開 CLI／非同步語法／任務調度、方法多參數與一般算式求值；保留 F00／G6／G17 凍結與 G18 `--check` 嚴格結案條件。
