## 正式來源與實際路徑隔離

`PreparedProgram::prepare` 原樣執行唯一 P07/P09/P10/P11/P12 正式 Checker，保留原始來源、模式、已驗證宣告和型別 HIR、可達性證據。新增 `PreparedProgram::execute_with_trace` 只在驗證通過時建立 Runtime，從**真正執行的語句**產生 `ControlEvent`：
- `FunctionEntered`／`FunctionExited { returned }`：函式真呼叫與返回／錯誤退出。
- `ConditionChecked { selected }`：每次確實求值過的 `if`／`else if` 條件結果；後續跳過的條件不會產生事件。
- `ElseSelected`：前述條件全不成立且真的選到 `else` 才記錄。
- `Returned`：return 表達式真正成功求值，並且控制實際離開該函式或分支時才記錄。

`ExecutionOutcome` 的 `result` 和 `events` 彼此獨立。真正動態錯誤會保留錯誤以前的控制事件，`FunctionExited { returned: false }` 不冒稱已成功 return；非法來源或 HIR 不會啟動求值且事件為空。

## 保守界線
