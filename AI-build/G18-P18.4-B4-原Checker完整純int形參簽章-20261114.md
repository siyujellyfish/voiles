## 原已驗收起點

以 `main 71a049196ceee3d5a5b2a3a04f019986eb7513d9` 為起點：PR #767 已 Squash merge，合併後主線同一 SHA 的「文件與工作紀錄」「Rust 前端建置」「Rust 獨立架構測試」皆 `completed/success`。PR #766/767 已把零、一、兩個原 Checker 已核准 Copyable int 形參與普通純 int helper 的動態參數框架、main／self 方法局部與 var RHS、不同 DeclarationId 的精確身分、左至右求參與唯一 Unwind 接通。

此前 `safety_checker.rs::helper_arity` 與 `execute_method_self.rs::prepare` 另設 `params.len()>2` 子集上限，雖然原 Checker 已核准多參數同步純值普通函式，其安全性其實只依賴**每一個參數的型別、DeclarationId、已生存來源、是否無副作用**，不依賴正好有兩個。這項不必要的子集限制導致合法純 int 多參數程式在方法橋接中被錯拒。本批刪除兩處人工上限，完全依**原 Checker 真簽章**決定 int 形參數量，不新增語言語法、一般函式能力、資源語意或任意巢狀 Call。

## 同源靜態證明與安全邊界

- `helper_arity` 只承認原 Checker 真存在的**同步**普通函式，返回型別 `int`、單筆 `Return`，**每一個**形參皆須為 `int`、名稱非 `self` 且互不重複；返回樹只能使用已宣告參數名稱、Lexer 整數、Group 及加減，不能使用 `str`、bool、Borrow、Move、FieldRead、任意呼叫或其他副作用。
- `PreparedPrivateSelfMethod::prepare` 遍歷整份原 Parser `helper.params`，按宣告順序核對每一個參數的 `VerifiedTypedMember(Parameter)`、來源半開位元組跨度、原 `plan.members` 及唯一 `DeclarationId`，形成 `Vec<DeclarationId>`。所有返回 HIR 只使用 `PrivateScalarReturnExpr::from_checked_bindings` 解析原 Checker 已核准 `int` 引用、純加減；`private_self_pure_helper_int` 再確保每個 `Parameter(id)` 必為上述真形參之一。
- `private_self_matches_helper_call` 嚴格要求真 `Call`、名稱相同、未 await、引數長度和形參完全一致，且每個引數仍為原 Checker 正式建構的 Copyable int `Constant`／`Parameter`／純加減樹；不允許以 `Call`、Struct、str、bool、Resource、Borrow 或 Move 偽裝引數。所有計畫由 `matches_source` 重跑原 Checker 與逐欄比對，不能換參數身分、順序或多塞同值虛假節點。
- 受限 `PreparedPrivateSelfMethod` 仍然只認**一個普通 helper 函式**、一個原 Checker 結構的單一 Copyable int 欄位、真同步方法框架、main 局部與直線方法局部／重賦 RHS；並未因此變成支援任意普通函式控制 CFG、任意巢狀呼叫或非 Copyable P16 資源圖。這些仍是 B4/M3 未完成責任。

## 真動態框架與失敗時序

沿用已驗證的 `private_self_helper_argument_frame`，按原 Parser 形參向量逐筆由當前 caller（main／同步 self 方法）Copyable int frame 求值。只有所有實參求值成功、未重複且與真形參 `DeclarationId` 一一綁定，才允許記 `FunctionEntered` 並在獨立 helper frame 內執行原純 int Return HIR。若頭端或尾端任一實參溢位：**helper 並未進入**，不記 `ordinary_calls_entered`，由 caller 錯誤責任處理；若原 helper 本體真溢位：先 `UnwindStarted`、`FunctionExited(false)`，後方法逆序 ScopeEnded／原唯一 self BorrowTicket 歸還與外層退出，不能假造 Returned／LocalAssigned。整數不是 P16 UTF-8 ResourceId，不得創造任何假的資源事件。
