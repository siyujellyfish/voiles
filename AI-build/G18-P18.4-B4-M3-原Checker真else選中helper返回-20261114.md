# G18／P18.4-B4／M3：原 Checker 真 if/else 選中 else 純 int helper 返回（2026-11-14）

## 已驗收基準與第三個混合 CFG 缺口

本批基準為 `main 4eb96087b209eeab0e1d5a2b11c271621b0915a3`：PR #770 已 Squash merge，且新主線同 SHA 的「文件與工作紀錄」「Rust 前端建置」「Rust 獨立架構測試」三必要 CI 全部 completed/success。前兩批 B4／M3 已接通方法局部最後直接 `return helper(...)`，及原 M2 真 `if(flag)` **true 選中葉**提前 `return helper(3,2)`。原 Checker 的 `method_branch_checked_pure_helper_return` 僅對原 `method_return_type` 已通過的真 Return、同步純 int helper、原 Parser int 形參及純 Lexer int 常值／加減實參，由同一 `self.evaluate` 真簽發 `ScalarHIR`，不另外創造語意。

仍缺 `if(flag){ return self.n } else { return helper(3,2) } return self.n` 的**else 選中返回葉**：M2 受限執行器先前只容許 else 常數／self.int 或其原加減，即使 Checker 已取得相同來源權威，Runtime 無法在 else 真選中時進入 B4 helper。另一個已核准的 M2 特例是 else 葉先一筆 `self.n=10`、再 `return`；其 ExclusiveWrite 借用模式不得被新增 helper 返回偷換或重複取得票據。

## 同一原 CheckedHelperReturn 圖，而非第二份認證

- 新 `private_self_checked_helper_return_leaf(term, bindings, verified, helper)` 是**唯一共通的受限 Caller→Helper 返回來源建構器**，供 M2 true、else 單 Return、else 合法一筆 FieldAssign 後 Return 三種原 Parser 葉使用。它只調用原 `PrivateScalarReturnExpr::from_checked_bindings` 以原 `TypedHIR`／Lexer span／DeclarationId 重建真 Call，且由 `private_self_matches_helper_call` 檢驗同名、無 await、與已封存唯一純 int helper 的完整引數一致性，保留嚴格純 int 白名單。來源缺失、Call 在算式內嵌、資源、bool／str／async、其他函式皆保守拒絕，沒有單靠原文字猜測。
- 原 Checker `method_writes` 仍驗證所有 true／else 葉的型別、`checked_returns` Span，並根據任何實際可寫葉推導 `ExclusiveWrite` 模式。既有 `method_branch_else_field_return` 也可供純 helper else 返回保存原真 ReturnSpan，`method_branch_else_calculation=CheckedScalar(Call)`；`matches_source` 繼續對照所有新欄位與原 `VerifiedMethodSafety` 及 Caller BorrowFact。
- 原 M2 動態控制選葉仍是先觀測真正 bool，非選中葉不得發出 `FunctionEntered`、`Returned`、失敗 Unwind 或偷寫 self；只有 `branch_checked=Some(false)` 才會進 else 的 Caller 值槽求參、helper Return、必要時 inner Unwind。原 ExclusiveWrite else 寫入如真的選中，在 helper 真 Caller 求參前先以**同一已取得 BorrowTicket**執行欄位寫入，不能額外申請、提早歸還或隱含共享與獨占混用。
- 預先求參溢位（尤其第二 int 實參）時，helper 未進入，不能偽造內層框架；helper 本體真溢位時才記 `FunctionEntered`、唯一 `UnwindStarted`、`FunctionExited(false)`，再由方法 R05 真 `LoanReturned` 與 `FunctionExited(false)`，不把失敗計入成功完成數或創造不存在的 UTF-8 ResourceId。
- `true` 支線仍能返回原 M2 self.int／算術值，M2 原巢狀葉、之前 B4 單純方法 Return 與多參數直接 RHS 不退步。本批未開放一般化任意 CFG、巢狀 helper Call、非 Copyable P16 str Move/Borrow／ResourceId、async 或同步方法重入。
