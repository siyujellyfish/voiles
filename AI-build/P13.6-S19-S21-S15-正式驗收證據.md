# P13.6 S19／S21／S15 正式驗收證據（2026-10-30）

**獨立正式結論：P13.6 原始三項結構所有權禁令與合法來源已驗收。** 本項不替代 P13.4 的不確定資源合流、P13.5 執行期資源責任，亦不提前驗收 P14～P16。

## 原始規格契約

1. **S19**：僅所有欄位皆已核准 Copyable 的 struct 整體才可隱含複製；遞迴巢狀結構、含 str Forbidden 及容器 Undecided 必須分別判定；完整值可依 HB13-A 明確整筆移動而不靠隱含複製。
2. **S21**：禁止對結構單獨欄位使用 `.move()`，包括一般程式、方法、分支與回傳運算式，拒絕保留來源位置。
3. **S12／S15**：方法 `self` 只借用，禁止消耗整個 self，含巢狀引數、分支與回傳；讀寫模式依方法實際行為推導。Copyable 的 self 欄位可形成獨立值，str 等非 Copyable self 欄位不能偷複製或借用逃逸。
4. 已核准合法方法來源：Copyable／str 擁有權參數、合法參數 return `.move()`、分支提前回傳、純 Copyable 運算式、一般函式回傳獨立新建 str；對 const 接收者寫入、從 self 資源欄位逃逸、非 Copyable 隱含複製必須拒絕。方法非已核准副作用仍不擅自放行。
