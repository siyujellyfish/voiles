### 同一原 Checker 真工作棧

- `PrivateScalarBoolExpr::from_checked_call_argument` 原只作布林形式參數值。此批允許其核准的同步 bool 函式返回經原 Parser/Checker TypedHIR，流入同一函式的合法 `const/var bool` 局部初始化與 `var bool` 重新賦值，並允許 bool leaf 函式直接 `return` 另一個已核准 bool 函式結果。
- `PrivateScalarTask::BindBoolFromValue`／`AssignBoolFromValue` 只在真 `EnterCall/ExitCall`、真 `BoolReturned` 之後取用 0／1 內部型別化暫存；未返回不得提前寫入，錯誤回滾走原 P16/R05 事件及借用資源清理。不讓 bool 變 int。
- 原 bool 純值來源仍走原直接 `evaluate_runtime`，避免更改既有預算與已驗證事件先後。bool 動態呼叫額外顯式任務受既有 D18-01 `max_steps` 控制；沒有背景工作或第二套 AST。
- 原 `PrivateScalarLocalStep::collect_calls` 現收錄 bool 局部初始化／更新的函式依賴。可達函式依原 Checker 完整決議、`matches_source` 真來源對帳；不能因新增 bool 函式藏在局部裡就跳過原工作圖。

## 原始正反等價類與必要 Gate

新增 `src/struct_stage/g18_f2_bool_local_tests.rs` 七項真正 Rust 單例：
1. 合法 bool 函式結果初始化 const bool 區域，先有真 BoolReturned 後有 BoolInitialized，再決定 if 分支。
2. var bool 重新賦值讀真正 bool 回傳，留下 BoolAssigned 真值與正確返回。
3. 尚未初始化 var bool，待 bool 子函式完成才正式首次寫入。
4. 兩層嵌套 bool 函式真入／退，局部只有一個初始化。
5. bool 函式直接返回另一 bool 函式；真進入順序與 bool 類型一致。
6. 具有真 UTF-8 資源的外部函式在 bool 局部真返回後按逆序清理，唯一 ResourceId。
7. 非法 int 結果寫入 bool 局部必原 Checker 直接拒絕。

專用 `tools/核對G18-F2布林局部返回.py` 對七項精確名稱 `--list` 掛鉤，逐例 `--exact` 執行並要求 `1 passed; 0 failed; 0 ignored`，納入必要 Rust 內部架構測試。不得移除舊 Gate 或只靠文件宣稱成功。
