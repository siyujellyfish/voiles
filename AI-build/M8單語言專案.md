# M8 單語言專案

第一批以 Linux x86-64 的多檔命令列工具為目標。examples/詞數統計 的應用、詞數計算與測試入口均使用公開 voiles。每段連續非分隔字素算一詞；字素首位元組為 ASCII 空格、Tab、CR 或 LF 時分隔。中文連寫視為一段。

從倉庫根目錄執行：
```sh
voiles run examples/詞數統計/main.voil -- examples/詞數統計/sample.txt
voiles test examples/詞數統計
voiles pack examples/詞數統計/main.voil -o ./word-count
./word-count examples/詞數統計/sample.txt
```

原生程式印出完整詞數，成功退出 0。run 會額外顯示 main 的整數返回值。第一批測試入口從檔案讀取三詞範例；第二批起直接提供文字。CI 使用 tools/核對M8詞數統計.py 檢查四命令、兩種產物、空輸入、組合字素、大於 255 詞、斷言失敗及缺檔來源位置。

後續驗收目標為統一的專案測試命令、跨模組可重用的文字分析介面，以及僅攜帶交付產物的乾淨環境驗收。

## 第二批　可重用文字分析

count(text:str) 在分析模組內接收單一擁有者，入口負責讀檔並明確 text.move()。測試入口直接傳入文字常值，無須檔案或引數。分支、迴圈中的唯讀字串形參沿用原有資源框架與離域清理。命令為 voiles run examples/詞數統計/test.voil。

## 第三批　統一專案測試命令

在專案目錄執行 `voiles test`，或從其他位置執行 `voiles test 專案目錄`。兩者均檢查並執行該目錄的 test.voil 與其匯入模組。main 返回 0 時命令成功，其他整數一律失敗並在 stderr 顯示完整值。來源錯誤與執行錯誤沿用既有診斷。專案可透過一般函式和 import 組織多組斷言。

## 第四批　乾淨環境交付

以 check、run、build、pack 驗證專案，再將詞數工具的 pack 產物和輸入檔複製到新的隔離根目錄。CI 在該目錄內啟動靜態 ELF，核對三詞報表、缺檔及非法 UTF-8 的退出狀態與來源診斷。隔離目錄中只有應用程式與測試資料。

M8 驗收依序涵蓋多檔應用與純 voiles 測試、跨模組文字分析、統一測試命令，以及 Linux x86-64 單檔交付。可重跑 `python3 tools/核對M8詞數統計.py 建置好的CLI`；本機隔離驗收使用 bwrap，原生建置沿用既有 Rust 與系統工具鏈。
