# G18／P18.5-T3／R05：真 HC14 借用票據的 frame 離域前歸還與退票後禁復用（2026-11-14）

## 基準與安全漏洞

起點為已完成 PR #778 Squash merge 且合併後 `main f5eb2a49305e3236e177feb5afa06780b06c8de5` 同 SHA 三必要 CI `completed/success`。P18.5-T3 的 R05 共通退出器 `private_shared_call_exit_balanced` 已由 PR #776 增加借票取得深度、阻擋內層借票尚未歸還時先退外層票，及同深度不同 HC14 借票合法的非 LIFO 歸還。

實際發現兩個仍可造成**虛假平衡**的稽核漏洞，且都不須改動原 Checker 的語意：

1. `FunctionExited` 僅檢驗 `Returned` 與局部作用域已清空，**未阻擋該 frame 自己簽發的 BorrowTicket 尚未歸還就銷毀 frame**。如果兄弟函式隨後在相同深度 `FunctionEntered`，舊 `LoanReturned` 只驗證票據深度相等，因此允許兄弟函式冒領前一個已銷毀函式的票據。即使所有函式進退、總 BorrowTicket 張數與局部逆序事件均剛好對帳，仍是無效 HC14／R05 資源生命期。
2. `LoanAcquired` 原本只檢查活動票據中是否已存在相同 `BorrowTicket`，**未保存已歸還票據的一次性身分**。前一函式正常歸還並退出後，下一個兄弟函式可能重用同一張已失效票據身份，舊稽核誤判第二次借還為有效。

## 本批修正，不擴張語言語意

- 在 `src/struct_stage/shared_call_exit.rs::private_shared_call_exit_balanced` 保存 `issued_tickets`，任何已在**整條 trace** 出現過的真 `BorrowTicket` 均不許重新 `LoanAcquired`。已歸還之後也不能復用。此約束只反映 HC14 本身簽發單次的票據身分，不影響不同來源合法重借時由 BorrowSafety 重新簽發**不同票據 ID** 的情況。
- 在每個 `FunctionExited` 前，若活動票據集合仍有**取得深度恰好等於當前 frame 深度**的票，立即拒絕。允許外層原票據在其尚未退出期間，跨子函式存活；也允許方法原 `self BorrowTicket` 在 Caller（深度 0）先簽發、在方法真 Return 後歸還，避免錯誤要求所有 BorrowTicket 全域 LIFO。
- 原 `LoanReturned` 深度與內後外順序、`UnwindStarted` 唯一性、已 Returned frame 不可新借／新進入、`LocalScopeEnded` LIFO、原 Checker 型別安全／BorrowFact／OwnedStr ResourceId 都保持不變。**不新增 Borrow、Move、str、async 或新函式語意。**
- 執行器正常及故障路徑的真正事件若不符合上述已承諾的 HC14 生命期，就讓 CI 揪出，不迴避、不刪舊測試、不得用一個空 trace 假通過。

## 新增八項原 BorrowSafety 真簽票正反

`src/struct_stage/g18_r05_t3_ticket_frame_lifetime_tests.rs` 以原 HC14 `BorrowSafety::acquire` 建立真不同來源票據，涵蓋：

1. 兩個兄弟函式各有不同真票，均先借還後退出合法；
2. 第一兄弟攜未還真票退出、第二兄弟同深度冒還，即使總數平衡必拒；
3. 已在第一兄弟歸還的真票被第二兄弟重新 `LoanAcquired`，必拒；
4. 外層合法借票可在兩個真子函式已退出後由外層還票；
5. 原 Caller 深度 0 先借 `self`，方法正常 Returned 後在方法退出前歸還合法；
6. 真兩層失敗框架，唯一 Unwind、內層先還票再退出、外層再還票合法；錯序竄改必拒；
7. 同一合法函式不同來源的多張共享借票可依原最後使用點非 LIFO 歸還；
8. 即使子函式 `LocalInitialized/LocalScopeEnded` 已正確清空，也不能挾未歸還借票離域、讓下一兄弟冒還。

新增獨立 `tools/核對G18-P18.5-T3票據frame生命期與復用.py`，先 Rust `--list` 比對恰好八個精確 test name，後逐項 `--exact --test-threads=1` 要求 `1 passed; 0 failed; 0 ignored`，納入必要 Rust 獨立架構 CI。舊 `g18_r05_t3_nested_ticket_order_tests` 的八項及所有 G17/F00/G18/B4/M2 Gates 完整保留。
