# G18／P18.1、P18.4｜已核准 Copyable int 普通函式真參數與返回（2026-11-05）

> **非公開真正執行的工程子批，不是 G18 正式 Passed。** 工程基線為已通過三必要 CI 的 `main b083dad14e08f44028c209f0c83887f43819b63c`，G17 6／6 Passed，P18.1／18.2／18.4／18.5 SubsetVerified，P18.3／18.6 BlockedByDecision。

## 本批要修正的缺口

P18.1 原先已能於公開內部 P01 執行無參數函式，私有 P18 已能由真 Checker 承接單一 `str` 函式參數的 BorrowTicket；但是原私有 P13 已核准的 **Copyable `int` 普通函式參數**尚未真正轉接到被呼叫函式局部框架，無從檢驗「語言層已核准的一般參數值」與靜態宣告身分在執行時是否一致。

## 實作範圍與必要來源授權

- 新增**非公開** `src/struct_stage/execute_call_scalar.rs`，由既有 `struct_stage.rs` include，使用**相同**真正 `verify_source_with_ability`、私有 Parser AST、原 Checker 的 `VerifiedScalarHir`、P16 `VerifiedTypedMember`、`DeclarationId` 和原 Lexer 記號；**不新造 Parser 或 Checker、不公開 CLI**。
- 被呼叫端限一個原本就合法的 `int` 參數，直接返回該參數；從原 Checker 的 `declarations.matches(id,"int",false)` 與 `members` 完整核對函式簽章，以真正 `scalar_hir.reference(return_span)` 確認返回使用的是那個參數的 DeclarationId、不是其他同名變數。
- 呼叫端限真正 `main()->int` 的單一函式直接呼叫，實參可為已驗證 `int` 常值，或已初始化、原 Checker `int` 型別與 `scalar_hir.reference` 綁定的具名 const／var；也驗證 `scalar_hir.expression(call_span)` 為 `int`。Copyable `int` 以實際 `i64` 值傳入，**不使用 BorrowTicket、不移動／失效原持有者、不增加 str ResourceEvent**。
- 真執行前重新準備同一份 UTF-8 來源、重新核對完整原 P16 計畫及已抽取的函式／參數／呼叫身份，防止來源或計畫遭篡改。真正進入函式時，先執行引數求值，再以已簽出的 `DeclarationId` 在單次函式局部框架建立 `i64` slot；`return parameter` 只能從該 slot 取得真結果，不准假裝執行了其它控制邊。
- 明確 `PrivateScalarCallEvent` 依序紀錄真實引數求值、函式進入、參數綁定、返回、函式退出；在返回或 Rust 專用動態故障注入後皆清空參數框架。測試注入故障**不是 voiles 例外語意**。
- 保留原 G18 來源稽核 `--audit` ≠ `--check`：將新真函式子批列為**第五組**每次重跑，而非只檢查名稱。增加 P18.1／18.4／18.5 的實際原項追溯案例，但**正式六項仍不得標記 Passed**。

## 八項新 Rust 真來源正反

| 檢查 | 預期結果 |
|---|---|
| 前向宣告 `main(){return forward(7)}` | 真 i64 返回 7，5 階段動態進出及已解析參數身份 |
| 已初始化 `const n:int` 實參 | 原 Checked Reference 指向 caller n，callee 參數獨立 ID |
| 已初始化 `var owner:int` 實參 | Copyable 值複製、真函式多次重跑不耗用原所有者 |
| 呼叫參數綁定後注入 Rust 測試故障 | 無成功返回假事件、函式退出標記 false、局部框架零殘留 |
| 錯誤實參型別／個數 | 原 Checker 靜態拒絕，執行前零效果 |
| 未初始化具名實參 | 原 Checker 靜態拒絕 |
| 執行計畫中參數 DeclarationId／引數值造假 | 在動態框架前 SourceChanged |
| 篡改真呼叫跨度／原始來源 bytes | 在動態框架前 SourceChanged |

新 `tools/核對G18純值函式參數真框架.py` 明確檢查八案例，既有 Rust 全量真正執行；`tools/核對G18原六項驗收差距.py --audit` 新增第五組真重跑，不以模型模擬冒充真實執行。

## 尚未完成

本期只支援一個 `int` 參數、直接具名返回的**安全執行子集**；一般參數清單、變數運算、複雜型別與方法 self，均仍須獨立合法性與動態所有權正反證據。P18.1、P18.4 仍 `SubsetVerified`；D18-01 遞迴／耗盡、D18-02 多載／async／跨 await 安全仍 `BlockedByDecision`。P18.1～P18.6 原始六個工作項仍不勾選。
