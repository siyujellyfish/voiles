# G18／P18.2～18.3｜真 Checker 有限 for／while、break／continue 與實際 UTF-8 清理（2026-11-05）

> **施工候選，並非 G18 原 P18.1～P18.6 全數正式驗收。** 基準 `main cf9939bf2e17088c28a24684e82e2805e9822c21`，G17 已 6／6 Passed；原 `F00/G6/G17` 與公用 CLI 安全界線不變。

## 已核准語意及執行來源

- 以**同一原私有 Lexer／Parser／Checker／VerifiedSafetyPlan** 接受原 P15 允許的 `for i in lower..upper` 半開整數常值區間、`while(false)`、及有明確直接 `break` 或 `return int` 退出證明的 `while(true)`，不新增文法、預設步長、跨函式或方法語意。
- `PreparedPrivateLoop` 只接受非公開、單一 `main()->int`、已驗證 `str` 獨立常值宣告、合法巢狀常值迴圈及 `return int`／`break`／`continue` 子集。每筆真被執行的 `str` 須先對照 Checker `DeclarationId`、型別及 var／const，再由原 Lexer token 取得 UTF-8 解碼值；不接受未驗證的隱含 str 複製、方法、動態 bool 條件或任意賦值。
- 為避免為尚未核准的 D18-01 無窮執行／耗盡政策創設**語言**錯誤，這個非公開橋接只承接事前可證明最多 **64 次**的有限整數區間；超出僅回傳內部 `Unsupported`，**不是 voiles 的一般 for 次數限制**。`while(true)` 必須證明本體有直接的 `break`／`return`，不得執行未核准的無限重入。
- 真執行不是靜態展開的資源事件：每輪真正 `enter_scope`、只有執行到 `str` 宣告才 `OwnedStrRuntime::declare` 建立獨立 UTF-8／`ResourceId`，每個 `continue`／`break`／`return`／錯誤均先 `leave_scope` 逆序釋放迭代局部資源；根所有者最後 `finish`，且真事件 `event_trace_balanced`。
- `for 2..2`／`while(false)` 的本體實際零迭代，**不能憑 AST 偽造 Checker 未交付的局部宣告或 UTF-8 ResourceId**；即使來源出現無執行路徑的節點，執行器也不得創造事件。
- 任何執行前已準備來源 bytes、同一 Checker 宣告身分、控制轉移表、函式退出分類或投影動作漂移都需重新由原 Checker 驗證、比對後才建立第一筆動態資源；故障注入只限內部 Rust 正反測試，不能外溢為 voiles 例外語意。

## 十三項真來源正反（獨立專用 Gate）

| 測試面向 | 預期真執行觀察 |
|---|---|
| `for 0..3` | 每次新 `Created/Released`、外層保留至函式退出 |
| `for 2..2` | 空區間不執行、僅外層建立一次 |
| 多次 `continue` | 每一輪先釋放局部 str 再進入下一輪 |
| 一輪 `break` | 只建立第一輪資源 |
| `while(false)` | 不建立任何未走本體資源 |
| `while(true)` 加直接 `break` | 真執行一次、清理後退出 |
| `for` 內提前 `return` | 提前返回值與迭代／根資源逆序清理 |
| 第 2 輪資源建立後注入失敗 | 保留已完成輪次事件，第二輪及根持有者原子清理 |
| 兩層 `for` | 四次內層獨立 UTF-8、每輪離域歸還 |
| 迴圈中非法 str 隱含複製 | 原 Checker 在任何真 ResourceId 前拒絕 |
| 非公開試驗超過 64 次 | 保守 `Unsupported`，不冒充合法語言錯誤或修改語言上限 |
| 運算計畫中的 for 端點竄改 | 原始真投影驗證失敗、零資源拒絕 |
| 靜態控制邊或來源 bytes 竄改 | 同一原 Checker 權威比對失敗、零資源拒絕 |
