# P15.3 break／continue 迴圈轉移與來源存活安全（2026-10-30）

> 原始項目要求分支、迴圈與函式呼叫間借用有效期。本批為實作與候選測試，不自動標記 P15.3 完成。

## 現行核准規格

- D04-A：for i in 1..4 半開區間；while、for、break、continue 均屬既有語言設計，不能把已核准的 break／continue 永久拒絕當作 Phase 完成。
- VA15-01-A：每條可達控制路徑按最後合法使用點解除一般借用；活躍別名不得讓持有者提前直接使用。
- VA15-02-A：不能證明借用逃逸與來源存活關係時保守拒絕；所有權轉移和 P16 釋放責任不得推定。

## 本批實際來源處理

- 在私有 StmtKind 新增 Break、Continue，僅允許於 for／while 的內層來源；迴圈外使用靜態拒絕。
- 迴圈內遇 break／continue，於轉移當下逐一核對與最近一層迴圈入口相同的外層宣告來源身分、ValueSlot、部分初始化集合、借用種類／有效性；一旦不穩定便保守拒絕，禁止將移動後狀態偽裝為安全出口或下一次迭代。
- if／else 內的控制轉移仍沿原先的可達路徑合流，只合流能繼續走到後面語句的分支，break／continue 的轉移路徑則獨立檢查；巢狀 for 控制最近一層迴圈。
- 保留既有 while／for 每次迭代局部作用域、借用未來使用點與函式呼叫的 Copyable 來源檢查，不擅自支援資源型別跨輪覆寫或一般未有不動點證明的修改。

## 新增七項正反來源

| 案例 | 預期 |
|---|---|
| for 內借用局部值、合法 continue | 來源通過 |
| while 的 if 分支 break、後續合法返回 | 來源通過 |
| 巢狀 for 內 break 最近迴圈、外層 continue | 來源通過 |
| 外層 str 移動後 break | 靜態拒絕外層狀態不穩定 |
| 外層 str 移動後 continue | 靜態拒絕反向邊狀態不穩定 |
| 迴圈外 break／continue | 兩類皆靜態拒絕 |
| for 內借用別名值經 Copyable 函式呼叫／continue | 來源通過 |
