# P16 具名字串函式返回與資源責任交接證據（2026-10-30）

> 本批只接通完全可證明的真實 .voil 單次函式返回來源，並以真正 UTF-8 String 模型交叉驗證；不宣稱可執行任意程式、P16.1～P16.6 正式驗收或 P17 直譯器已完成。

## 適用的既定安全契約

- P13：str 不可隱含複製；合法獨立字串常值與整筆 `.move()` 可交接單一所有者。
- P14／P15：非擁有借用不得逃逸或藉返回變成第二所有者；借用來源的靜態檢查在任何資源模擬前完成。
- VA16-01-A／VA16-02-A：真實 UTF-8 緩衝區只有一個持有者；函式返回轉交後，原作用域不得釋放，呼叫端退出才釋放；不依賴垃圾回收。
- P16.4 已有逐筆 `Created`／`Returned`／`Released` 事件身分稽核。

## 新增的實作與七項實測來源

- `src/struct_stage.rs` 新增測試限定 `trace_string_return_source`：Lexer／Parser／Checker 全部完成後，僅接受無參數 str 函式直接返回獨立字面值、或局部 str 建立後以具名整筆 `.move()` 返回；呼叫端須以單次 `var str = provide()` 接收並以 `return 0` 結束。
- `OwnedStrRuntime` 真正建立 String，將資源從被呼叫端以 `return_named` 轉出，離開該作用域後由 `accept_return` 交給呼叫端，最後才清理。正常來源的同一 ID 事件序列精確為 `Created(1)`、`Returned(1)`、`Released(1)`；中文與表情內容一致。
- 四項拒絕來源：非擁有借用直接返回、非 Copyable 隱含複製、未連接的被呼叫端分支控制流程、呼叫端額外語句；另拒絕不能正確求值轉義內容的來源，避免把原始字面值錯當已解碼值。
- 七項正反測試集中 `p16_真正_voil_函式返回資源交接`；與前一批 `p16_真正_voil_來源至_utf8_緩衝區清理`、既有 P16.4 身分稽核共同執行。

- P15.3／P15.6 尚須在含 #243 的最新 main 上正式重新稽核，P16 六項保留未驗收。
- 最新 PR HEAD 必要三項 CI 必須 completed/success，合併前核對 GitHub 身分、mergeable 及其他近期 main 變更，再使用 Squash merge。
