# P16.4 資源事件身分稽核候選（2026-10-30）

> 本檔只記錄 VA16-01/02/03-A 已核准的私有 UTF-8 資源模型之強化測試；不代表 P16.4 或 P16 正式驗收。

## 問題與安全不變式

- 原 OwnedStrRuntime 以 created 與 released 總數相同檢查最終責任，尚不能區別同數量的資源身分錯置、重複釋放及漏釋放。
- 每個 Created(id) 必須唯一；Moved(id)／Returned(id) 僅可指向先前建立且當時尚未釋放的資源；Released(id) 必須只出現一次且對應先前建立的身分。
- 最終所有已建立身分都須恰好釋放一次，且身分集合、原有計數需同時一致；實際合法多次所有權轉交仍不可被誤當重複釋放。
- 本模型不使用垃圾回收器掩蓋責任缺口，不更動已核准資源單一持有者、原子覆寫及反序清理語意。

## 新增真實 Rust 資源測試（5 項）

| 測試 | 期待 |
|---|---|
| 兩筆 UTF-8 資源經具名移動及原子覆寫 | 依事件序列僅各清理一次 |
| 建立／釋放總數相同但事件重複釋放 | 拒絕 |
| 偽造不存在的資源移動或返回 | 拒絕 |
| 建立與釋放資源識別碼錯置 | 拒絕 |
| 已釋放身分仍出現轉移事件 | 拒絕 |
