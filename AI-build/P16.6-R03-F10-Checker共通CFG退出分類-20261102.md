# P16.6-R03 F10｜正式 Checker 與後繼借用活性共用 CFG 退出分類（2026-11-02）

> UTF-8。本批去除 F07 的可達性掃描與 F10 正式 Checker 分支合流之間第二份獨立控制流分類邏輯，不開放未核准的路徑或迴圈語意。

## 實作
- 新增共通 `combine_non_fallthrough(left, right)`：只有兩側皆為同一類必定退出才保留 `Returned`、`Break` 或 `Continue`，其餘混合類型統一為 `LoopTransfer`；只在兩側都不是 `Fallthrough` 時呼叫。
- 正式 `Checker::statement_body` 處理 if 兩側均不可繼續時，改直接消費上述共通 CFG 合流，不再自行維護三段相同類型比對。
- F07 的靜態後繼掃描則使用 `future_stmt_exit`／`future_block_exit` 先對已知直線 return、break、continue 與完整 else 雙分支計算同一 `FlowState`；只依 `Some(FlowState)` 確認確定出口並排除後繼不可達 use-def。
- 不推論無 else 分支必定返回、不推論迴圈固定點或未知條件，亦不以混合 return/break/continue 冒充單一返回類別；實際 Checker 原有錯誤順序、所有權與借用合流仍維持。
- 新增六組雙分支相同或混合退出分類、巢狀混合退出與無 else 保守回歸，確認預判與正式 Checker 合流**使用同一分類函式**。
