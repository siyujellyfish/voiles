## 真正正反測試

| 案例 | 驗證內容 |
|---|---|
| 成立分支提前返回 | FunctionEntered → ConditionChecked(true) → Returned → FunctionExited(true)，無 else 事件 |
| 不成立分支落入 else | FunctionEntered → ConditionChecked(false) → ElseSelected → Returned → FunctionExited(true) |
| 巢狀函式 | main 進入、helper 進入、helper 返回／退出、main 返回／退出順序 |
| 動態算術溢位 | 仍有真已進入、條件檢查、FunctionExited(false)；沒有假的 Returned |
| 偽造 HIR | 執行前零事件，必拒絕 |
| else-if 短路 | 只留下 false → true 兩筆檢查，未訪問後續分支 |
