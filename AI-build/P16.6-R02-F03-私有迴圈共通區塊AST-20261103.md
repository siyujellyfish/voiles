# P16.6-R02 F03｜私有 for／while 正式共通區塊 AST（2026-11-03）

## 基準與不變界線

- 本批承接已合併 PR #419、#420 的最新 `main`，只處理 F03 中私有 for／while 的**正式 AST 來源權威**，不擴充公開 MVP-A 或 P13～P16 的文法／所有權權限。
- 共通 `syntax_shared::parse_block` 原已回傳 `ParsedBlock<Stmt>`，私有迴圈入口過去使用 `.statements` 將 `start/end` 丟棄；正式 `StmtKind::While` 與 `StmtKind::ForRange` 僅保存 `Vec<Stmt>`，未完整消耗共同產物。
- 這次 **不改** for 區間端點、while 條件、break／continue、反向邊、不動點與所有者／借用保守拒絕規則。

## 完成的源碼遷移

1. 私有正式 `StmtKind::While.body` 與 `StmtKind::ForRange.body` 改為直接持有 `syntax_shared::ParsedBlock<Stmt>`，由真正 Parser 交付同一份正式來源，不在後處理猜測原始位元組跨度。
2. 私有 `Parser::body` 直接返回原始 `parse_block` 結果，讓 for／while 保存左／右大括號的 UTF-8 半開範圍。
3. 舊私有 if／else-if 分支目前仍依已核准巢狀形式使用 `Vec<Stmt>`，`IfSyntax` 透過取用已解析區塊的 `statements` 維持既有語意；**不以此宣告 if 也已整合**。
4. Checker 對 `ParsedBlock` 採唯讀 `Deref<Vec<Stmt>>` 查核原節點；只有 CFG 後繼活性模擬需要 `Vec<Stmt>` 時，建立單純分析用的 `statements.clone()`，該副本不是 Parser 或安全 Checker 的第二套 AST 權威。
5. 既有手造 AST 的借用遮蔽／迴圈跳轉負例，明示建立 `ParsedBlock` 及測試專屬跨度；新增真正解析器實例，檢查 for／while 編譯期泛型身分、原始 byte 範圍與中文註解。
