# voiles 核心語言規格 v0.2

> 狀態：**已確認的核心原則**與**尚待確認的細節**分開記錄；此文件不是已完成的編譯器規格。

## 一、目標

- 以 Python 風格的縮排、清晰宣告方式編寫。
- 採強型別、靜態型別及**強制型別標註**。
- 借鑑 Rust 的**單一所有權、靜態借用檢查與資源安全**。
- 以直譯式為主要執行型態，另支援編譯及獨立執行檔打包；長期以 voiles 自舉。
- 預設不採用垃圾回收來取代所有權規則；不得讓直譯與編譯模式具有不同的安全語意。

## 二、已確認：變數宣告

三個宣告關鍵字：

```python
var x:int = 5
var y:float
const name:str = "voiles"
share counter:int = 0
```

- `var`：可變。
- `const`：不可變。
- `share`：外部可變。
- 變數型別必須明確標註；`var x = 5` 不符合目前規格。
- `share` 不可直接解讀為「可繞過借用檢查」或「多擁有者」；其精確跨作用域權限尚待決定。

## 三、已確認：複製與移動

- `=` 為**預設複製**；所有具備 `Copyable` 能力的型別可以使用 `=` 複製內容。
- 複製所得結果具有自己可管理的值，不與來源意外共享可變所有權。
- 不支援複製的型別不能藉 `=` 靜默移動。
- `move(x)` **明確轉移所有權**；來源後續不能讀取，除非按語意重新初始化。
- `Copyable` 複製可能昂貴；編譯器可以提供效能提示，但不得擅自改變值語意。

```python
var original:str = "Hello"
var copy:str = original
var transferred:str = move(copy)

# copy 的所有權已轉移；original 仍可使用。
```

上述範例沿用已討論的字串可複製方向；底層字串配置與複製演算法仍待正式確認。

## 四、已確認：借用

- 使用**函數式借用**：`borrow(x)` 為唯讀借用；`borrow_mut(x)` 為可變借用。
- 使用者**不需宣告 `ref[T]` 等顯式引用型別**；同樣的資料型別可搭配不同借用模式。
- 借用權限、來源擁有者與生命週期仍必須由型別檢查器及借用檢查器在內部追蹤。
- 多個有效的唯讀借用可以並存；對同一資源的可變借用必須排他。
- 借用不能比擁有者存活得更久；不能移動或釋放仍被有效借用的資源。

```python
var text:str = "voiles"
var reader:str = borrow(text)

var data:list[int] = [1, 2, 3]
var writer:list[int] = borrow_mut(data)
writer.append(4)
```

> 注意：範例展現語法方向，完整標準函式庫與方法細節尚未實作。

## 五、已確認：記憶體模型

- 採用 Rust 式 Ownership + Borrow Checker（所有權及借用檢查器）。
- 普通資源以單一擁有者管理，明確移動所有權，借用者不取得所有權。
- 資源在其擁有者生命週期結束時依規則清理，避免懸空引用與重複釋放。
- 直譯器與編譯器必須遵守一致的複製、移動、借用、析構語意。

## 六、首個可執行版本的已確認方向（P01.1）

- **2026-10-10 使用者選定方案 B：記憶體安全核心**。首版應以直譯方式提供強型別、靜態型別及強制型別標註，並包含 `Copyable` 複製、`move(...)` 明確移動、`borrow(...)` 唯讀借用、`borrow_mut(...)` 可變借用與必要的靜態資源安全檢查。
- **首版宣告種類已確認**：2026-10-10 使用者選定宣告方案 C，首版同時納入 `var`、`const`、`share`。其既有語言方向分別為可變、不可變、外部可變。
- 上述決議不等於已確認 `share` 的權限、可見範圍、延長借用、跨模組／跨執行緒安全邊界，也未確立 `const` 是編譯期常數或初始化後不可變。這些規則在確定之前不得自行實作。
- **首版基本型別已確認**：2026-10-10 使用者選定型別範圍方案 B，首版包含 `int`、`float`、`bool`、`str`。`list[T]` 不在此次核准的基本型別集合內，容器能力另行決議；規格示例的 `list[int]` 仍僅為示意。
- 此決議**不包含**整數位元寬度、浮點精度、溢位／除零、字串內部表示、型別轉換、各型別是否具有 `Copyable` 能力、字面值規則及運算子合法型別的裁決。這些仍待進一步確認。
- 此階段尚未確認首版運算式／控制流程的功能範圍、函式、容器、模組、借用有效期與資源型別。現存範例是語法方向示意，不構成完整功能驗收承諾。
- 首版功能細項須依 P01.1 至 P01.5 的決議逐步補齊。
