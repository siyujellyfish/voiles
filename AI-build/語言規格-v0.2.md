# voiles 新版語言規格（初步草案）

> 最後調整：2026-10-23。本文件**以使用者於 2026-10-23 提出的新版設計與後續補充為準**。舊版 v0.2 與此前 P01 各項細部提案暫不沿用；檔名暫保留以維持既有索引連結。此處記錄規劃，**不代表已實作**。未明確定義的語意一律標示為待確認，不能引用舊版內容自行補齊。

## 一、型別與容器

- 基本型別：`int`、`float`、`str`、`bool`、`none`。
- 容器型別：`list[T]`、`dict{K,V}`。
- `Optional` 同時可表示多型別聯集與缺失值；例如 `Optional[int,str]`。
- `list[Optional[int,str]]` 與 `dict{str,Optional[int,str]}` 是規劃中的合法型別使用方式；字典鍵不能使用 `Optional`。
- `var` 容器可進行寫入操作（例如 `append`、`pop`）；`const` 容器僅允許查詢操作（例如 `get`、`index`）。具體方法清單與返回型別尚未核准。

## 二、基本語法及宣告

- 大括號 `{}` 劃定作用域區塊；不沿用舊版以縮排界定區塊的提案。
- `#` 為單行註解；`"""` 為多行註解標記。
- `var`：可變，受所屬 `{}` 作用域限制。
- `share`：可變、可從作用域外讀取（例如跨模組）；修改權限限定於宣告所在作用域。其他權限與借用交互規則待確認。
- `const`：不可變，作用域同 `var`。

```voiles
var a:int
share f:float = 1.23
const s:str = "hello world"
```

## 三、函式、結構與模組

- 函式宣告為 `fn 名稱(參數)->回傳型別{...}`；例如 `fn main()->none{...}`。
- **已決定：一般 `fn` 預設公開**，可由其他模組呼叫，**不需要 `share fn`**。
- **已決定：函式名稱以 `_` 作為前綴時為內部函式**，不對其他模組公開；一般函式及 `async fn` 均依此命名規則。
- **已決定：`struct` 方法遵循相同規則**：方法預設公開；名稱以 `_` 開頭的方法為內部方法，不對其他模組公開。
- **已決定：內部函式／方法的可見範圍是宣告所在模組**。同一模組內的其他函式及結構方法可以呼叫 `_` 前綴方法；其他模組不可呼叫。這是模組內部可見性，不是僅限所屬結構的私有性。
- `_` 前綴可見性僅適用一般函式、非同步函式與 `struct` 方法；**不自動擴及**變數、結構名稱與欄位。方法接收者的參數表表示方式、接收物件方式及同模組呼叫的具體寫法仍待確認。
- **已決定：`struct` 方法存取自身欄位時，必須明確使用 `self.欄位名稱`**，例如 `self.name`；不採用省略 `self` 的隱式欄位存取。這只定義方法內的欄位參照形式，**不等於**已決定接收者如何宣告、是否自動傳入、所有權歸屬、可變性、借用模式及其生命週期。
- **已決定：`struct` 方法的宣告位置採方案 A**，欄位與方法直接寫在同一個 `struct 名稱{...}` 區塊內；不使用額外的 `impl` 或其他結構外專用實作區塊。方法宣告沿用 `fn` 關鍵字。接收者參數表示及方法所有權／借用語意仍屬獨立待決事項。
- 結構宣告以 `struct Stru{...}` 表示，可建立實例並以 `S.a` 等形式存取欄位；實例宣告與型別推導方式待確認。
- 模組可使用 `import a`，並有 `import a from b as c` 的別名方向；搜尋路徑、具體語法細節待確認。

```voiles
# a.voil
share i:int = 5

fn add_i()->int{
    return i+=1
}

fn _helper()->none{
    # 模組內部函式
}
```

```voiles
# b.voil
import a

fn main()->none{
    print(a.i)        # 5
    print(a.add_i())  # 6
    print(a.i)        # 6
    a._helper()       # 錯誤：不允許跨模組呼叫內部函式
}
```

> `return i+=1` 延用使用者提出的示意；「複合賦值可否用於回傳運算式」仍待明定，不從範例推導語法合法性。

## 四、流程控制、例外與非同步

- 條件判斷：`if`、`else if`、`else`。
- 迴圈：`for`、`while`；支援 `break` 與 `continue`。
- 區間範例：`for i in 1..4{...}`；端點包含規則待確認。
- `match case` 參考 Python 的比對概念；voiles 的正式區塊語法與模式支援範圍待確認。
- 例外處理使用 `try{...} except SomeErrorType{...}`，要求明確例外型別。**`exception` 是先前筆誤，不是關鍵字**。
- 型別轉換以函式進行，要求明確錯誤處理，示例為 `.to_int()` 與 `except TypeConversationError`（錯誤型別拼寫暫依使用者原例保留，名稱是否調整待確認）。
- 非同步使用 `async fn`、`await`。

```voiles
try{
    i = num.to_int()
}except TypeConversationError{
    print("轉換錯誤")
}
```

## 五、字串與索引

- 一般字串插值依 Python `f-string` 概念；樣板字串依 Python `t-string` 概念。
- 使用者提出 `const s:str = "函式已經呼叫 {count} 次"` 作為樣板字串形式，並要求樣板為 `const`；儲存插值資訊、何時求值、是否另設型別仍待確認，不得自行認定 Python t-string 的物件型別等同 `str`。
- `str` 具雙層索引：第一層取得字元，第二層取得該字元 UTF-8 編碼中的位元組。

```voiles
const s:str = "你"
# 底層示意：[[\xE4,\xBD,\xA0]]
print(s[0])     # "你"
print(s[0][0])  # \xE4
print(s[0][1])  # \xBD
print(s[0][2])  # \xA0
```

> 「字元」具體指 Unicode 純量值或使用者可見字素叢集、第二層索引的型別與越界規則，尚未確認。

## 六、所有權及借用

- `copy`：一般變數呼叫**預設複製**，取得同值的新所有權；哪些型別支援複製與複製成本待確認。
- `move`：**永久轉移**所有權，來源失效；目標是否可變依目標的新宣告決定。語法採 `a.move()` 的設計範例。
- `borrow`：暫時借用，借用有效期間來源不可使用；借用變數的可變性必須跟隨來源，不同則錯誤。語法採 `a.borrow()`。
- 一般借用的歸還點：**借用變數最後一次使用**。
- 函式參數預設借用，並以**函式執行離開該函式作用域**為借用歸還點。
- 函式接受移動的語法示例如下；借用跨分支、容器元素、非同步與回傳值的細節仍待確認。

```voiles
fn test(a.move():int)->int{
    return a+10
}

fn main()->none{
    var a:int = 5
    var b:int = test(a.move())
    print(a)  # 錯誤：所有權已轉移
    print(b)  # 15
}
```

## 七、運算子

- 邏輯：`and`、`or`、`not`。
- 算術：`+`、`-`、`*`、`/`、`**`、`//`、`%`。
- 使用者範例包含比較、複合賦值與 `..`，但完整運算子清單、優先順序及型別規則待確認。

## 八、規格界線

- 本次新版草案取代舊的縮排式區塊、`borrow(x)`／`borrow_mut(x)`、`move(x)` 等**舊語法示意**；不可繼續當成已確定的新規格。
- 不自行擴充容器操作、可見性規則、方法語意、型別推導、資源清理或最小標準函式庫。
- 其他未決項目集中記錄於 [待確認事項.md](待確認事項.md)；語言目前尚無可執行的直譯器／編譯器。
