# P18 六階段正式驗收

本版涵蓋原 Parser／Checker 核准的私有直譯器入口。P18.1～P18.6 的 26 個原始義務均有專屬 Gate。正式完成日與 GitHub 各項檢查結果以合併後主線的驗收紀錄為準。

|階段|獨立驗收內容|
|---|---|
|P18.1|F1～F4 函式呼叫、返回及資源退出|
|P18.2|C1～C4 分支、迴圈及跳轉|
|P18.3|R1～R4 遞迴、框架預算與回滾|
|P18.4|B1～B5 參數、所有權、借票及 self，122 個具名案例|
|P18.5|六類程式四欄、六組高風險交叉、防偽與凍結回歸|
|P18.6|M1～M3、A1/A2 同步方法與單執行緒直接等待，51 個具名案例|

T4 在同一 checkout 逐名比對完整 Rust 測試清單及執行結果，要求零忽略，再重跑四組 F00 證據、P13～P16、G6、G17、五個相依階段、R06、R07 和原義務清冊。T3 刻意污染較早暫停工作的事件，核對整批退出與喚醒在任何資源變動前拒絕。

## 重跑

使用 CI 編譯的 p04_source_internal 與 f00_probe，在專案根目錄執行：

```sh
python3 tools/核對G18-P18.5原始四義務正式驗收.py --test-bin target/p02/p04_source_internal --check
python3 tools/核對G18原六項驗收差距.py --test-bin target/p02/p04_source_internal --check
```
