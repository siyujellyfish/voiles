# G18／P18.6｜同步 self 欄位加減真執行與溢位安全退出（2026-11-05）

> 本批只擴張已核准的 **Copyable int 同步結構方法** 真執行子集，不變更語言文法，不開放多載／async，不代表 P18.6 Passed。

## 既有缺口

原私有 Checker 已能驗證方法的 int 欄位與 int 加減，但 G18 同步方法真執行器只允許直接 `return self.count`，不能在實際方法 BorrowTicket 存活期間，依真正 int 欄位值計算 `return self.count + 3` 或 `return self.count - 4`。既有獨占 self 寫入後也未涵蓋以更新後欄位值計算的真返回。

## 本批真實變更

- `src/struct_stage/execute_method_self.rs` 新增非公開 `PrivateSelfIntReturn`，只接受原 Parser `TermKind::FieldRead` 或原 Checker 方法純值安全事實 `Arithmetic` 所簽發、端點／運算子均一致的 `self.int ± int常值`。右運算元需有原 Lexer `Integer` token，禁止以文字重新猜測 AST 或建立第二 Checker。
- 動態執行仍以原 `VerifiedMethodSafety`／`call_borrows_at` 及 `BorrowSafety::check_ticket_access` 授權真 `self` 讀／寫；如有合法獨占寫入，先更新真 `MixedStructRuntime` 欄位，再以其最新值進行 `checked_add`／`checked_sub`。
- 運算溢位回傳專用 `IntegerOverflow` 受控執行錯誤，不能冒充成功返回；仍先歸還 BorrowTicket，再完成真結構資源退出。若準備後竄改運算種類或常值，重新以原 Checker 核對後在配置前拒絕。
- 新增六項真 Rust 正反：共享加法、獨占寫後減法、加法溢位離域、未接通的複合減法保守拒絕、偽造計畫拒絕、錯誤型別／未知欄位由原 Checker 拒絕。專用 Gate 13→19，六原項追溯增列真運算與溢位。
- 原 `P18.6=BlockedByDecision`：多載完整唯一解析與 async 調度／取消仍未驗收；G18 原六項一律保持未勾選。
