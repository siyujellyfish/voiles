# P17-F｜結構執行計畫來源防偽與真資源零副作用拒絕（2026-11-04）

> 本批只加固非公開 P17-F 受限真結構求值，**不代表 17.6/G17 正式驗收**。基準 `main b8ed969d5a3f07076a7128c81c886cbf6794c27a`，P18 其餘功能及 P19～P22 尚未完整驗收。

## 安全缺口與封閉方式

原本 `PreparedPrivateStruct::prepare` 由真私有 Lexer／Parser／Checker／SafetyPlan 證明單一結構真來源，再快取 `fields`、`supplied`、`binding_name`、`returned` 供 `MixedStructRuntime::construct` 使用。先前執行檢查原始位元組及靜態計畫一致，但若**已準備的 Rust 內部執行計畫欄位快取**被寫入不同常值、名稱、可變性或返回值，仍有沿用 Checker 舊證據配置資源的風險。

本批新增 `is_same_prepared_payload`：每次真正資源建立前，從**同一份原始 UTF-8 來源**經原 `PreparedPrivateStruct::prepare` 再次取得正式安全投影，逐項比對欄位來源次序、欄位型別、預設值、不可變權限、具名欄位值／順序、綁定名稱及整數返回。無第二套 Parser，也不以散列作為安全身分；失配立即回報 `SourceChanged`，在建立首個 `ResourceId` 前退出。代價是此非公開小切片每次執行重新進行 Checker，屬保守過渡設計，後續可透過不可寫的已驗證執行計畫在不削弱安全下優化。

## 新增五項真 Rust 正反

1. 合法預設 `str` 與 `bool` 結構可以重複真執行，每次獨立 `Created(1)/Released(1)`。
2. 準備後更換 `str` 欄位預設值拒絕。
3. 偷換具名引數值或已驗證的欄位名稱拒絕。
4. 偷改欄位型別或不可變權限拒絕。
5. 偷改 `main` 返回值或已驗證實例綁定名稱拒絕。

原六項資源建立、逆序失敗回滾與靜態拒絕完整保留，共十一項 `tools/核對P17結構建立切片.py` 名稱 Gate。所有 Rust 測試仍由原全量工作真正執行一次，並跑 F00/G6；不修改公開 CLI、未決語言語意或資源事件來源。
