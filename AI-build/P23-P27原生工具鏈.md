# P23～P27 原生工具鏈

## P23 共用表示與 G05 選型

公開模組入口產生的 LinkedProgram 持有來源快照與已連結的型別化 Program。兩種模式都須先完成相同的型別、所有權、跨模組借用驗證，再從 checked_plan 取用計畫。來源變更須重新準備。舊式單檔檢查維持原有支援範圍；公開模組入口目前支援直線函式。P18、P19 的內部完整案例仍依原入口驗證。

首個後端選擇轉譯為安全 Rust，由 stable rustc 在 Linux x86-64 GNU 環境連結。以現有有型別的動作、運算式及來源位置為共用表示。原生成功結果以 int 的低八位作程序結束狀態；執行失敗寫入 stderr 並退出 1，與合法值 1 依 stderr 區分。公開 run 維持輸出完整 int。後端尚未支援的動作必須明確拒絕。

共同樣本涵蓋基本加法 5、跨檔呼叫 42、錯誤型別、有效借用期間寫入及編譯前來源變動。P22 的 CLI 案例繼續覆蓋名稱遮蔽、診斷順序與跨檔錯誤位置。

## P24 最小原生程式

以 voiles build 入口.voil -o 產物 建置。支援 int 區域變數、重賦值、加減、同步無參數跨檔呼叫及 bool 常值 if/else 兩側各直接回傳純 int 運算。兩側都先檢查，執行時只求選中運算。保留溢位、來源位置、步數及呼叫深度限制。建置於輸出所在目錄暫存，成功後才發布至新檔名。
