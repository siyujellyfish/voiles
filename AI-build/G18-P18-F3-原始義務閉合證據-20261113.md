# G18／P18.1-F3：原始函式呼叫位置正式義務閉合證據（2026-11-13）

## 正式收口範圍

F3 僅包含**已由原 Checker 核准**的 return、宣告初始化、賦值、if／else-if／else、for／while 本體與其可達控制分支的真動態函式調用。原 Checker 已禁止 while 直接函式條件、非 bool 的 if 條件，必須保留拒絕；不擅自新增 while 條件函式副作用或語意。

本批與已驗收 F2 的差異，是函式**出現位置與控制可達性**，而非重新計算 F2 借用規格。所有測試都實際由原 Checker 生成 TypedHIR，執行原顯式函式堆疊，驗證真 ResourceId/BorrowTicket 記錄和不可達零事件。

## 安全與驗收控制

- 不替代原 Compiler Checker 的非法條件拒絕；不依據函式名稱猜測動態可達圖；未真正到達的分支沒有 OwnedResource 與 BorrowTicket。
- F3 的 `closure_proof` 只在 PR 最新 HEAD 三項必要 CI 均 completed/success，確認作者/base/mergeable 並 Squash merge，且合併後 **main 同一 SHA** 三項必要 CI 均 completed/success 時正式認列。
- F1/F2/F3 各自 Closed；F4 及其餘 23 條仍 OpenEngineering，P18.1 仍 SubsetVerified，P18 六 Phase 保持 0/6 Passed。下一工程批為 V1 F4 可達靜態函式圖權威閉合。
