# G18／P18.4-B4／M3：同步 self 方法直接 Return 純 helper 的共通退出邊（2026-11-14）

## 已驗收起點與靜態權威

本批從已 Squash merge 且主線三必要 CI 全部 `completed/success` 的 `main 53558c7da3c8dcc2eae5b4d0f92241de118c5d40` 開始。PR #766～#768 已接通原 Checker 合法、零至多個 Copyable `int` 形參的單一純普通 helper，在 main 局部、同步 self 方法局部初始化與 `var int` 直接 RHS 真求值，支援原 Checker `TypedHIR`、精確 `DeclarationId`、呼叫者先求參、溢位時已進入／完成函式分別計數和 R05 內後外清理。

**本批真缺口**：原 `method_checked_int_locals` 對方法末尾的 `return helper(n+1)` 仍呼叫 `pure_int(..., false)`，且受限執行器的 `return_calculation` 僅接受無 `Call` 的 `CheckedScalar`。即使同一原 Checker 已核准這個無副作用純 Copyable `int` helper 的呼叫形式、參數和返回型別，合法的返回邊被錯拒，無法驗證普通函式的真正返回點位於 self 借用存活期間。

## 只接通原 Checker 核准的直接 Call

- 原 `safety_checker.rs::method_checked_int_locals` 對最後 `StmtKind::Return` 以既有 `pure_int(..., true)` 驗證，只接通**整個返回運算式即是**同一 `helper(...)` 的合法 Call 或原來已核准純 int 返回。二元加減的子節點仍遞迴使用 `false`，`return 1+helper(...)`、巢狀 Call、非 Copyable、未核准函式、bool/str/await 一律不因此開放；返回仍由原 `self.evaluate`、原 Scope 和 `TypedHIR` 真實驗證。
- `PreparedPrivateSelfMethod::prepare` 只在方法有**已被原 Checker 逐句驗證的 int 局部**時，對末尾返回 `PrivateScalarReturnExpr::from_checked_bindings` 取得與原 Lexer／Parser／TypedHIR 一致的工作圖；若有 Call，必須是**唯一整筆直接 Call**，由 `private_self_matches_helper_call` 校驗同一已封存 `PrivateSelfApprovedHelper` 的原名稱、完整 int 參數數量、無 await 和純值 argument HIR。任何內嵌、未知與資源 Call 仍 `Unsupported`。原 `matches_source` 將 `return_calculation`、參數、helper 和所有原 Checker 證據對照真重編計畫。
- 在 `execute_with_fault` 中，已拿到唯一原 Checker `self BorrowTicket` 且執行完已核准方法局部宣告和重賦值後，才進入 `return_calculation::CheckedScalar` 的真正退出邊；**先由呼叫者當前 `parameter_frame` 求完全部 int arguments**，再 `FunctionEntered`，在 helper 獨立 int frame 中求原返回 HIR，成功 `Returned`／`FunctionExited(true)`／`ordinary_calls_completed`，最後才記外層方法 `Returned` 和清理局部、`LoanReturned`、`FunctionExited(true)`。不允許 prepare 階段假執行。
- 若**Caller 求參溢位**：helper 根本未進入，不記 helper `FunctionEntered`；最外層記唯一 `UnwindStarted`，逆序 ScopeEnded 已初始化方法局部及歸還唯一 self 票據。若**helper 真本體溢位**：已進入者先記唯一 `UnwindStarted`、`FunctionExited(false)` 退出內層，再逆序清理外層方法局部與歸還原 BorrowTicket，失敗不偽造成功 Returned 或幽靈資源 ID。
- 本批**不改變**方法中途的 `if`／`else` 語意，不放開方法內控制分支局部、任意混合 self 欄位算式、str／Move／Borrow／P16 非 Copyable 資源及 async。B4/M3 仍 OpenEngineering，P18.4/P18.5 仍 SubsetVerified。
