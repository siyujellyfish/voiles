# P15.3 非 Copyable 函式／方法預設借用跨分支及迴圈來源（2026-10-30）

> 依已核准 VA15-01-A、HC14-A、D04-A 與最新 #253／#254 的預設借用來源實作，新增實際控制流程交叉回歸。此為候選證據，不直接簽核 P15.3／P15.6 或 P16。

## 核准契約

- 函式與方法非 Copyable 具名參數依核准規格可暫時借用，借用歸還在該呼叫作用域退出；若被呼叫端實際消耗參數，則必須明確提供所有權轉移。
- VA15-01-A 每條可達分支處理真正最後使用點；迴圈反向邊及 break／continue 的外層資源／借用狀態必須安全穩定。
- D04-A 的正向整數半開區間對已確認零次／單次／多次保持各自的靜態可達性；不得默認非 Copyable 來源可跨輪反覆移動。
- HC14-A 活躍獨占別名禁止再次取得相同來源的函式借用；詞彙遮蔽不能把內層新來源誤當外層持有者。
- 方法 self 仍由行為推導借用模式，不因新增函式參數借用規則而隱含複製、消耗或跨函式逃逸。

## 新增八項真實來源回歸

1. if／else 雙側各借用同一 str，合流後可安全移動。
2. 巢狀 if 中的 const str 借用退出後可再次呼叫。
3. 已知單次 for 內借用後 continue，迴圈後可移動原持有者。
4. 多次 for 內反覆借用但不移動，迴圈後原來源仍可移動。
5. while 中 struct 方法參數借用後 break，迴圈後可移動原來源。
6. 多次 for 內借用後再移動同一資源，必須因不穩定反向邊拒絕。
7. 分支內仍會於外層再次使用的獨占別名，不能被函式呼叫提早解除。
8. 迴圈區域內同名資源遮蔽，不得把內層借用／所有權變化套用到外層來源。

## 待驗收界線

- 本批不增設新語法或資源執行期；仍無法藉此聲稱支援一般函式呼叫重入、例外／await 資源清理、非 Copyable 全結構跨函式所有權操作的完整路徑。
- P15.3／P15.6 原始完整條文、P15 Phase 與 P16 六項，須維持獨立稽核與正式方框，不能由單批測試直接推定完成。
