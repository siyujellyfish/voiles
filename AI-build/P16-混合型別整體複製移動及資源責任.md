# P16 混合 Copyable 純值與唯一 UTF-8 資源結構工程（2026-10-30）

> 接續 #261 真正 .voil 欄位原子覆寫完成；本批以 S19 所有欄位 Copyable 的合取規則及 VB16-01-A 真正求值計畫，加入 int／bool／str 混合私有執行期。此模型不等同 P17 通用直譯器，也不新增 float 或容器語意。

## 已核准安全契約

- 已核准 int／bool 純值為 Copyable；str UTF-8 緩衝區非 Copyable。只有每個已初始化欄位皆 Copyable 才允許整個結構獨立複製，絕不可直接複製含 str 的實例。
- 所有權整筆 .move() 不保留第二持有者；完成初始化依來源具名順序及未覆蓋預設宣告順序，最後與失敗時逆序清理真正取得的 String 資源。
- 非資源純值 int／bool 不能產生 Created／Moved／Returned／Released 假事件；資源帳簿必須能逐 UTF-8 身分證明沒有重複清理或洩漏。
- 未初始化 var 欄位在未補齊前不能整筆移動、複製或返回；跨函式返回不可以將未完成結構當作完整所有者。

## 實作

- 新增 src/mixed_struct_runtime.rs 的內部 MixedStructRuntime：依共用 VB16 評估計畫配置混合結構欄位；純值 Int／Bool 是實際具型別值，Str 擁有真正 OwnedUtf8；真正的失敗注入在已確認求值步驟後回滾本次已取得資源。
- 實作完整整筆 move、純值 Copyable 結構的獨立複製與含 str 結構的保守拒絕，和逐欄位真實 Returned、作用域反向清理、接收衝突時的顯式資源回收。
- src/struct_initialization.rs 既有持續 str-only 模型也新增「尚未補齊欄位不得整體 move／return」的拒絕，並有補齊後成功轉移正例。
- src/struct_stage.rs 新增真正 Lexer／Parser／Checker → MixedStructRuntime 受限來源橋接。只接受 main 直線的結構建構、同型別整體 .move() 或 Copyable 一般複製、return 0；從真實 AST 解析 int、bool、未經轉義 str 常值，對未證明混合運算式保持拒絕。

## 驗證

- 10 項混合執行期模型來源：混合欄位、真緩衝整筆 move、含 str 隱含複製拒絕、全純值結構合法複製、混合失敗只釋放 str、求值前型別錯誤、跨作用域 return、接收衝突責任、部分初始化拒絕，以及內外層清理。
- 2 項 str-only 未完成結構整體轉移／返回防護。
- 8 項真正 .voil 來源：混合建立與整筆 move、Copyable 純值結構複製、str 混合非法隱含複製、具名及預設故障清理、未知故障點、部分初始化、未支援多語句保守拒絕。
