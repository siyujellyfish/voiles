# G18／P18.1-F2：原 Checker 巢狀 str-return 暫存實參

## 實作範圍
本批從既有原 Checker 可接受的 `outer(inner())` 同步字串來源擴充私有標量工作棧，不改語言對外入口、語法、型別、安全權限或 V7 E1～E5：

- `NestedStrCall` 只由既有 `checked_str_initializer` 核對過的同步 `str` 函式產生，完整 int／bool／str 混合引數仍逐層驗證原 Checker `call_borrows`；字串 literal、不具名來源或隱式複製不偽裝成已 Returned 暫存。
- `queue_call_arguments` 讓內層函式的全部引數依原 Parser 順序在顯式工作棧求值，內層真 `ExitCall` 完成之後才把 Returned 的唯一 ResourceId 記作外層完成實參。
- `OwnedStrRuntime::accept_returned_argument_as` 以 **同一個 OwnedUtf8** 接入原 Checker 指定的正式 str 形參，成功後產生真 `Moved(id)`，不 `clone`、不重新配置、不合成來源 DeclarationId。
- `StrTemporaryTransferred {target, resource_id}` 使 trace 審計檢查 caller 的已 Returned 暫存、callee 原始形參 ID 與跨框架轉移；接續真 OwnedResource::Moved 與 ResourceOwnerBound。偽造 ID 或重複綁定拒絕。
- 每個動態框架 `pending_owned_returns` 保留自身仍須釋放的暫存 ID。成功消費時從原 holder 移除；失敗時在該框架 `FunctionExited(returned:false)` 之前逆序真實釋放，且借用票據仍先交還。
