## 最小修正

在 `src/struct_stage/execute_method_self.rs::execute_with_fault` 開始、任何 main helper、MixedStructRuntime OwnedStr、BorrowSafety.acquire、方法 Return 與 Event 建立之前，新增對**原先封存的** `verified_private_source_tokens(text, &self.verified.tokens, &self.verified.structs, &self.verified.functions)` 的精確、唯讀驗證，失敗一律 `SourceChanged`，不改任何動態事件。本稽核仍由原 `token_provenance.rs` 的單一權威驗證以下事實：

- async self 方法來源必以實際六相鄰詞彙 `await`、owner、`.`、method、`(`、尾端 `)` 及正確半開 NodeSpan 綁定；不能只保留合法 HIR 就把 receiver 或 method 偷換成另一個名稱。
- 原 `async fn` 標頭、欄位／參數宣告與其真 Lexer Token 仍須一致；不可在準備後把 async 改為同步而保持已通過的原 CheckedBorrowFact。
- 把 `AwaitMethodCall` AST 改成 `MethodCall` 即使仍保留真 `await` 文字也必拒；同步方法的原正向執行照舊允許。
- 這不是新的 Lexer、Parser 或型別器，不重新 parse 動態來源、不創建新 `BorrowTicket` 或 `ResourceId`、不修改 S20、VB15-01-A、已決 V7 E1～E5、公開 CLI 和同步資源清理契約。
