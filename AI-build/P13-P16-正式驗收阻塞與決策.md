## 一次裁決的七項獨立 A／B

### VA14-01：一般 .borrow() 的借用結果表示
- **A（建議）**：沿用已核准 var／const 型別宣告外觀，內部另外記錄「借用非擁有」資格、來源宣告身分及跟隨來源的可變性；借用值不能視為整筆擁有者，也不能移動來源。
- **B**：新增明示的借用型別標註，型別文法及一致性檢查須後續核准。
- 不更動既定函式參數預設借用、方法 self 自動借用與既有 var／const 限制。

### VA14-02：一般 .borrow() 的共享／獨占種類
- **A（建議）**：依「借用可變性跟隨來源」將 const 來源視為共享唯讀、var 來源視為獨占可寫，並遵循 HC14-A 同時借用衝突。
- **B**：一般 .borrow() 預設共享唯讀，獨占借用另設專用授權方式；語法還要獨立裁決。
- 方法 self 已核准依方法行為推導借用種類，不因選項而更動。

### VA15-01：一般借用的最後使用點與多路徑合流
- **A（建議）**：靜態檢查每條可達路徑的真正最後合法使用點，所有路徑都結束才歸還；合流尚有有效借用時繼續封鎖來源。
- **B**：本階段一般借用到詞彙區塊出口才歸還，精細最後使用點待獨立驗收。
- 函式參數與方法 self 原有作用域歸還點不變；跨 await／例外保持未決保守拒絕。

### VA15-02：非 Copyable self 欄位借用回傳與逃逸
- **A（建議）**：無法證明回傳借用來源存活的逃逸一律拒絕，非 Copyable self 欄位先保留 P13 已核准的拒絕政策；Copyable 獨立值回傳不變。不是永久語言禁令。
- **B**：P15 即建立來源區域與回傳區域的精確關係，只有靜態證明擁有者比借用存活更久才允許回傳。
- 兩方案皆禁止由借用偷渡 str 隱含複製。

### VA16-01：str 最小資源執行期表示
- **A（建議）**：先以單一所有者持有的 UTF-8 緩衝區實作最小資源值；.move() 轉交資源責任，借用不建立新所有者；Rust 宿主 Drop 不等於 voiles 清理順序。
- **B**：使用 voiles 執行期集中管理的資源識別／堆區控制表，實際釋放與引用表示另外核准。
- 不因此決定 list／dict Copyable、Optional 或 P19 API。

### VA16-02：作用域、返回及失敗清理順序
- **A（建議）**：已成功初始化的持有值按完成初始化的相反順序清理；return／.move() 已轉交值不在原作用域釋放；失敗僅回收已取得責任的資源。
- **B**：按成功初始化的原順序清理，維持相同轉交與失敗回收要求。
- 均禁止重複釋放、遺漏清理，不透過 GC 掩蓋錯誤。

### VA16-03：有效非 Copyable var 值被重新賦值
- **A（建議）**：先驗證與求值右側，再原子提交新值並清理舊資源；求值失敗時舊值保持有效，清理尚未轉交的臨時資源。
- **B**：本階段維持拒絕有效非 Copyable 資源整筆覆寫，只允許尚未初始化或移動後的重新繫結，其他覆寫另行驗收。
- 兩方案均不改 str 禁止隱含複製及 S18 const 規則。
