# G18／P18.6-M2：原 Checker if true 葉獨占 self.int 寫入與 false 葉零副作用（2026-11-13）

## 施工來源與真正缺口

已在 `main dfab8b3e40f3ca6372d8ca8abc1a0843d9056fa7` 完整驗證上一批同步 self 方法 `if(flag) { return self.n } else { return 22 }` 的原 Checker 真選枝。M2 仍有重要控制圖缺口：當 true 葉**可能寫入** `self.n` 時，原 Checker 的 `method_writes` 已將整個方法認定為 `BorrowKind::ExclusiveWrite`，但舊 Runtime 只看方法**最外層第一句是否 FieldAssign** 判斷借用模式，於是即使靜態合法也保守 Unsupported，無法完成真條件式寫入／歸票。

## 此批最小原 Checker→Runtime 合法增量

唯一支援的新增形狀：
```voiles
struct Counter{
var n:int = 7
fn read(flag:bool)->int{
if(flag){
self.n = 19
return self.n
}else{
return 22
}
return self.n+1
}
}
fn main()->int{
var owner:Counter = Counter()
return owner.read(true)
}
```

- 仍由**同一個** `verify_source_with_ability`、原 Parser `StmtKind::If`、`VerifiedMethodSafety.checked_returns` 與原 Lexer 的同一起訖跨度驗證，不建立另一份 Checker。if true 葉只允許一筆 `self.<唯一 Copyable var int 欄位>=<Lexer int 常值>`，再立即一筆 `return self.<同欄位>`；未核准的 else 多語句寫入、一般借用別名再借、Move、async、迴圈、任意嵌套控制流程繼續拒絕。
- `method_branch_write` 封存原 FieldAssign 的**值及 NodeSpan**。來源重新編譯比對包含這個新欄位：改寫值／位置必須在動態配置前得到 `SourceChanged`，不能只憑返回值碰巧相等就放行。
- 整個方法的安全權限從**所有可能分支**推導：只要 true 葉可能寫入，方法入口就必須持有原 Checker 認定的 `ExclusiveWrite` 真 BorrowFact；如果接收者／欄位不可寫，無權取得獨占票據。
- Runtime 只在**真正進入 self 框架後**從原 bool 形參動態槽或 bool 常值判斷，僅 true 葉在核實原 `BorrowTicket` 獨占授權後寫入 `MixedStructRuntime`，再以同張票據讀回最新欄位值。false／else 路徑即使方法已取得獨占票據，也**完全不寫入**；未到達的最後 return、算術溢位不得提前執行。
- `branch_write_applied` 是**真 Runtime 結果**而不是預先偽造的執行旗標，與 `expected_branch_write`、`branch_checked`、正常返回及真進退帳共同稽核。方法入口故障時 true 葉不曾選中，不得虛構寫入或 Returned，必須按照原 Tracker 安全點退還唯一票據；此純 int 子集仍無任何 UTF-8 資源事件。

## 八條固定真來源正反 Gate

`src/struct_stage/g18_m2_conditional_write_tests.rs` 與 `tools/核對G18-P18.6-M2獨占self分支寫入.py` 包含：

1. bool true 葉從真獨占票據實際寫入 `19`、讀回 `19`，只回傳一次；
2. bool false 葉取得原 Checker 必要的獨占票據，但未選中 true 葉、未寫入；
3. false 且沒有 else 時落入最後 return，仍讀到原欄位值 `7`；
4. true 提前返回不可到達的溢位計算不產生故障；
5. 方法入口注入故障未選葉、無寫入、沒有成功 Returned，卻真歸還 self 借用；
6. true 葉的原欄位寫入值／Lexer 位置被篡改，必於執行前拒絕；
7. const 欄位與不可寫接收者，原 Checker／已核准保守權限防線拒絕；
8. else 未獲得跨分支寫入證據時，不因另一個 true 寫入葉而提前放行。

專用 Gate 使用 `--list` 精確核對全部八個 Rust 名稱，並逐項 `--exact --test-threads=1` 真執行，逐項要求 `1 passed／0 failed／0 ignored`；接入既有必要 Rust CI，所有 P13～P17／F00～G17／G18 回歸與 V0/R07 原義務一致性照舊嚴格執行。
