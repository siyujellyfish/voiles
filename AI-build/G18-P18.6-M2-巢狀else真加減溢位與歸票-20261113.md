## 本批封閉的可證子集

```voiles
struct Counter{
var n:int = 7
fn read(flag:bool)->int{
if(true){
if(flag){
return self.n+5
}else{
return self.n+3
}
}
return self.n+1
}
}
fn main()->int{
var owner:Counter = Counter()
return owner.read(false)
}
```

- 只在原 Checker 已核准的巢狀 `else` 一條 `Return` 葉內接受 `self.int`、`self.int + 原 Lexer int`、`self.int - 原 Lexer int`。左端必須是原 Parser `TermKind::FieldRead(self,真欄位)`，右端必須是原 Lexer 精確 `Integer` token，運算子必須與原 Parser `BinaryInt` 及原來源中間範圍一致。這些約束沿用已通過 true 葉驗收的同一檢查方式，沒有新增型別推導。
- `method_nested_else_calculation: Option<PrivateSelfIntReturn>` 獨立封存原 Checker inner-else Return 的真 Copyable int 計算；必與原 `method_nested_branch` 同時存在，且 inner-else `NodeSpan` 必由 `VerifiedMethodSafety.checked_returns` 確認。重編 `matches_source` 強制逐欄比對，篡改常值、運算或 Return 身分在 Runtime 前拒絕。
- Runtime 僅在**外層已真正進入 true 葉且內層原 Checker bool 形參實際選中 false** 時，才從原同一 self BorrowTicket 授權讀取 `MixedStructRuntime` 的最新 int 欄位並執行 `PrivateSelfIntReturn(Add/Subtract)`。內層 true 或外層 false 時不得求值未選中的巢狀 else，即使該式會溢位。
- 真正達到溢位時回傳既有 `IntegerOverflow`，沿用 R05 `UnwindStarted`、零成功 `Returned` 與唯一 `BorrowSafety` 退票。Copyable int 不建立假的資源事件；未解決非 Copyable Move／Borrow、複合 CFG、async。

## 八項真 Rust 獨立 Gate

`src/struct_stage/g18_m2_nested_else_arithmetic_tests.rs` 與 `tools/核對G18-P18.6-M2巢狀else加減溢位.py`：

2. 動態 true 不執行 else 計算，只返回 `7+5=12`；
3. false 的原 Checker 減法 `7-20=-13`；
4. false 到達 `7+i64::MAX` 溢位，真 Unwind、零 Returned、還票；
5. 內層 true 跳過必溢位 else 算式；
6. 外層 false 甚至不進內層，跳過必溢位 else，合法尾端返回 `8`；

8. 原 Checker 拒絕 `self.n+true` 與不存在欄位，禁止 Runtime 視為合法。
