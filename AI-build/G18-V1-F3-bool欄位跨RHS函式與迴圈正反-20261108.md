## 避免重複實作與採證

原 PR #661 在施工期間遇到 #660 先合併相同功能，因此已正式關閉且**未合併**，避免把第二份相同 bool 欄位執行器覆寫新的主線。已經過 #661 原 Checker 真測試的四項**非重疊**來源轉移到這個獨立 PR，其他三項重複 if、溢位、事件造假案例仍以既有 #660 為唯一主要正反。不以計數重複替代原義務。

新增的真正例：
1. 同一結構的 `f.left = f.right` 與後續 `f.right = false` 有序求值，`if(f.left)` 必仍讀得先前的 `true`。驗證 RHS 不從預設值重播，且不偷改已讀持有者。
2. 兩次普通函式呼叫 `route(false)+route(true)`，各自實際執行所選的 if 葉，將更新後的 `bool` 欄位傳給另一個真函式；未選葉不製造額外 `CopyStructBoolFieldAssigned`。
3. 真 `for i in 0..2` 的 `continue`，緊接以同欄位進 `while`，在本體真更新為 false 並 `break`；核對三次寫入與返回值，而非僅做獨立迴圈單項。
4. `const` 實例、`const` 欄位及 `int` RHS 寫入 `bool` 皆須先由原 Checker 靜態拒絕，不能碰到 P16 動態寫入操作。
