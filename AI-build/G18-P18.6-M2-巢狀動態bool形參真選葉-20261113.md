## 允許的最小真來源

```voiles
struct Counter{
var n:int = 7
fn read(flag:bool)->int{
if(true){
if(flag){
return self.n+5
}else{
return self.n
}
}
return self.n+1
}
}
fn main()->int{
var owner:Counter = Counter()
return owner.read(false)
}
```

- 內層 `if` 條件由原 Parser `TermKind::Name`、原 Lexer `TokenKind::Name` 的**精確半開 UTF-8 來源範圍**，以及 `VerifiedTypedMember(Parameter)` 和 `DeclarationId` 綁定到同一原 Checker 真 `bool` 形參；不另外推導 bool 型別、不能把 int／str 隱含轉型。
- 原先 Lexer bool 常值的分支繼續沿用，動態形參只增加 `method_nested_branch_parameter: Option<DeclarationId>`。原 `method_nested_branch` 的 bool 值／內層 else 真 ReturnSpan、`method_branch_return` 的原 Checker 計算、`VerifiedMethodSafety.checked_returns` 兩葉原位置及唯一 BorrowFact 全部保留。篡改任何計畫欄位都會在 `matches_source` 用原 Checker 重新編譯比對後拒絕。
- 真方法框架已在簽發 self 借用前依原 Checker 形參建立 `bool_parameter_frame`。Runtime **只在外層 true 已真正到達時**從同一 `DeclarationId` 讀取內層 bool；重新核對其真值與已封存的 Checker 來源值一致，將 `nested_branch_checked` 填入真執行事件。外層 false 時不可執行、不可觀測、不可計算內層。
- 所有 `self.n` 讀取、真整數加減、溢位與返回仍透過已有唯一真 BorrowSafety `BorrowTicket`、共享 R05 退出記錄與逐框架歸票，不放寬原所有權／借用安全；本批無獨占寫入、不接通一般函式呼叫、資源 Move、async 或新增語言規格。

## 八項獨立真 Rust 正反

檔案 `src/struct_stage/g18_m2_nested_dynamic_bool_tests.rs`，正式 Gate `tools/核對G18-P18.6-M2巢狀動態bool形參.py`：

1. 外層常 true、內層真 bool 形參 true，傳回 `7+5=12`，唯一 Returned。
2. 外層常 true、內層形參 false，傳回 `7`，不執行 true 葉。
3. 外層和內層共用同一已驗 Checker bool 形參、值 false，外層直接落至尾端 `8`，內層未觀測。
4. 外層和內層共用同一形參、值 true，才進入巢狀並返回 `12`。
5. 內層形參 false 不得執行另一葉的溢位算式。
6. 內層形參 true 已到達 i64 溢位，原 `UnwindStarted`、沒有正常 Returned，真借用歸還。
7. 封存的內層 bool 形參 `DeclarationId` 或預期 bool 真值遭修改時，執行前須 `SourceChanged`。
8. 內層非 bool int 條件或未宣告 bool 名稱，原 Checker 直接拒絕，不給 Runtime 新捷徑。
