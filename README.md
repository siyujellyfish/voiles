# voiles

voiles 是規劃中的自製程式語言。本儲存庫目前以語言設計與開發規劃為主，**尚未提供可執行的直譯器或編譯器**。

## 新版語言設計方向（初步草案）

自 2026-10-23 起以新版草案為準，暫捨棄此前版本的具體語法規格。新版目前包含：

- 型別：`int`、`float`、`str`、`bool`、`list[T]`、`dict{K,V}`、`none`，以及具多型別聯集／缺失值語意的 `Optional`。**Y05/Y06、Z01–Z04、AA01–AA06 已細化 D11**：Optional 僅可作為**容器元素或字典值型別**（如 `list[Optional[int,str]]`、`dict{str,Optional[int,str]}`），允許單候選 `list[Optional[int]]`。**AA01** 禁止 Optional 直接巢狀，**AA02** 重複候選為靜態錯誤，**AA05** 候選型別排列順序不影響型別身分；不得自動刪除重複候選。合法 Optional 值可用 **`== none` 判斷缺失**、**`!= none` 判斷有值**（AA03），且 **`none` 必須有合法已知 Optional 型別上下文**（AA04）。合法容器元素／字典值 Optional 位置可直接用 `none` 或符合候選型別的非缺失值（AA06），不需額外包裝。裸用 Optional 的一般獨立宣告與容器操作結果型別未獲核准；不解除 `str == str`／`str != str` 禁令。**AB01** 至少要求一個候選；**AB02** 候選必須是非容器型別，不能 `Optional[list[int]]`；**AB03** 非缺失候選值必須符合列出的型別，不額外隱含轉換數值型別。**AB04** `x != none` 成立分支排除缺失可能，但保留候選型別集合；**AB05** 禁止將 none 放在比較左側；**AB06** 相同 Optional 型別的值可直接用在另一個合法容器 Optional 元素位置，複製／移動／借用與操作語法另議。**AC01/AC02** 確定 `x == none` 的假分支排除缺失、真分支確認只有 none；**AC03** 確定 `x != none` 假分支確認只有 none，AB04 真分支仍排除缺失；**AC04** 對已檢查變數合法重新賦值後取消先前縮限。**AC05** 相同 Optional 型別值亦可直接用於另一合法字典值位置，**AC06** 禁止 `none` 作 Optional 候選型別。**AD01** 離開 if／else 分支恢復完整 Optional；**AD02/AD03** and/or 右側不繼承左側 Optional 縮限，短路求值不變；**AD04/AD05** Optional 候選集合只可由子集直接用於超集合法位置，不可反向直接轉用；**AD06** 排除 none 且靜態確定唯一候選時可按候選型別使用。**AE01** 允許對合法缺失比較運用 `not` 反轉結果縮限；**AE02** 可追蹤儲存於 bool 變數的比較結果，來源／結果穩定性未決；**AE03** while 本體不因 Optional 缺失條件自動縮限；**AE04** 禁止自訂 struct 作 Optional 候選；**AE05** 允許 bool 候選；**AE06** 允許 int 與 float 同時作候選且不隱含數值轉型。**AF01/AF02** 直接合法重新賦值來源 Optional 或儲存比較結果的 bool 旗標後，取消既有缺失縮限關聯；**AF03** 允許尚有效的旗標關聯在內層作用域追蹤，**AF04** 允許以 `not flag` 反轉缺失判斷；**AF05** int／float 候選依來源靜態型別選擇且不隱含轉型，**AF06** bool／int 可並列為候選。**AG01–AG03** 明定 bool 比較結果的複製、函式參數傳遞及函式回傳**不帶 Optional 縮限追蹤關聯**，不影響一般 bool 值操作；**AG04** bool/int 候選依來源靜態型別選擇、不隱含轉型；**AG05** str/float 可並列但判別待議；**AG06** 多個獨立比較旗標可追蹤同一 Optional 來源，各自檢查失效。**AH01** str/float 候選依來源靜態型別選擇且不隱含轉型；**AH02/AH03** bool/float 及 str/bool 均可並列、具體判別待決；**AH04** 追蹤綁定原來源變數身分，不把外層縮限誤套到內層同名變數；**AH05** 函式呼叫完成後一律取消呼叫者既有旗標關聯，不表示函式一定有副作用；**AH06** 不設固定候選數量上限，原候選型別限制不變。別名／非同步、函式實際副作用、其他縮限、候選歧義、型別轉換、容器操作與所有權安全仍待議。
- 大括號 `{}` 劃定作用域，換行分隔語句且忽略空白行；圓括號內可跨行；`#` 支援程式碼行尾註解（J05），語句區塊至少一條語句，`if true{}` 不合法（J06）。一般 `var`、`const`、`share` **都必須標註型別**（H03、I01、I02）；`var x:int` 可以延後初始化，但讀取前必須通過靜態檢查（I05）；`const`、`share` 則必須在宣告時初始化。布林常值是 `true`、`false`，`int` 為有號 64 位元且溢位靜態可判斷即報錯、否則執行時報錯；整數常值可使用連續底線分組，如 `1__000`（I03/J01），十進位前導零如 `007` 等同 `7`（K03），並支援僅用小寫前綴的 `0xFF`、`0b1010`、`0o77`，以及非十進位連續底線 `0xFF__AA` 和前綴後底線 `0x_FF`（J02/K01/K02/L01/L02）。`float` 採 IEEE 754 十進位 `decimal64`，**不支援科學記號**，允許連續底線 `1__000.25`、小數點旁底線 `1_.25`／`1._25`，以及結尾底線 `1.25_`；浮點 `.5` 不合法（須寫 `0.5`），`1.` 表示 `1.0`（L03–L05）。**M01 已確認連續兩點 `..` 優先作區間符號**，所以 `1..4` 切分為整數 `1`、`..`、整數 `4`，單獨 `1.` 仍是浮點常值；前導零 `00.5` 與 `0.5` 同值（M06）。**T06 已裁決 I04：decimal64 預設最近值、恰好一半時取偶數捨入**；其餘異常與特殊值規則待決。一般字串常值只用雙引號（L06），允許空字串 `""`（M02），`\n` 為換行（M03）、`\"` 為雙引號（M04），`\\` 為反斜線（N01）、`\t` 為定位字元（N02）、`\r` 為歸位字元（N03）；未知跳脫為語法錯誤（N04），一般字串不得直接跨行（M05）。`"""` 多行註解可在程式碼**後方**同一行開始（N05），允許空註解 `""""""`（N06），但**不可巢狀**（O01），**結束後不得於同一行接續程式碼，須換行**（O02）。一般字串內的 `#` 是文字內容（O03），另支援 Unicode 跳脫 `\u{...}`（O04）及空字元跳脫 `\0`（O05）；`str` **不允許以 `+` 串接**（O06）。**Q01** 允許 Unicode 跳脫 `\u{...}` 內的前導零；**Q02** 對格式可辨識但無效的 Unicode 碼位（如 `\u{110000}`）使用替代字元 `�`，不擴張至格式錯誤。多行註解結束後允許空白再換行（Q03），普通字串**之外**連續三個雙引號優先辨識為多行註解標記（Q04）。`str` 不支援 `==` 相等比較（Q05）與 `*` 重複字串（Q06），先前 O06 的 `str +` 禁令仍有效；不據此確定 `str !=` 或其他型別運算。**T01** 確認 Unicode 跳脫十六進位英文字母大小寫皆可；**T02/T03** 新增 `\u{}` 與 `\u{GG}` 都轉替代字元 �，不影響未知跳脫的語法錯誤；**T04** 限多行註解結束後只能接一般空格或 Tab 再換行；**T05** 另外禁止 `str` 的 `!=`。**U01** 將 `\u{...}` 的十六進位數字上限訂為 6 位（含前導零），**U02** 規定缺少右大括號為語法錯誤；**U03/U04** 不允許碼位數字內的空白及底線，但其與 T03 替代字元規則的錯誤優先順序仍待決。**V01**：Unicode 跳脫內含空白（如 `\u{ 41 }`）為語法錯誤；**V02**：底線（如 `\u{1F_600}`）以替代字元 � 處理；**V03**：超過六位數字（如 `\u{0000041}`）為語法錯誤。Unicode 版本、字素比較、其他壞格式與註解詞彙邊界仍待議。
- 一般 `fn`、`async fn`，以及 `struct` 型別名稱、方法和欄位均預設公開；名稱以 `_` 開頭的函式、結構型別、方法或欄位只在同一模組內可見，跨模組不可存取。
- 結構 `struct` 的欄位與 `fn` 方法定義在同一區塊，不得同名；方法內明確使用 `self.欄位名稱`。實例 `var` 宣告須標註型別，如 `var s:Stru = Stru()`。具名或空參數建立、預設值每次建立重新求值，`var` 欄位允許延後初始化但讀前須靜態檢查；**F01 已修訂 D09：`struct const` 欄位宣告時必須有預設值，不允許延後首次寫入**；**F02：`const` 結構實例變數宣告時必須有初始運算式**。`struct` 必須至少一個欄位或方法，`struct Empty{}` 不合法（K06）；不支援巢狀／泛型結構或自訂專用建構方法；初始化與借用安全其他細節仍待決。
- `and`／`or` 採短路求值，`!=` 表示不相等（I06），`1..4` 不含 4；`return i+=1` 先更新後回傳新值。具名欄位引數不限制順序，未知／重複欄位靜態錯誤，尾逗號合法；具名值覆蓋預設值時不計算原預設值。一般函式呼叫及函式宣告參數列表均允許尾逗號，例如 `add(1,2,)` 和 `fn add(a:int,b:int,)->int{...}`。同一作用域不得重複宣告同名變數，但內層區塊允許遮蔽外層變數（H05/H06）；借用及完整名稱解析細則仍待決。
- 值的預設複製、明確 `.move()` 與 `.borrow()`；結構需所有欄位皆可複製才可複製，禁止只移動部分欄位。`self` 作為方法接收者只允許借用，方法不得消耗整個 `self`；方法之外仍可依已定一般規則明確移動整個實例，借用可變性與安全細節仍待定；字串第一層索引以 Unicode 字素叢集為單位，**U05 允許負數索引從尾端倒數**；**U06 規定第一層索引越界靜態可證明則靜態報錯、否則執行時報錯**。**V04** 允許第二層 UTF-8 位元組索引負數，從所選字素的位元組序列末尾倒數；**V05** 規定第二層越界靜態可確認則靜態報錯，否則執行期報錯。**V06 僅補充待決條件**：索引可否寫入須考慮 `str` 是 `const` 或 `var`，不表示 `var` 已核准索引賦值。**W04/X05**：第一層索引取得一個字素叢集，回傳**獨立複製的 `str`**。**W05/X01**：第二層 UTF-8 位元組索引讀取回傳既有 **`int`（0–255）**，**X03 禁止第二層單一位元組索引賦值**。**X02** 要求第一層索引賦值的替換值恰一個字素叢集；**X04** 允許替換前後 UTF-8 位元組長度不同。**W06-B**：字素分割依執行環境 Unicode 版本。**W01–W03** 字串寫入權限仍遵守 `var` 可變、`const` 不可變與 `share` 宣告作用域內修改；**X06** 確認模組級 `share str` 可由同模組其他函式修改，跨模組仍不能寫。**Y01** 允許第一層字素替換後與相鄰內容合併，依修改後字串重新判定字素邊界；**Y02** 違反恰一字素限制時靜態可確認則靜態報錯，其餘執行期報錯；**Y03** 索引賦值可作為運算式，結果為寫入的字素 str（結果持有方式未決）；**Y04** 同模組函式修改模組級 share str 不需額外標記。**Z05** 已確認第一層字素索引賦值運算式結果為**獨立複製的字素 `str`**；**Z06** 已確認每次字素替換完成後立即重新判定修改後字串的字素邊界。UTF-8 寫入安全與原子性、索引失效、運算式求值順序、借用／所有權、跨環境 Unicode 差異及資源管理仍未決。原始碼副檔名 `.voil` 已確定。

以下僅為設計語法示意，**目前不可執行**。原始碼副檔名 `.voil` 已依 D13 核准，但模組載入語意仍待確認：

```voiles
# a.voil
share count:int = 5

fn read_count()->int{
    return count
}

fn _helper()->none{
    # 模組內部函式
}
```

```voiles
# main.voil
import a

fn main()->none{
    print(a.read_count())  # 公開函式
    a._helper()            # 錯誤：不能跨模組呼叫內部函式
}
```

## 專案狀態

新版語言設計與 `struct` 21 項批次決策已有一致的文件基準；**正式規格的權威來源是新版 [AI-build/語言規格-v0.2.md](AI-build/語言規格-v0.2.md)**，檔名沿用歷史但內容已取代舊版 v0.2。原 P01 舊合併請求 #4 已關閉、不應合併。D11 經 Y/Z/AA/AB/AC/AD/AE/AF/AG/AH 批次已確定 Optional 僅容器元素／字典值型別、至少一個非容器候選、禁止直接巢狀與重複候選、候選排序不影響型別身分、none 必須有合法上下文且只能置於比較右側。已定型 Optional 的 `x == none` 判斷缺失、`x != none` 判斷有值；後者成立分支排除缺失可能但不減少候選型別。合法容器元素／字典值位置可直接使用 none 或符合候選的值（不添加隱含數值轉型）；相同 Optional 型別值可用於另一合法容器元素位置。一般獨立裸用 Optional 宣告與容器方法結果型別仍不在核准範圍；AC01–AC03 已補定 Optional 比較的相應真／假分支缺失判斷，AC04 在合法重新賦值後取消先前縮限；AC05 准相同 Optional 值用於另一合法字典值位置，AC06 禁止 none 列為 Optional 候選。AD01–AD06 另已確認分支退出後縮限復原、and/or 右側不繼承縮限、Optional 候選集合子集向超集單向使用、禁止逆向直接使用及非缺失唯一候選的型別使用資格。AE01–AE06 另確認 not 反轉合法 Optional 缺失比較可縮限、bool 存放比較結果可追蹤但穩定性未定、while 本體不自動縮限、自訂 struct 禁作候選、bool 可作候選及 int/float 並列不隱含轉型。AF01–AF06 再確定來源或旗標直接重新賦值後舊追蹤關聯失效、內層有效關聯追蹤與 not flag 反轉、int/float 依來源靜態型別判別及 bool/int 並列。AG01–AG06 補定 bool 複製、函式參數及回傳不帶追蹤關聯，bool/int 按來源靜態型別選候選、str/float 可並列但判別待議，以及多旗標對同一來源各自追蹤與失效。AH01–AH06 已將 str/float 候選判別限定為依來源靜態型別且不隱含轉型；允許 bool/float 與 str/bool 並列但判別未定；追蹤與原來源變數身分綁定，函式呼叫後呼叫者舊旗標關聯一律失效；候選數量不設固定上限而全部既有型別限制仍有效。其餘縮限、別名／非同步穩定性、候選判別、型別轉換、跨容器複製／移動／借用、API、Unicode／UTF-8 及資源安全尚未封閉。全語言的形式文法、型別與借用安全規則尚未封閉。已在 [語言規格的統整與範例](AI-build/語言規格-v0.2.md) 提出一份結構示範程式及預期拒絕的反例，**僅供規格討論，沒有可執行或通過編譯的宣稱**。程式碼實作、編譯模式、開發工具及發行方式均需以後續已核准且已驗證的成果為準。
