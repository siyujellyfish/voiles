# voiles

voiles 是規劃中的自製程式語言。本儲存庫目前以語言設計與開發規劃為主，**尚未提供可執行的直譯器或編譯器**。

## 新版語言設計方向（初步草案）

自 2026-10-23 起以新版草案為準，暫捨棄此前版本的具體語法規格。新版目前包含：

- 型別：`int`、`float`、`str`、`bool`、`list[T]`、`dict{K,V}`、`none`，以及具多型別聯集／缺失值語意的 `Optional`。
- 大括號 `{}` 劃定作用域；`var`、`share`、`const` 宣告資料。
- 一般 `fn`、`async fn`，以及 `struct` 型別名稱、方法和欄位均預設公開；名稱以 `_` 開頭的函式、結構型別、方法或欄位只在同一模組內可見，跨模組不可存取。
- 結構 `struct` 的欄位與 `fn` 方法直接定義在同一個區塊內，欄位與方法不得同名；方法以 `self.欄位名稱` 明確存取自身欄位。實例的 `var` 宣告強制標註型別，如 `var s:Stru = Stru()`。結構可用具名參數或空參數建立、允許欄位延後初始化但讀取前需靜態檢查，欄位預設值每次建立重新求值；目前無自訂建構方法，也暫不支援巢狀或泛型結構。其餘詳細語意請以 `AI-build` 為準；模組 `import`、條件、迴圈、比對、`try/except` 與 `async fn/await` 亦屬規劃。
- 值的預設複製、明確 `.move()` 與 `.borrow()`；結構需所有欄位皆可複製才可複製，禁止只移動部分欄位。`self` 作為方法接收者只允許借用，方法不得消耗整個 `self`；方法之外仍可依已定一般規則明確移動整個實例，借用可變性與安全細節仍待定；字串依字元及其 UTF-8 位元組雙層索引。

以下僅為設計語法示意，**目前不可執行**：

```voiles
# a.voil
share count:int = 5

fn read_count()->int{
    return count
}

fn _helper()->none{
    # 模組內部函式
}
```

```voiles
# main.voil
import a

fn main()->none{
    print(a.read_count())  # 公開函式
    a._helper()            # 錯誤：不能跨模組呼叫內部函式
}
```

## 專案狀態

新版語言設計與 `struct` 21 項批次決策已有一致的文件基準，但全語言的形式文法、型別與借用安全規則尚未封閉。已在 [語言規格的統整與範例](AI-build/語言規格-v0.2.md) 提出一份結構示範程式及預期拒絕的反例，**僅供規格討論，沒有可執行或通過編譯的宣稱**。程式碼實作、編譯模式、開發工具及發行方式均需以後續已核准且已驗證的成果為準。

內部規格、待確認議題及工作階段記錄於 [AI-build](AI-build/README.md)。所有文件採繁體中文與 UTF-8。
