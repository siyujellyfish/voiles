# voiles

voiles 是規劃中的自製程式語言。本儲存庫目前以語言設計與開發規劃為主，**尚未提供可執行的直譯器或編譯器**。

## 新版語言設計方向（初步草案）

自 2026-10-23 起以新版草案為準，暫捨棄此前版本的具體語法規格。新版目前包含：

- 型別：`int`、`float`、`str`、`bool`、`list[T]`、`dict{K,V}`、`none`，以及具多型別聯集／缺失值語意的 `Optional`。
- 大括號 `{}` 劃定作用域，換行分隔語句且忽略空白行；圓括號內可跨行；`#` 支援程式碼行尾註解（J05），語句區塊至少一條語句，`if true{}` 不合法（J06）。一般 `var`、`const`、`share` **都必須標註型別**（H03、I01、I02）；`var x:int` 可以延後初始化，但讀取前必須通過靜態檢查（I05）；`const`、`share` 則必須在宣告時初始化。布林常值是 `true`、`false`，`int` 為有號 64 位元且溢位靜態可判斷即報錯、否則執行時報錯；整數常值可使用連續底線分組，如 `1__000`（I03/J01），十進位前導零如 `007` 等同 `7`（K03），並支援僅用小寫前綴的 `0xFF`、`0b1010`、`0o77`，以及非十進位連續底線 `0xFF__AA` 和前綴後底線 `0x_FF`（J02/K01/K02/L01/L02）。`float` 採 IEEE 754 十進位 `decimal64`，**不支援科學記號**，允許連續底線 `1__000.25`、小數點旁底線 `1_.25`／`1._25`，以及結尾底線 `1.25_`；浮點 `.5` 不合法（須寫 `0.5`），`1.` 表示 `1.0`（L03–L05）。**M01 已確認連續兩點 `..` 優先作區間符號**，所以 `1..4` 切分為整數 `1`、`..`、整數 `4`，單獨 `1.` 仍是浮點常值；前導零 `00.5` 與 `0.5` 同值（M06）。**T06 已裁決 I04：decimal64 預設最近值、恰好一半時取偶數捨入**；其餘異常與特殊值規則待決。一般字串常值只用雙引號（L06），允許空字串 `""`（M02），`\n` 為換行（M03）、`\"` 為雙引號（M04），`\\` 為反斜線（N01）、`\t` 為定位字元（N02）、`\r` 為歸位字元（N03）；未知跳脫為語法錯誤（N04），一般字串不得直接跨行（M05）。`"""` 多行註解可在程式碼**後方**同一行開始（N05），允許空註解 `""""""`（N06），但**不可巢狀**（O01），**結束後不得於同一行接續程式碼，須換行**（O02）。一般字串內的 `#` 是文字內容（O03），另支援 Unicode 跳脫 `\u{...}`（O04）及空字元跳脫 `\0`（O05）；`str` **不允許以 `+` 串接**（O06）。**Q01** 允許 Unicode 跳脫 `\u{...}` 內的前導零；**Q02** 對格式可辨識但無效的 Unicode 碼位（如 `\u{110000}`）使用替代字元 `�`，不擴張至格式錯誤。多行註解結束後允許空白再換行（Q03），普通字串**之外**連續三個雙引號優先辨識為多行註解標記（Q04）。`str` 不支援 `==` 相等比較（Q05）與 `*` 重複字串（Q06），先前 O06 的 `str +` 禁令仍有效；不據此確定 `str !=` 或其他型別運算。**T01** 確認 Unicode 跳脫十六進位英文字母大小寫皆可；**T02/T03** 新增 `\u{}` 與 `\u{GG}` 都轉替代字元 �，不影響未知跳脫的語法錯誤；**T04** 限多行註解結束後只能接一般空格或 Tab 再換行；**T05** 另外禁止 `str` 的 `!=`。**U01** 將 `\u{...}` 的十六進位數字上限訂為 6 位（含前導零），**U02** 規定缺少右大括號為語法錯誤；**U03/U04** 不允許碼位數字內的空白及底線，但其與 T03 替代字元規則的錯誤優先順序仍待決。Unicode 版本、字素比較、其他壞格式、註解剩餘詞彙邊界及其他語意仍待議。
- 一般 `fn`、`async fn`，以及 `struct` 型別名稱、方法和欄位均預設公開；名稱以 `_` 開頭的函式、結構型別、方法或欄位只在同一模組內可見，跨模組不可存取。
- 結構 `struct` 的欄位與 `fn` 方法定義在同一區塊，不得同名；方法內明確使用 `self.欄位名稱`。實例 `var` 宣告須標註型別，如 `var s:Stru = Stru()`。具名或空參數建立、預設值每次建立重新求值，`var` 欄位允許延後初始化但讀前須靜態檢查；**F01 已修訂 D09：`struct const` 欄位宣告時必須有預設值，不允許延後首次寫入**；**F02：`const` 結構實例變數宣告時必須有初始運算式**。`struct` 必須至少一個欄位或方法，`struct Empty{}` 不合法（K06）；不支援巢狀／泛型結構或自訂專用建構方法；初始化與借用安全其他細節仍待決。
- `and`／`or` 採短路求值，`!=` 表示不相等（I06），`1..4` 不含 4；`return i+=1` 先更新後回傳新值。具名欄位引數不限制順序，未知／重複欄位靜態錯誤，尾逗號合法；具名值覆蓋預設值時不計算原預設值。一般函式呼叫及函式宣告參數列表均允許尾逗號，例如 `add(1,2,)` 和 `fn add(a:int,b:int,)->int{...}`。同一作用域不得重複宣告同名變數，但內層區塊允許遮蔽外層變數（H05/H06）；借用及完整名稱解析細則仍待決。
- 值的預設複製、明確 `.move()` 與 `.borrow()`；結構需所有欄位皆可複製才可複製，禁止只移動部分欄位。`self` 作為方法接收者只允許借用，方法不得消耗整個 `self`；方法之外仍可依已定一般規則明確移動整個實例，借用可變性與安全細節仍待定；字串第一層索引以 Unicode 字素叢集為單位，**U05 允許負數索引從尾端倒數**；**U06 規定第一層索引越界靜態可證明則靜態報錯、否則執行時報錯**。第二層 UTF-8 位元組索引的負數、越界與結果型別、字素 Unicode 版本及資源安全仍未決。原始碼副檔名 `.voil` 已確定。

以下僅為設計語法示意，**目前不可執行**。原始碼副檔名 `.voil` 已依 D13 核准，但模組載入語意仍待確認：

```voiles
# a.voil
share count:int = 5

fn read_count()->int{
    return count
}

fn _helper()->none{
    # 模組內部函式
}
```

```voiles
# main.voil
import a

fn main()->none{
    print(a.read_count())  # 公開函式
    a._helper()            # 錯誤：不能跨模組呼叫內部函式
}
```

## 專案狀態

新版語言設計與 `struct` 21 項批次決策已有一致的文件基準；**正式規格的權威來源是新版 [AI-build/語言規格-v0.2.md](AI-build/語言規格-v0.2.md)**，檔名沿用歷史但內容已取代舊版 v0.2。原 P01 舊合併請求 #4 已關閉、不應合併。D11 對 `Optional` 的「考慮預設只支援容器」尚未裁決，不改變既有示例。全語言的形式文法、型別與借用安全規則尚未封閉。已在 [語言規格的統整與範例](AI-build/語言規格-v0.2.md) 提出一份結構示範程式及預期拒絕的反例，**僅供規格討論，沒有可執行或通過編譯的宣稱**。程式碼實作、編譯模式、開發工具及發行方式均需以後續已核准且已驗證的成果為準。

內部規格、待確認議題及工作階段記錄於 [AI-build](AI-build/README.md)。所有文件採繁體中文與 UTF-8。
