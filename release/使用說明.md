# voiles 0.1.0-preview.1

此預覽版提供 Linux x86-64 原生 CLI。下載同一版本的 .tar.xz 與 SHA256SUMS，在下載目錄執行：

```sh
sha256sum -c SHA256SUMS
tar -xJf voiles-0.1.0-preview.1-linux-x86_64.tar.xz
cd voiles-0.1.0-preview.1-linux-x86_64
./voiles --version
./voiles check examples/入門/基本加法.voil
./voiles run examples/入門/多檔/main.voil
```

最後一行輸出 42。安裝到個人命令目錄可執行 `install -Dm755 voiles "$HOME/.local/bin/voiles"`。解除安裝只需移除該檔。直接執行、check 與 run 均可在沒有開發工具鏈的環境使用。

## 語法與建置

以 .voil 保存 UTF-8 原始碼。整數函式使用明確回傳型別及 return，局部宣告使用 var 或 const。例如 `fn main()->int{ return 2 + 3 }` 的結果是 5。範例目錄附有可直接執行的單檔與多檔版本。模組從入口所在目錄載入。

build 與 pack 需要 PATH 可找到 stable rustc、GNU 連結器及 Linux x86-64 系統開發函式庫。pack 另需 glibc 靜態函式庫。下列命令需要新的輸出檔名：

```sh
./voiles build examples/入門/基本加法.voil -o ./addition
./voiles pack examples/入門/多檔/main.voil -o ./numbers
./numbers
echo "$?"
```

numbers 退出 42。run 將完整有號 64 位元結果寫到 stdout。原生產物使用低八位作退出狀態，執行錯誤寫到 stderr 並退出 1。缺少入口或匯入檔時，依診斷路徑確認檔案位置；靜態型別或借用錯誤請依行欄修正；原生建置失敗時先檢查 rustc、系統連結器及輸出路徑。

## 相容與回報

0.1.0-preview.1 承諾本版實際驗收的 check、run、build、pack 及舊式單檔檢查。預覽版的後續變動會列入變更紀錄。本版的原生子集涵蓋受限整數、同步跨檔呼叫、受限分支、共享字串及結構移交；完整容器、一般迴圈、async 與其他平台仍在公開原生子集之外。私有自舉 ABI 供工具鏈元件使用。

回報缺陷時，附上 --version、平台、最小 .voil 範例、重現命令及實際／預期結果。維護者將確認的案例加入對應 CLI 或核心回歸測試。來源版本記錄於 SOURCE，建置工具資訊記錄於 TOOLCHAIN。[問題回報](https://github.com/siyujellyfish/voiles/issues)
